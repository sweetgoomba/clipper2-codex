# 스토리보드 제작 목적·생성 스타일 목록 제안

> 이 문서는 설계·구현 당시의 결정과 검증 이력을 보존한다. 이후 수정 및 최신 Git/승인 상태는 [스토리보드 작업 카드](../handoff/tasks/storyboard.md)를 우선한다. 9/21 현재 제품 구현은 별도 worktree에 미커밋이며, 사용자는 `.codex` 문서만 커밋·푸시하도록 승인했다.

상태: 2026-09-21 최신 요청 반영. 목적은 공통 14개에서 1뎁스별 고정 선택지로 전환하고, 스타일 24개는 8개씩 더보기로 펼친다. 대사 예시·툴팁은 제거한다. v2 목업에 적용했으며 제품 코드는 아직 미변경이다. 사용자가 현재 시안에 동의해 분야별 목적(분야마다 5개) 및 스타일 표시 방식을 확정했다. AI 추천은 고도화로 보류한다.

## 구성 원칙

목적은 시청자에게 제공할 가치 또는 달성하려는 결과로, 단일 선택 또는 직접 입력이다. 스타일은 전달 말투로 복수 선택한다. 목적은 선택한 1뎁스 분야에 맞춰 바뀌고, 2뎁스나 타겟 변경으로 바뀌지 않는다. 분야를 선택하기 전에는 안내 문구를 보여주며 직접 입력란은 항상 유지한다.

분야 변경 시 이전에 선택한 목적이 새 분야 목록에 없으면 직접 입력란으로 옮겨 보존하고 안내한다. 기존 직접 입력과 선택한 스타일도 유지한다. 이 보존 동작은 이전 입력을 조용히 덮어쓰지 않는 합의를 따른 시안 처리이며 실제 저장 계약은 바꾸지 않았다.

## 제작 목적 — 1뎁스별 확정 선택지

### 시사·사회

- 주요 이슈 빠르게 정리
- 사건의 배경과 맥락 설명
- 정책이 일상에 미치는 영향 설명
- 서로 다른 입장 비교
- 사회 문제에 대한 생각 나누기

### 경제·금융

- 경제 흐름 쉽게 해설
- 생활 속 돈 관리 돕기
- 금융 상품의 차이와 조건 비교
- 경제 용어와 원리 설명
- 제도 변화와 확인할 점 안내

### 비즈니스·커리어

- 기업의 전략과 사례 분석
- 일하는 방법과 노하우 공유
- 취업·이직 준비 돕기
- 창업 경험과 시행착오 공유
- 제품·서비스의 가치 알리기

### IT·AI

- 새 기술과 도구 소개
- 실제로 쓰는 방법 안내
- 도구·기기의 차이 비교
- 어려운 기술 원리 설명
- 직접 써본 경험과 한계 공유

### 과학·우주

- 일상 속 과학 궁금증 풀기
- 발견과 연구의 의미 소개
- 과학 원리 쉽게 설명
- 실험·관찰 과정 보여주기
- 과학에 대한 오해 짚기

### 역사·인문

- 사건과 인물의 맥락 설명
- 역사 속 흥미로운 이야기 소개
- 현재와 과거의 연결 찾기
- 다양한 해석과 관점 비교
- 철학적 질문 함께 생각하기

### 교육·학습

- 어려운 개념 이해 돕기
- 문제 풀이 과정 설명
- 공부 습관과 학습법 공유
- 시험·자격증 준비 돕기
- 배운 내용을 연습하고 복습하기

### 연예·대중문화

- 주요 활동과 소식 정리
- 입문자를 위한 매력 소개
- 작품·무대의 감상 포인트 설명
- 팬의 시선으로 감상 나누기
- 대중문화 현상과 흐름 해설

### 영화·드라마·애니메이션

- 취향에 맞는 작품 발견 돕기
- 작품을 보고 느낀 점 공유
- 장면·캐릭터·주제 해석
- 제작 비하인드와 표현 기법 소개
- 작품별 차이와 매력 비교

### 게임

- 처음 시작하는 이용자 돕기
- 공략과 플레이 노하우 공유
- 인상적인 플레이 순간 보여주기
- 게임의 재미와 아쉬움 리뷰
- 업데이트와 변화 정리

### 스포츠

- 경기 핵심 장면과 흐름 정리
- 전술과 플레이 이해 돕기
- 규칙을 쉽게 설명
- 선수와 팀의 이야기 소개
- 팬의 시선으로 감상 나누기

### 건강·운동

### 뷰티·패션

- 생태와 자원에 대한 궁금증 풀기

## 생성 스타일 — 8개씩 더보기

처음 8개를 표시하고 더보기를 누르면 기존 항목 아래에 8개를 추가한다. 두 번째 더보기로 전체 24개를 표시한 뒤 버튼을 제거한다. 펼칠 때 선택한 항목과 다른 입력을 유지한다. 새로 여는 작성/수정 화면은 8개로 시작하며 펼침 여부가 저장된 스타일 값을 바꾸지 않는다. 스타일 예시/툴팁은 제공하지 않는다.

### 처음 표시

- 친구한테 썰 풀듯
- 솔직하고 거침없이
- 무심하게 툭툭
- 능청스럽게 농담 섞어
- 텐션 높게, 리액션 크게
- 덕후처럼 디테일하게
- 현실적인 조언처럼
- 통념을 재치 있게 꼬집으며

### 첫 번째 더보기

- 궁금증을 이어가며
- 차분하게 몰입시키며
- 혼잣말 같은 감성으로
- 다정하게 편들어주듯
- 짧고 단호하게
- 옆에서 차근차근 알려주듯
- 비유로 쉽게 풀며
- 질문 던지며 함께 생각하듯

### 두 번째 더보기

- 현장 중계하듯 생생하게
- 조용히 비밀 얘기하듯
- 자기 얘기로 웃기며
- 작은 일도 호들갑스럽게
- 뻔뻔하게 자신만만
- 시청자에게 말 걸듯
- 정중하고 또렷하게
- 돌아보듯 담담하게

## 검증 및 상태

로컬 Chrome에서 8→16→24개 누적 표시, 전체 표시 후 더보기 제거, 예시·스타일 툴팁 없음, 21개 분야별 목적 5개 정확한 전환, 기존 선택 목적의 직접 입력 보존, 사용자 직접 입력 및 복수 스타일 보존, 768/390px 줄바꿈, 런타임 오류 없음을 확인했다. 데스크톱 스크린샷 확인 완료. 실제 AI/API 호출·제품 코드 변경·커밋·푸시 없음. 관련 문서는 미커밋이다.
