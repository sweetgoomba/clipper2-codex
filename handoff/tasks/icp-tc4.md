## 결정

TIPS 최종 보고서용 ICP 인증 시험의 TC4는 **새 “생성시간 로그” 메뉴를 개발하지 않고 기존 개발자 로그 메뉴를 사용**한다. 평균을 계산하는 제품 기능도 필요하지 않다. 시험 기록에서 수동 계산할 수 있다.

시험 중 다른 렌더 작업을 섞지 않고 URL로 숏폼 생성 작업 5개를 연속으로 정상 완료한다. 개발자 모드 로그에서 Nest 소스의 `clipper_video_render.job.succeeded` 성공 로그 중 가장 최근 5개를 확인하고 각 상세 `ctx.elapsedMs / 1000`을 초로 기록한다.

설정의 앱 버전을 5회 클릭해 개발자 모드 활성화 → 왼쪽 로그 메뉴 → 새로고침 → 소스 Nest만 선택 → 위 메시지 검색 → 시간순 목록의 최근 5개 상세 확인. 메시지에는 다른 플러그인의 동일 공통 렌더 잡도 포함될 수 있으므로 **이 시험 중 해당 로그를 만드는 다른 작업을 실행하지 않는 조건**이 필요하다. 로그 회전/조회 범위로 5개 모두 보이는지도 실제 시험 때 확인한다.

## 시간의 의미

기존 `elapsedMs`는 공통 큐가 실행을 시작한 뒤 executor/종결 처리까지의 구간이다. 사용자 생성 버튼 이후 모든 사전 준비·대기 시간을 포함한다고 주장하지 않는다. 절차서의 측정 시작/끝 정의를 이 값과 일치시킨다.

이전 PDF TC4에는 5개 시험·평균 30초 이하 기준이 있었고, 사용자에게 전체 수정 문안을 제공했다. 실제 제출 PDF를 수정/재제출했는지는 미확인이다. 결과 자체와 인증기관의 변경 수용 여부도 미확인이다.
