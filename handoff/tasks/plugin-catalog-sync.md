# W18 플러그인 목록과 관리자 및 앱 스토어 동기화

최종 정리: **2026-11-18 KST**. 상태: **설계 제안·독립 검증 2회와 필수 보완 반영, 제품 미구현**. 사용자 요청으로 설계만 재개했으며 구현 승인은 받지 않았다. 우선순위·구현 일정은 미정이다.

## 목표와 범위

앱에 구현된 사용자 기능과 웹 관리자 운영 목록의 ID를 맞추고 카테고리·순서·공개·전체 활성·요금제 연결을 일관되게 관리하는 후속 과제다. 수동 등록/릴리스 목록 전송 중 방식은 미확정이다. 실제 사용자 기능과 공유 내부 모듈·과금 작업은 구분한다.

관련 플러그인 관리·분류·전체 긴급 중지 논의는 후속 검토로 보존한다. 현재 W19의 등급별 허용 설정과 실행 검사, 회원 웹 가격 카드의 DB 허용 목록 표시는 이 동기화의 완료를 기다리는 과제가 아니다.

## 현재 상태와 중단 지점

사용자가 복잡성을 이유로 이번 세션 구현에서 제외했다. 제품 카탈로그/동기화/관리자 분류/전역 중지 기능은 미구현이다. 실제 소스 14개 추출과 임시 HTTP/PostgreSQL의 11개 검사는 기술 실험이며 제품 endpoint·권한·배포·앱 연결 완료가 아니다.

초기 전략실 답변은 Basic⊆Pro⊆Business였다. 이후 사용자 승인으로 W19는 Free를 포함한 하위 자동 포함 전역 ON/OFF를 구현했으며 OFF에서는 독립 설정이 가능하다. 스토어 표시·설치·준비를 허용하고 권한이 필요한 실제 실행에서 검사하는 현재 흐름도 W19에 구현됐다. 초기 이사님 문의문/카드 시안은 당시 논의이며, W18 전체 동기화가 구현됐다는 뜻은 아니다. 개인 설치 순서·즐겨찾기 순서는 유지하고 전체 사용 중지 시 등급별 설정을 지우지 않는다.

## 작업 공간

후속 전용 구현 브랜치·담당 세션은 아직 없다. 기존 조사 경로는 `.worktrees/signup-promotion-plugin-access-20261028`이고, 그 안 관련6개 저장소의 현재 W19 브랜치는 `feat/signup-credit-promotion-free-20261102`다. W18 전용 구현 공간으로 확정하지 않는다. 재개 시 실제 원격 dev·미커밋 상태를 다시 확인한다. 문서는 `.codex`에 둔다.

## 다음 행동

11/18 권고 설계를 사용자와 검토한다. 구현 지시가 오면 현재 원격 dev와 작업 상태를 다시 확인하고 계약·migration·화면·실행 경계별 검증 계획을 작성한다. 기존 기술 실험을 그대로 운영에 붙이지 않는다. 설계 문서만을 근거로 제품 구현에 착수하지 않는다.

## 제약과 미확인

- 전역 중지의 실행 중 작업·오프라인·캐시 처리와 배포 목록 동기화 방식은 재개 시 설계한다. 초기 스토어 노출 질문을 현재 W19 실행 흐름 전체의 미승인 상태로 되돌리지 않는다.
- 앱에 없는 코드가 서버 등록만으로 생성되는 구조를 약속하지 않는다.
- 정식 지원 버전의 범위를 넘는 옛 개발판 전용 호환 예외를 임의 추가하지 않는다.
- 구현·커밋·푸시·배포·검증은 각각 구분한다.
