# W17 — 범용 프로모션 코드·AI 부스 캠페인

## 목표와 확정 범위

회원이 웹에서 프로모션 코드를 직접 입력해 약속된 혜택을 받고, 관리자가 캠페인·코드를 생성하며 사용 횟수와 회원별 등록 내역을 조회하는 **재사용 가능한 기능**. 계정당 캠페인별 성공 등록 1회이고 다른 캠페인은 별도로 참여 가능하다.

이번 AI 부스에는 모든 바우처에 **행사 공통 코드 1개**를 인쇄한다. QR은 사이트 접속용이다. 혜택은 **Pro 1개월과 이에 포함된 1,000크레딧**이며 신규 회원 무료체험 400크레딧은 별도다. 전략팀은 **① 과거 이용권 결제 및 사용 이력이 있으면 현재 만료됐어도 등록 불가**를 선택했고, 사용자는 **무료체험 이용권 이력은 제외**한다고 확정했다. 관리자 지급 이용권 이력은 미결정이다. 이 제한은 이번 캠페인에만 적용하고 다른 프로모션 코드에는 공통 적용하지 않는다. 관리자가 캠페인 등록 가능 기간을 **행사 시작일부터 1년**으로 설정한다. 수령 시점 추적·현장 등록 확인은 없다.

담당: **한진아 대리**. 구현 완료 목표: **2026-10-21**. 제품 코드 변경이나 구현 검증은 아직 없다.

## 재개 시 먼저 정할 것

1. 과거 이력 제한에 **관리자 지급 이용권**을 포함할지. 무료체험 이력은 등록 제한에서 제외하기로 확정. 현행 유료 결제처럼 무료체험 400크레딧을 보존하면서 Pro 권한을 적용할 수 있으며, 행사 지급 경로에 이 동작을 연결해야 한다. 향후 다른 캠페인의 기존 이용권 처리도 별도 결정.
2. 이번 캠페인 전체 등록 한도를 둘지와 그 건수.
3. 크레딧 전용 코드의 등록·사용 조건, 취소·재발급·회수 등 보류된 운영 정책을 범용 기능 범위에 어떻게 반영할지.
4. 실제 인쇄 코드 문자열과 관리자 상세 설정을 정식 spec에서 확정.

구체적인 확정/미결정 구분과 회원·관리자 흐름, 데이터 설계 방향은 위 [설계 기록](../../design/2026-10-12-promotion-code-decisions-and-open-questions.md)을 따른다. 현행 Web API·고객 웹·관리자 웹 상태와 Git 작업 공간은 구현 재개 시 다시 확인한다. 요청 없는 commit·push는 하지 않는다.
