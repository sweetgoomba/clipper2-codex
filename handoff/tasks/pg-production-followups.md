최종 확인: 2026-09-15 KST. 상태: **기록상 미완료 / 재개 전 최신성 확인**.

[전체 작업 현황](../WORKBOARD.md)

2026-09-17 W04의 [독립 재감사](../../implementation/2026-09-17-astra-independent-review.md)는 수정 전 증거다. 이후 승인된 R01–R13+A14와 추가 환급 누락을 수정했고, 현재 정본은 [최신 수정·검증 결과](../../implementation/2026-09-17-archive-refund-fix-result.md)다. 코드 커밋 정리와 설치형 실기가 남으며 이 카드의 과거 운영 후속과 구분한다. 서버 작업·실제 PG·개발 DB 변경을 승인받은 것으로 해석하지 않는다.

## 심사 작업과 구분

카드사 심사용 익명 테스트 성공은 정식PG 결제·권한·크레딧의 전체 검증 완료가 아니다. [PG 운영 TASKS](../../implementation/TASKS.md) §4~5가 상세 증거원이다. 아래는 9월 기록의 미완료군이며 이번에 서버나 코드로 재검증하지 않았다.

## 남은 작업군

- 사용 크레딧과 환불자격, 부분환불/실패/복구, 자연기간종료·동시요청·멱등성.
- 구독 즉시변경/예약/취소, 카드변경 후 실제다음청구, 재시도·유예·만료·worker복구.
- webhook/콜백의 동시성·실패재전송. 이미 확인한 정상·중복 사례는 반복하지 않는다.
- 최종동의/약관·FAQ·정책 확인, 테스트MID/웹훅·옛등록 정리, 명시 승인된 live전환 판단.
- 운영desktop/runner/Release·S3 분리, Windows 설치·dev공존·자동업데이트 검증.
- 모니터/알림·백업복원·정전재기동 등 운영준비.

## 다음 행동

사용자가 원하는 항목을 고른 뒤 TASKS의 과거 unchecked를 최신 후속문서/코드/실제출력과 대조한다. 일부는 이후완료됐을 수 있으므로 전부 신규할일로 취급하지 않는다. Mac공개·자동빌드/업데이트와 실제ML·Build5보류는 유지. 서버직접접속 없이 사용자 실행 방식으로 진행한다.

## 갱신 규칙

작업 재개 시 실제 branch/HEAD/미커밋과 아래 근거를 대조한다. 세션 종료 때 상태·중단 지점·다음 행동·검증 한계만 갱신하고, 세부 실행 이력은 날짜별 기록에 링크한다. 다른 작업의 우선순위나 상태를 자동 변경하지 않는다.
