# AI 숏폼 디렉터 부분 레퍼런스 성공 자동 진행 설계

- 작성일: 2026-07-31
- 범위: Desktop NestJS 조사 오케스트레이션, Angular 아이디어 찾기 화면
- 상태: 사용자 방향 승인 후 구현 전 검토

## 목표

선택한 레퍼런스 영상 중 일부만 정밀 분석에 성공해도 성공한 분석만 사용해 참고 영상
패턴과 조사 주제를 생성한다. 개별 영상 실패는 전체 조사 실패로 취급하지 않는다.

## 상태와 동작

| 정밀 분석 결과 | 조사 동작 | 화면의 전체 조사 상태 |
|---|---|---|
| 전부 성공 | 모든 성공 결과로 자동 종합 | 조사 완료 |
| 1개 이상 성공, 일부 실패 | 성공 결과만으로 자동 종합 | 조사 완료 |
| 전부 실패 | 자동 종합하지 않고 사용자 선택 대기 | 레퍼런스 선택 대기 |
| 사용자가 정밀 분석 없이 계속 | 시장 조사 결과만으로 주제 생성 | 조사 완료 |

부분 실패가 있어도 참고 영상 패턴과 조사 주제까지 정상 생성됐다면 부모 조사 run은
`succeeded`로 끝낸다. 정밀 분석 attempt run은 실제 실행 결과를 숨기지 않도록
`partial`을 유지한다.

## 부분 성공 처리

1. 영상별 분석과 검증은 현재처럼 독립적으로 실행한다.
2. 검증 통과 분석이 한 개 이상이면 부모 조사 run을 다시 `running`으로 전환한다.
3. 참고 영상 패턴 종합에는 검증 통과 분석만 전달한다.
4. 주제 종합에는 시장 조사 근거와 성공한 참고 영상 패턴만 전달한다.
5. 종합이 끝나면 부모 조사 run을 `succeeded`로 완료한다.
6. 실패 영상의 failure artifact, 비용, 단계, 재시도 정보는 삭제하거나 성공으로
   바꾸지 않는다.

기존의 “선택한 영상 수와 성공한 영상 수가 같아야 진행” 조건을 “검증 통과 분석이 한
개 이상이면 진행” 조건으로 변경한다.

## 전부 실패 처리

검증 통과 분석이 없으면 자동으로 시장 조사 전용 주제를 생성하지 않는다. 사용자가
화면에서 다음 중 하나를 선택한다.

- `정밀 분석 없이 계속`: 기존 market-only 사전 점검과 비용 승인을 거쳐 진행
- `실패 영상 다시 시도`: 실패 영상을 다시 선택해 새 분석 승인으로 진행
- `다른 영상 선택`: 다른 후보로 선택 revision을 만들고 진행

정밀 분석 없이 계속하는 경로는 새로 만들지 않고 기존 skip preflight와 skip 실행
경로를 재사용한다.

## 화면 표시

- 부모 조사 run이 성공하면 전체 상태는 `조사 완료`로 표시한다.
- 정밀 분석 진행 영역에는 별도로
  `레퍼런스 3개 중 2개 분석 성공 · 1개 실패`처럼 결과를 표시한다.
- 실패 영상 카드는 실패 단계와 교체 동작을 계속 보여준다.
- 전부 실패하면 진행 영역에 세 가지 다음 행동을 이해할 수 있게 안내한다.
- 성공한 분석이 있는 partial attempt를 발견한 화면은 폴링을 중단하지 않고 부모
  조사가 종합을 마칠 때까지 계속 확인한다.
- 전부 실패한 partial attempt에서만 자동 폴링을 멈추고 사용자 선택을 기다린다.

## 데이터와 감사 기록

- 기존 JSON 파일 저장 구조와 artifact 종류를 유지한다.
- 성공한 분석, 실패 artifact, attempt completion 집계를 모두 보존한다.
- 새로운 결제 또는 크레딧 차감은 추가하지 않는다.
- 기존 관리자 credential과 Web API provider 호출 구조를 그대로 사용한다.

## 오류 경계

- 성공 분석이 한 개 이상이어도 이후 OpenAI 패턴·주제 종합이 실패하면 기존 조사 실패
  처리와 재시도 예산을 그대로 적용한다.
- 검증을 통과하지 않은 분석은 패턴·주제 입력에 포함하지 않는다.
- 전부 실패한 상태를 성공으로 위장하지 않는다.

## 검증 기준

1. 3개 중 2개 성공 시 성공한 2개만으로 패턴·주제 종합이 실행된다.
2. 위 경우 부모 조사는 `succeeded`, 분석 attempt는 `partial`이다.
3. 실패 영상 artifact와 집계가 그대로 남는다.
4. 3개 전부 실패 시 부모 조사는 `awaiting_reference_selection`에 남는다.
5. 전부 실패 후 기존 `정밀 분석 없이 계속`을 승인하면 시장 조사만으로 완료된다.
6. Angular는 부분 성공 시 부모 완료까지 폴링하고, 전부 실패 시 사용자 선택을
   기다린다.
7. 화면은 전체 `조사 완료`와 레퍼런스 성공·실패 집계를 구분해 보여준다.

## 비범위

- 새로운 run status 또는 별도 데이터베이스 도입
