# AI 숏폼 디렉터 보관함 상세 딥링크 설계

## 목표

프로젝트 보관함의 `AI 숏폼 디렉터` 작업물에서 `상세`를 누르면 일반
프로젝트 상세 화면을 열지 않는다. 해당 작업물을 만든 AI 숏폼 디렉터
스토리보드 화면으로 이동하고, 사용자가 클릭한 최종 영상을 선택한 뒤
`3. 최종 영상 만들기` 영역까지 자동으로 스크롤한다.

## 범위

- Angular 라우팅과 AI 숏폼 디렉터 화면 상태 복원만 변경한다.
- 새 백엔드 API나 새 상세 화면은 만들지 않는다.
- 보관함의 `재생`, 일반 Clipper의 `편집`, 다른 플러그인의 상세 동작은
  유지한다.
- 과거에 만들어진 AI 숏폼 디렉터 렌더도 기존 작업 메타데이터만으로
  열 수 있어야 한다.

## 이동 계약

AI 숏폼 디렉터 렌더 작업에는 다음 값이 이미 저장되어 있다.

- `origin_storyboard_revision_id`: 해당 스토리보드 실행 ID
- `origin_render_revision_id`: 사용자가 클릭한 최종 렌더 ID

`상세` 클릭 시 `/shortform/director/storyboard`로 이동하면서 두 값을
각각 `storyboardRunId`, `finalRenderId` 쿼리 파라미터로 전달한다.
일반 `/projects/:projectId` 상세 화면은 열지 않는다.

필수 원본 ID가 없는 손상된 과거 작업은 잘못된 Director 화면으로 보내지
않고 기존 일반 프로젝트 상세 화면으로 폴백한다.

## 스토리보드 복원

스토리보드 페이지는 기존 후보 선택 파라미터 진입을 그대로 지원한다.
추가로 `storyboardRunId`가 있으면 기존 candidate-production API의
`run`, `result`, `project` 조회를 사용해 다음을 복원한다.

1. 해당 스토리보드 실행과 프로젝트
2. 결과에 저장된 후보 실행 ID, 후보 ID, 운영 프로필 ID
3. 같은 후보의 스토리보드 이력
4. 해당 스토리보드의 내레이션, 컷 영상, 최종 렌더 이력

목록의 최신 스토리보드를 대신 열지 않고 전달된 `storyboardRunId`를
선택 상태로 유지한다.

## 최종 영상 선택과 스크롤

프로젝트 복원이 끝나면 기존 `selectFinalRender` 동작으로
`finalRenderId`에 해당하는 영상을 불러온다. 영상 URL이 준비되고
`3. 최종 영상 만들기` 영역이 DOM에 나타난 다음 한 번만
`scrollIntoView({ block: 'start' })`를 실행한다.

스크롤은 보관함 딥링크 진입에서만 수행한다. 사용자가 후보 페이지에서
정상적으로 스토리보드를 열거나 페이지 안에서 다른 스토리보드를 선택할
때는 자동 스크롤하지 않는다.

## 오류 처리

- 스토리보드 실행을 찾지 못하면 기존 스토리보드 오류 영역에 표시한다.
- 지정한 최종 렌더가 삭제되었거나 찾을 수 없으면 스토리보드는 그대로
  보여주고, 기존 최종 렌더 조회 오류를 표시한다.
- 오류가 있어도 새 렌더를 자동 생성하거나 최신 렌더로 조용히 바꾸지
  않는다.

## 검증

- Director `상세`가 일반 프로젝트 상세 대신 스토리보드 딥링크로
  이동하는 컴포넌트 테스트
- `storyboardRunId`로 클릭한 스토리보드를 직접 복원하는 스토어 테스트
- `finalRenderId`를 선택하고 최종 영상 영역으로 한 번만 스크롤하는
  페이지 테스트
- 기존 후보 선택 진입과 다른 플러그인의 보관함 동작 회귀 테스트
