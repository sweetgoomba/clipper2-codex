# 클리퍼 요금제 변경 정책 추가 검토 요청

## 1. 검토 목적

차액 계산의 악용 가능성과 결제기간 변경 정책 확인.

- 같은 결제기간 내 상향: 즉시 적용
- 변경일부터 새 이용기간과 결제주기 시작
- 차액: 새 요금제 가격에서 기존 이용권의 남은 기간 가치 차감
- 크레딧 사용량: 차액 계산에서 제외
- 같은 결제기간 내 하향: 다음 결제일부터 적용
- 변경 결제에 실패하면 기존 이용권 유지

## 2. 연간 구독에서 월간 구독으로의 변경

연간 구독은 할인된 1년 약정 상품. 중도 월간 전환 시 부분 환불이나 별도 잔액 처리가 필요. DeeVid AI, Studio.Design, Higgsfield 등도 중도 전환을 제한.

- [Studio.Design 요금제 변경 안내](https://help.studio.design/en/articles/3652807-important-points-when-changing-project-plans)
- [Higgsfield 월간·연간 결제 변경 안내](https://higgsfield.ai/creator-hub/help-center/plans/can-i-switch-between-monthly-and-annual-billing)

- 연간 이용 중 월간 전환 불가
- 자동 갱신 중단 가능
- 연간 이용 종료 후 월간 신규 구독 가능

확인: 위 정책 승인 여부

## 3. 즉시 상향 차액을 기간만으로 계산할 때의 문제

기간과 크레딧은 소진 속도가 다름. 기간만 계산하면 크레딧을 먼저 사용한 고객에게도 같은 잔존가치를 인정.

### 실제 악용 가능 사례

| 사례 | 가능한 결과 |
|---|---|
| 베이직 400개 사용 직후 프로 월간 상향 | 프로 가격 정도로 총 1,400개 사용 |
| 베이직→프로→비즈니스 순서로 크레딧 사용 후 연속 상향 | 비즈니스 가격 정도로 총 5,400개 사용. 정상보다 1,400개 많음 |
| 프로 하향 후 크레딧 사용, 비즈니스 재상향 | 비즈니스 가격 정도로 매월 1,000개 추가 사용 반복 가능 |
| 월간 크레딧 사용 직후 같은 요금제 연간 전환 | 연간 가격 정도로 이전 월간 크레딧 한 달치 추가 사용 |
| 베이직 월간 크레딧 사용 후 프로 연간 전환 | 프로 연간 가격 정도로 베이직 400개 추가 사용 |
| 연간 월별 크레딧 지급 직후 사용하고 상위 연간으로 변경 | 기간은 거의 남아 있으나 두 요금제 크레딧 연속 사용 |

결과: 크레딧 선사용 유도, 기능 사용 원가 증가, 별도 크레딧 매출 감소.

### 차액 계산 대안

| 방식 | 장점 | 문제 |
|---|---|---|
| 기간만 계산 | 가장 단순 | 선사용·반복 상향 위험 수용 |
| 기간·크레딧 차액을 각각 계산해 큰 금액 적용 | 더 많이 소진된 기준 적용, 악용 방지에 가장 효과적 | 계산·안내 복잡 |
| 금액은 기간만 계산하고 새 크레딧 조정 | 중복 지급 감소 | 새 이용기간인데 크레딧 전량을 받지 못할 수 있음 |
| 기존 정기구독 크레딧 사용 시 즉시 상향 제한 | 단순한 악용 방지 | 즉시 상향 매출·편의 감소 |

확인: 위 위험을 감수하고 기간만 계산하는 기존 방향을 유지할지, 다른 방식을 적용할지

## 4. 같은 요금제의 월간 구독에서 연간 구독으로 변경

Notion, Dropbox, Higgsfield 등은 즉시 적용 후 남은 월간 가치를 차감. GitHub와 Zoom은 현재 월간 종료 후 적용.

- [Notion 결제기간 변경 안내](https://www.notion.com/help/billing)
- [Dropbox 결제기간 변경 안내](https://help.dropbox.com/billing/change-information)
- [GitHub 이용약관](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)
- [Zoom 결제기간 변경 안내](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0061653)

장기 구독 전환 및 상위 연간 변경과의 통일성을 고려해 즉시 적용 제안.

- 변경 즉시 기존 월간 구독 종료
- 변경일부터 새 연간 이용기간과 결제주기 시작
- 기존 월간 잔존가치를 연간 가격에서 차감
- 변경 결제에 실패하면 기존 월간 이용권 유지

주의: 기간만 계산하면 월간 크레딧 선사용 가능. 3번 차액 방식과 함께 확인 필요.

## 5. 월간 구독에서 상위 연간 요금제로 변경

예: 베이직 월간 → 프로 연간. 즉시 적용 제안.

- 변경 즉시 상위 연간 요금제 적용
- 변경일부터 새 연간 이용기간과 결제주기 시작
- 변경 결제에 실패하면 기존 월간 이용권 유지

주의: 기존 월간 크레딧 선사용 문제는 3번 차액 방식에 따라 달라짐.

## 6. 월간 구독에서 하위 연간 요금제로 변경

예: 프로 월간 → 베이직 연간. 현재 가격에서는 즉시 변경해도 환급 없이 추가 결제 발생.

| 선택 | 처리 | 장단점 |
|---|---|---|
| 다음 결제일부터 | 현재 월간 종료 후 연간 가격 전액 결제, 새 주기 시작 | 일할 계산·크레딧 선사용 문제 없음. 결제 실패 시 기존 재시도·유예·종료 절차 적용 |
| 즉시 | 기존 월간 종료, 잔존가치 차감 후 연간 시작. 실패 시 기존 월간 유지 | 기간만 계산하면 상위 월간 크레딧 선사용 가능. 기간·크레딧 함께 계산 시 위험 감소하나 복잡 |

확인: 적용 방식 선택

## 7. 요금제 상향 후 환불 판단 기준

예: 베이직 400크레딧 사용 → 프로 즉시 상향 → 프로 크레딧 미사용 → 환불 요청. 기간만 계산했다면 프로 이용권에는 베이직 잔존가치와 상향 추가 결제가 함께 포함됨.

### 선택안 1. 상향 전후를 하나의 연속된 정기구독으로 판단

- 이전·현재 요금제의 정기구독 크레딧 사용 이력 모두 확인
- 하나라도 사용했다면 환불 불가
- 무료 체험 크레딧과 별도 구매 크레딧 사용은 이 판단에 포함하지 않음
- 선사용 후 상향·환불 악용 방지, 기준 단순

### 선택안 2. 상향 추가 결제를 별도로 판단

- 새 크레딧 미사용 시 상향 추가 결제만 환불
- 기존 잔존가치가 새 이용권에 반영돼 있어 기존 이용권 복원 또는 전체 종료 기준 필요
- 결제·이용권 상태와 예외 처리 복잡

확인: 환불 판단 기준 선택

## 8. 확인 요청 사항 요약

1. 연간 구독 이용 중 월간 구독으로 변경하지 못하게 하는 제안을 승인할지
2. 크레딧 선사용과 반복 상향 위험을 감수하고도 즉시 상향 차액을 기간만으로 계산하는 방식을 유지할지, 아니면 다른 대안을 적용할지
3. 같은 요금제의 월간 구독에서 연간 구독으로 변경할 때 즉시 적용하는 제안을 승인할지
4. 월간 구독에서 상위 연간 요금제로 변경할 때 즉시 적용하는 제안을 승인할지
5. 월간 구독에서 하위 연간 요금제로 변경할 때 즉시 적용과 다음 결제일 적용 중 어떤 방식을 선택할지
6. 요금제 상향 전후의 정기구독 크레딧 사용 이력을 하나로 묶어 환불을 판단할지, 상향 추가 결제를 별도로 판단할지
