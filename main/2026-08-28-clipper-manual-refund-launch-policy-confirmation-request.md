## 1. 이번 런칭의 환불 처리 방향

이번 런칭에서는 다음과 같이 운영한다.

1. 고객은 회사가 공개한 이메일이나 전화번호로 환불을 문의한다.
2. 회사 담당자는 고객의 계정, 결제내역, 이용기간과 크레딧 사용내역을 확인한다.
3. 회사 담당자는 확정된 환불 기준에 따라 환불 가능 여부와 환불 금액을 계산한다.
4. 필요한 내부 확인을 마친 뒤, 권한이 있는 담당자가 토스페이먼츠 관리자 사이트에서 해당 결제를 직접 취소한다.
5. 결제 취소 후 Clipper의 이용권과 크레딧을 정해진 기준에 따라 조정한다.
6. 실제 취소 금액과 Clipper에서 조정한 내용을 확인하고 고객에게 결과를 안내한다.

이번 런칭에서는 다음 기능을 만들지 않는다.

- 서비스 안의 환불 신청 화면
- 고객이 환불 진행 상황을 확인하는 화면
- 고객에게 예상 환불 금액을 자동 계산해 보여 주는 기능
- 환불 가능 여부와 금액을 자동으로 판단하는 기능
- 관리자 페이지의 환불 검토·승인·실행 화면
- Clipper에서 토스페이먼츠 결제 취소를 직접 실행하는 기능
- 일반 환불의 자동 승인과 자동 처리

따라서 자동 환불 기능의 화면 구성, 자동 계산 방식, 관리자 입력 화면과 같은 세부사항은 이번 런칭 전에 정하지 않아도 된다. 다만 담당자가 실제 환불을 처리하려면 아래의 최소 기준은 반드시 정해야 한다.

## 4. 담당자가 사용할 환불 기준과 계산표

수동으로 처리한다는 것은 담당자가 고객마다 환불 금액을 임의로 정한다는 뜻이 아니다. 회사가 정하고 필요한 외부 전문가 확인을 마친 기준을 공통 계산표나 확인표로 만들어 모든 환불에 같은 기준을 적용해야 한다.

이번 런칭 전에 정해야 할 최소 항목:

1. 월간 정기구독을 전혀 사용하지 않은 경우 전액 환불을 제공하는 조건과 신청 가능 기간
2. 연간 정기구독을 전혀 사용하지 않은 경우 전액 환불을 제공하는 조건과 신청 가능 기간
3. 월간 정기구독을 일부 사용한 뒤 단순 변심으로 환불을 요청한 경우의 처리 원칙
   - 부분 환불을 제공하지 않고 다음 결제만 취소한 뒤 현재 이용기간을 유지
   - 앞으로 제공하지 않을 기간과 사용하지 않은 크레딧을 기준으로 부분 환불
   - 그 밖의 방식
4. 연간 정기구독을 일부 사용한 뒤 중도 종료를 요청한 경우의 계산 방식
   - 이미 이용한 기간을 되돌려 환불 대상으로 계산하지 않음
   - 앞으로 제공하지 않을 기간, 연간 할인분과 사용하지 않은 크레딧을 어떻게 반영할지 확정
5. 별도로 구매한 추가 크레딧을 전혀 사용하지 않은 경우 전액 환불을 제공하는 조건과 신청 가능 기간
6. 별도로 구매한 추가 크레딧을 일부 사용한 경우 부분 환불을 제공할지와, 제공한다면 남은 크레딧의 금액을 계산하는 방식
7. 중복 결제, 회사 책임, 서비스 장애, 상품 설명과 실제 제공 내용의 차이, 미성년자 결제와 같은 예외 상황의 처리 기준
8. 토스페이먼츠 관리자 사이트에서 취소할 실제 금액을 두 사람이 다시 확인해야 하는 금액 또는 상황

외부 전문가에게 확인할 사항:

- 상품별 청약철회 가능 기간과 기간 계산의 시작점
- 서비스를 사용하기 시작한 것으로 보는 기준
- 일부 사용 후 환불 의무와 계산 기준
- 정기구독 중도 종료와 앞으로 제공하지 않을 기간의 환급 기준
- 연간 할인분이나 위약금 공제 가능 여부
- 회사 책임, 서비스 장애와 미성년자 결제의 예외
- 전액·부분 환불 시 매출, 부가가치세와 결제 증빙의 취소·수정 방법
- 결제한 달과 환불한 달이 다른 경우의 처리 방법

## 6. 결제 취소 후 이용권과 크레딧 처리

토스페이먼츠 관리자 사이트에서 돈을 환불하는 처리와 Clipper 안의 이용권·크레딧을 변경하는 처리는 서로 다르다. 결제만 취소하고 내부 상태를 조정하지 않으면, 돈을 모두 돌려준 뒤에도 유료 이용권이나 해당 결제로 받은 크레딧이 남을 수 있다.

환불 건마다 다음 내용을 함께 확인해야 한다.

1. 다음 정기결제가 예정돼 있다면 자동 갱신을 중단했는가?
2. 전액 환불한 정기구독의 이용권을 언제 종료할 것인가?
3. 환불한 정기구독 결제로 지급했고 아직 사용하지 않은 크레딧을 얼마나 회수할 것인가?
4. 정기구독 결제만 환불할 때 무료 체험으로 받은 크레딧과 별도로 구매한 추가 크레딧은 어떻게 처리할 것인가?
5. 추가 구매 크레딧 결제를 환불했다면 그 결제로 지급한 남은 크레딧을 얼마나 회수할 것인가?
6. 토스페이먼츠에서 실제 취소된 금액과 이용권·크레딧 조정 결과가 일치하는지 누가 확인할 것인가?
7. 결제 취소는 성공했지만 이용권·크레딧 조정이 끝나지 않았을 때 누가 다시 처리할 것인가?

런칭 전 반드시 확인할 사항:

- 현재 운영자가 이용권과 크레딧을 안전하게 조정할 수 있는 방법이 있는가?
- 없다면 환불 건마다 제한된 절차로 조정할지, 이용권과 크레딧 조정만 가능한 최소한의 내부 수단을 마련할지 정해야 한다.
- 결제 취소와 이용권·크레딧 조정이 모두 끝나기 전에는 고객에게 환불 처리가 완전히 끝났다고 안내하지 않는 절차가 필요하다.

회신:

- 이용권 종료 기준과 처리 방법:
