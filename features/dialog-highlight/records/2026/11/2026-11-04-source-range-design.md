# 대사 하이라이트 원본 구간 편집 설계

사용자 요구: 한 하이라이트의 연속 구간을 앞뒤 원본 영상으로 확장·축소한다. 긴 원본 전체를 처음부터 타임라인에 펼치지 않는다. 인물·안무의 공통 편집기를 재사용한다.

## 결정
- 기존 SourceSceneOverlayComponent와 ClipTrimmerComponent를 대사에도 재사용한다. 대사의 기존 구간 편집 버튼으로 공통 모달을 편집 상태로 연다. 별도 유사 편집기를 만들지 않는다.
- 초기 표시 범위는 기존 구간 앞뒤 5초, 최소 12초이며 원본 시작·끝으로 제한한다. 더 넓게/좁게 보기와 이전/다음 범위 이동으로 필요한 부분을 점진적으로 탐색한다. 보기 범위 조작은 선택 구간을 변경하지 않는다.
- 실제 편집 가능 범위는 원본 영상 0초~끝이다. 대사는 기존 최소 3초, 인물·안무의 기존 최소 길이는 유지한다.
- 저장 좌표는 기존 ClipTrim의 원본 추출 클립 기준 상대 초를 유지한다. 앞쪽 확장은 음수 오프셋, 뒤쪽 확장은 기존 길이보다 큰 오프셋을 허용한다. 원본 영상이 없으면 기존 클립 안 편집만 유지한다.
- Nest는 원본 영상이 있으면 원본에서 다시 잘라 편집 파일을 생성한다. 원본 manifest는 수정하지 않고 기존 편집 사이드카에 기록한다. 원래 구간 복원은 기존 전용 동작을 사용한다.
- 상세 스크립트는 원본 stt.json의 시간 정보로 확장 구간을 반영한다. 없으면 기존 clip_stt.json의 알려진 정보만 사용하며 새 대사를 만들어 내지 않는다.
- 원본 미디어 티켓에 대사 프로젝트를 추가하되 기존 소유권·경로 검증을 유지한다. 미리보기, 다운로드, 숏폼 생성은 저장된 같은 편집 영상을 소비한다.

## 비교한 접근
- 기존 공통 원본 편집기 재사용: 이미 인물·안무가 쓰는 플레이어·손잡이·팬·복원을 공유해 중복이 적다. 채택.
- 대사 전용 임베디드 편집기 확장: 플레이어/탐색/줌 구현이 다시 갈라진다. 채택하지 않음.
- 원본 전체를 처음부터 표시: 30분 원본에서 30초 선택 구간이 보이지 않는다는 사용자 지적에 따라 사용하지 않음.

## 검증
30분 원본/30초 클립 초기 40초 viewport, 점진 확대·축소·팬 중 draft 보존, 0/끝 경계, 원래 구간 복원, 구형 상대 편집 기록, 앞뒤 확장한 실제 클립·스크립트·렌더 길이, 원본 없는 구형 프로젝트, 기존 인물·안무 회귀를 확인한다.

커밋·병합·푸시·배포는 이 요청에 포함되지 않는다.
