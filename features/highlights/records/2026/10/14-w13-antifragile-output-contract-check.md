# W13 — ANTIFRAGILE 인계 자료와 출력 계약 확인

상태: **W14 자료 및 W13 현행 코드의 읽기 전용 확인. 새 원본의 포즈 추론·메인 판정·제품 변경은 수행하지 않았다.** 아래는 W13 측 연결 설계이며, 양 세션의 구현 완료나 계약 수락을 뜻하지 않는다.

## 확인한 자료

- W14 기록: [SFace 특징 준비](14-w14-antifragile-sface-features.md), [얼굴 후보 관측](14-w14-antifragile-face-observations.md).
- 새 원본 SHA-256: `8feb03c0283c0d50eaab88ad7237524d6eacab9ad874d2b38258ecab3bc67517`. W14 기록상 1920×1080, 컨테이너 길이 220.891429초.
- W14 관측 결과 JSON의 SHA를 직접 다시 계산해 `93967024e0d79b0fa8276aa59cce22dc3a1a26878db3234ab2a63dad64949544`와 일치함을 확인했다. 1,104행, `frame_index`, `pts`, `time_base`, `time_sec`, `faces` 필드를 사용한다. 첫 행은 index/PTS 0, time base `1/60000`이다.
- 점수 행렬 manifest의 SHA는 `2650ca5cc9f33936c3109943cefd36138793d003c6d471ebd7701484345ce201`. `source_sha256`, 관측·특징·참조 선택 해시, query ID 규칙, 특징 공간과 행렬 크기를 별도로 기록하고 있다.
- 3,450개 얼굴 후보의 특징과 원시 비교 점수는 W14가 준비한 자료다. 이번 W13 확인에서 특징·점수 전항목을 독립 재계산하지 않았다. 이 자료만으로 메인 선택이나 얼굴 정확도가 확정되지 않는다.

## W13이 제공할 자료

새 실행이 정해지면 W13 소유의 새 출력 디렉터리에 아래 내용을 함께 저장한다. 기존 NewJeans 결과와 파일을 공유하거나 덮어쓰지 않는다.

| 범위 | 필수 내용 |
|---|---|
| 실행 출처 | 원본 SHA, 모델별 파일 SHA, 코드/config SHA, OS/device/runtime, 실행 횟수·시간·자원 상한과 실제 기록 |
| 원본 시각 | 0부터 시작하는 원본 frame index, 실제 디코딩 PTS, time base, 원본 PTS에서 계산한 초 |
| 좌표 | 원본 1920×1080의 픽셀 `xyxy`, 영상 회전/리사이즈/패딩의 역변환 정보 |
| 사람 관측 | 같은 프레임의 유효 사람 상자, 검출·관절 신뢰도, 관측 ID, 검출/추적 ID와 출처 |
| 선택한 역할 | 단독 메인·동시 공동 메인·군무·메인 없음·판단 불확실을 구분 |
| 선택한 몸 | 역할 참여자 ID와 실제 관측 ID의 연결. 보이는 몸만 실제 상자로 표시하고, 미관측 참여자의 상자를 만들지 않음 |
| 구간/교대 | 시작 포함·끝 제외의 원본 PTS 경계, 해당 구간의 역할/참여자, 교대 사유·신뢰도·카메라 컷 근거 |

`track_id`와 역할의 임시 참여자 ID를 실제 멤버 ID로 취급하지 않는다. ID가 바뀌거나 같은 구간 안의 몸이 교체되는 경우를 숨기지 않는다. 동시에 두 사람이 메인인 상태와 두 사람 사이의 순차 교대를 구분한다. 단순 검출 실패를 ‘메인 없음’으로 확정하지 않는다.

## W14 연결 규칙

1. 원본 SHA와 좌표계를 먼저 일치시킨다. W14 얼굴 후보는 `0,12,…,13236`의 1,104시점이다. 같은 frame index와 PTS의 몸 관측을 연결하며, 다른 시점의 몸 상자를 묵시적으로 가장 가까운 얼굴에 붙이지 않는다.
2. W13이 새 원본에서도 skip4를 선택한다면 산술상 3,310시점이고 W14 격자는 그 부분집합이 된다. **이는 실행 계획 후보이며 아직 그 격자로 분석한 결과가 아니다.** 실제 원본 디코딩 PTS와 프레임 수를 검증한 뒤 고정한다.
3. 장면 컷 후보 102개를 그대로 실제 컷으로 확정하지 않는다. 영상 마지막 구간 끝도 컨테이너의 오디오 포함 길이로 추정하지 않고 마지막 영상 PTS와 프레임 길이에서 정한다.
4. W14는 선택한 몸에 연결된 얼굴의 없음·복수/모호·검출 실패·인식 보류/충돌·잘못된 이름 확정을 별도로 기록한다. W13은 얼굴 점수나 이름을 메인 선정 규칙에 되먹이지 않는다.
5. 얼굴 표본 사이에 발생한 메인 교대는 W13의 더 촘촘한 구간 자료로 유지한다. W14 표본이 없는 순간을 얼굴 인식 성공/실패로 추정하지 않는다.

## 현재 코드의 적용 제약

W13 `tools/w13_rtmpose_runner.py`는 기존 2,002개 RTMO 상자 목록을 입력 템플릿으로 사용하고, `frame_index/fps` 시각 일치를 검사한다. 공통 검증도 기존 영상의 133.654059초와 skip4에 고정돼 있다. 따라서 새 원본 경로만 바꿔 실행하는 방식은 지원하지 않는다.

후속 작업은 **기존 실행기를 보존한 별도 평가 실행기**에서 원본 프레임/PTS를 기준으로 새 사람·관절 관측을 만들고, 고정한 역할 정책을 적용한 뒤 위 자료를 출력하는 범위다. 모델 선택·모델 해시·추론 호출 수·시간/메모리/출력 상한이 고정되기 전에는 실행하지 않는다. 기존 한 영상에 대한 반복 실행 허용을 새 영상 실행 범위의 확정으로 간주하지 않았다.

## 파일 소유와 진행 상태

- W13: 새 원본의 포즈·추적·역할·메인 몸·구간과 출력 adapter. W13 격리 worktree 안의 새 실험 디렉터리를 소유한다.
- W14: 원본 준비, 얼굴 후보·특징·점수, 몸↔얼굴 연결과 멤버 매칭 평가. 기존 W14 파일은 읽기 전용으로 참조한다.
- 공통 얼굴 Python 파일은 수정하지 않았다. 양 세션이 같은 파일을 동시에 편집하지 않는다.
- 이번 자료 확인은 현재 65번 실험 결과를 바꾸지 않는다. 새 영상의 W13 결과는 아직 없고, 새 영상에 대한 사람 정답과 정확도도 아직 없다.
- 인계 메시지 수신만으로 다른 세션에 답장을 보낼 사용자 권한을 추정하지 않았다. 이 기록은 W13 측 확인 내용이며 W14에 메시지를 발송하지 않았다.
