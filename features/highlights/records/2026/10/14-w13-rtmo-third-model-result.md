# W13 — RTMO-s를 추가한 세 모델 비교 결과

확인일: 2026-10-14 KST

## 결론

사용자가 다른 모델도 비교하라고 요청해 **RTMO-s를 세 번째 자세 모델로 추가하고, 지정한 영상 전체를 실제로 한 번 분석했다.** MoveNet 512와 YOLO26s의 저장 결과에 같은 메인 선정·군무 판정 규칙을 적용해 비교했다.

이번 기본 설정에서는 RTMO-s가 기존 두 모델보다 전반적으로 낫다는 결과를 얻지 못했다. 메인이 있는 장면을 군무로 잘못 분류하는 비율은 오히려 조금 높았다. 따라서 **RTMO-s를 제품에 채택하지 않고, 기존 15번 실험 결과를 비교 기준으로 유지한다.** 15번 자체도 제품 적용 기준을 충족한 결과는 아니다.

이번 결과는 RTMO 계열 전체의 가능성을 부정하지 않는다. 하나의 모델 크기·검출 기준값·영상에서 고정된 후처리를 비교한 결과다. 얼굴 매칭은 이번 실험 범위에 포함하지 않았다.

## 무엇을 동일하게 비교했는가

원본 `yFTAYXDTjqI` 전체 0–133.654059초에서 4프레임마다 저장한 **2,002개 동일 시각**을 비교했다. 새 RTMO 추론은 1회이며, MoveNet과 YOLO는 이미 저장한 자세 데이터를 사용했다.

- 메인 점수, 역할 판정, 시간 안정화, 몸 위치 선택 설정: 15번 실험 설정 고정.
- 세 모델 모두 관절 신뢰도 0.3 이상을 사용. 정답표는 결과 채점에만 사용하고 예측에는 넣지 않음.
- 사용자 정답 21행을 유지. 단독 메인만 표시된 642관측과 군무만 표시된 407관측을 따로 채점.
- 메인/군무가 함께 표시된 556관측, 명시적 제외 388관측, 미표시 9관측도 분리. 미표시는 평가에서 건너뜀.
- 보조 몸 위치 정답 66장은 전체 영상의 사람 선택 정확도를 대표하지 않음.

**이전 YOLO 수치와의 차이:** 15번의 YOLO 저장 자료에는 관절 신뢰도가 없었다. 이번에는 20번에서 수집한 신뢰도가 있는 자료를 사용했다. 따라서 아래 YOLO 군무 회수율 89.4%와 짧은 구간 8개는 신뢰도 필터가 없는 옛 15번의 94.1%·14개와 구분해야 한다. 옛 15번 결과도 별도로 재현하고 보존했다.

## 실제 결과

| 지표 | MoveNet 512 | YOLO26s | RTMO-s |
|---|---:|---:|---:|
| 메인 장면을 군무로 오판 — 낮을수록 좋음 | 178/642 (27.7%) | 170/642 (26.5%) | 188/642 (29.3%) |
| 실제 군무를 군무로 판정 — 높을수록 좋음 | 384/407 (94.3%) | 364/407 (89.4%) | 383/407 (94.1%) |
| 보조 66장 중 단독 메인 위치 일치 | 63/66 | 61/66 | 61/66 |
| 보조 66장 중 정답 인물 검출 | 66/66 | 66/66 | 65/66 |
| 1초 미만으로 나뉜 구간 | 1개 | 8개 | 1개 |
| 경계 F1, 정답 경계 ±0.5초 | 0.296 | 0.200 | 0.148 |

세 모델 모두 현재 평가 목표인 메인→군무 오판 12% 이하를 충족하지 못했다. 짧은 구간이 적다고 정답 경계를 잘 찾은 것도 아니다.

13.2–15.2초에서 RTMO는 30관측 중 15개를 단독으로 남겼다. MoveNet은 모두 군무, YOLO는 29개를 군무로 판정했다. 다만 RTMO가 단독으로 남긴 모든 시점에서 올바른 사람을 선택했는지는 검증되지 않았다. **78.8–85.4초의 메인 누락은 세 모델 모두 99/99관측 군무로 남아 해결되지 않았다.**

RTMO는 명시적 제외 구간을 모두 역할 미정으로 남겼다. 이를 제외 장면을 이해하는 분류기가 완성됐다는 뜻으로 해석하지 않는다. 추적 번호 수나 평균 관절 신뢰도 역시 실제 추적·관절 정확도와 구분한다.

## 새로 확인한 구체적 원인

RTMO가 보조 정답 인물을 놓친 59.059초의 원시 출력을 확인했다. 해당 사람 위치에 모델 출력 상자가 있었으나 검출 점수 약 **0.497**이 고정 문턱 **0.7 초과**에 미달해 걸러졌다.

이 한 사례는 모델이 사람을 전혀 찾지 못한 경우와 검출 필터가 사람을 제거한 경우를 구분해야 함을 보여준다. 문턱을 내리면 다른 사람의 오검출도 늘 수 있으므로, 낮추는 것이 전체 품질을 개선한다는 결론은 아직 없다. 이번 비교 도중 기준값을 바꾸지는 않았다. 원시 출력을 저장해 추가 추론 없이 후속 대조할 수 있다.
