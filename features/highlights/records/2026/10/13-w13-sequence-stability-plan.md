# W13 — 역할·인물 선택의 시간적 일관성 개선

사용자 승인: “응 계속 진행해줘. 나 두시간 정도 다른 일 해야해서 최대한 많이 이어서 진행해줘.” 기존 1~2일 개선안의 bounded 후속이다. 별도 승인 대기 없이 안전한 실험·비교·노트북·검증을 이어간다. 제품/얼굴/새 모델/영상 추론/다운로드/과금/Build5/commit/push/merge/deploy는 범위 밖.

## 확인한 원인

13-d의 `unknown`에는 관측 부족과 점수 분포가 애매함이 섞여 있다. 후자는 사람이 보이는데도 즉시 상태를 초기화한다. 군무는 누적 확인을 거쳐야 하지만 단독 메인 복귀는 즉시여서, 작은 흔들림이 구간 경계로 늘어난다. 예를 들어 MoveNet39.1–49.8초는 raw group141/161관측인데 최종group116, unknown21, single24다. YOLO70–78.8초는 raw group126/132인데 최종group105, unknown26이다. 짧은 single A-B-A만 보정한13의 C2는 역할 변화가 섞인 조각에 적용되지 않았다.

## 선택한 접근

기존 모델·추적·메인 점수·13 raw 역할 근거를 고정한다. 영상 전체의 저장 관측을 받은 **오프라인 시간 경로 선택기**가 순간 근거의 불일치 비용과 상태 전환 비용을 함께 최소화한다. 상태는 group/unknown/single(track)/joint(track set). 몸이 없는 상태로 확정 메인을 만들지 않는다. 관측 부족·shot 변경·긴 시간 공백에서는 문맥을 끊는다. 단순 다수결은 실제 짧은 솔로를 없앨 수 있으므로 전환 비용0 기준과 여러 작은 비용을 함께 비교한다. 신경망 학습이나 새 모델은 사용하지 않는다.

대안1은 기존13의 연속 확인시간만 연장하는 것인데, 진입 지연/unknown 증가를 악화시킬 수 있어 기본 접근으로 선택하지 않았다. 대안2는 시간 창 다수결인데 트랙 가시성/관측 부족을 다루기 어려워 이번에는 제외한다.

## 작업과 검증

1. `tools/w13_sequence_policy.py`, `tests/test_w13_sequence_policy.py`: 약한 짧은 역할 튐/단독 인물 튐을 완화하고 지속·강한 전환은 보존; 공동 메인 유지; 가림/shot/gap/reset; 모든 메인 실제 bbox 확보; 시간 단위 비용; 입력 불변. RED→GREEN.
2. `tools/w13_sequence_experiment.py`: hash검증·설정 사전 고정, 새 출력에만 쓰기. 전환 비용 `[0,.1,.2,.4,.8,1.2]`초 × 애매한 관측의 비unknown 비용 `[.15,.35]` =12설정×2모델. 각120초/RSS2GiB, 전체15분/새출력100MiB. 전체 결과요약 보존, 전체프레임은 기준과 대표 후보만 저장. 모델추론0회.
3. 12번/13번/새14번 비교. 사용자GT main-only/group-only/overlap/exclude/unmarked 분리. 66개 보조 표본은 정확한단독/추가오선택/미선택을 모두 표시. 추가경계·짧은조각·unknown·제외오표시·군무F1을 함께 보고. 동일영상 조정치이며 독립 검증/전체 인물 정확도로 주장하지 않는다.
4. 자동 통과조건: main-only 군무오판≤12%, group-only찾기≥85%, 단독표본정답≥12번,1초미만조각≤12번,군무강제메인0. 미달이면 미채택. 가장 나은 후보 선정 규칙은 실행전 manifest에 기록한다. 필요시 원인을 분석한 별도revision만 허용; 무기록 sweep 금지.
5. 새14번 notebook 생성, 기존13·정답·앱 불변. 구간 경계와 영상 역할 표시 시점 일치(미래 관측 사용 금지), 직접비교·재생·드래그·예측/정답 이동 검증.
6. 전체pytest·독립리뷰·dated기록·W13·WORKBOARD 갱신. 잘못된 후보는 앱에 넣지 않는다. 초기 선택 비용이 실패하면 다른 근거를 최소변경으로 조사하되 최대3개가설까지 기록한다.

## 판정·제한

- 이미 한 영상으로 설계를 조정했으므로 새 독립 holdout인 것처럼 표현하지 않는다. GT시간·멤버 이름은 예측기에 입력하지 않는다.
- 78.8–85.4초는 두 모델 모두 raw군무 우세(71/99,77/99)라 시간적 안정화만으로 사용자메인정답을 복원하기 어려울 수 있다. 이를 다른구간의 성공으로 가리지 않는다.
- 컷은 저장된shot메타가 없으면 기본0이므로 실제방송컷 대응은 아직검증불가. 긴 누락/실제인가림 추적연결/얼굴/identity교대지연도 범위 밖.
- 실제 사용자 품질판정이 필요한 단계까지 최대한 진행한다. 단순 실행 완료를 정확도 개선 완료로 표현하지 않는다.
