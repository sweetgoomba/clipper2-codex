## 3. 보충 규칙 — 멤버 판정을 보기 전에 선택 고정

각 경로의 기존3개를 모두 보존했다. 실패 표본이나 다른 멤버를 확정한 표본도 교체하지 않는다.

1. 기존 선택법3가지(기존 시점/시간대별/간격 선택)를 각각 시작점으로 유지.
2. 저장된 native 얼굴 연결이 유효한 후보 중 기존4K crop 품질 점수가 높은 얼굴을 추가.
3. 기존 선택과0.25초 이상 떨어진 후보를 우선. 없으면 남은 후보 중 가장 먼 시점을 추가하고
   간격 완화를 기록.6개까지 채운 후 그대로 보존하며9개로 확대.
4. 모델의 후보 이름·거리·GT를 선택에 사용하지 않는다. 같은 선택 ID를 세 모델에 적용하며
   이름을 얻었다고 일찍 멈추지 않는다.
5. 기존 경로별 합의로 판정하고, 이미 저장된 전체238관측의 반대 이름 근거도 대조한다.
   제한된 선택의 전체 이름과 모순되는 확정 이름이 전체 자료에 있으면 채택 조건 실패다.

품질 점수는 **처음의 얼굴 위치를4K로 변환한 crop**에서 얻은 값이다. native YuNet으로
재검출한 위치에서 품질을 새로 계산한 시험은 아니다. 미검출이나 불확실한 얼굴 연결을
모델 실패와 섞지 않으며, 표본 선택은 새로운 배경 인물 숨김/필터 기능이 아니다.

5범위×3시작 선택법×4표본량(3/6/9/전체)×3모델=180비교.
같은‘전체’ 결과는 시작 선택법별로 반복되어 있으며 독립적인180개영상/정답이 아니다.

### 구체적으로 바뀐 근거

- **다니엘/SFace/시간대별:** 앞 경로3확정·뒤1확정으로 전체 보류 →
  6개씩 보충 후 앞6확정·뒤4확정으로 전체 다니엘.9개에서는9/7. 전체 관측에서는44/30.
- **민지/SFace/시간대별:** 민지1확정 →3확정(6표본) →5확정(9표본).
  Intel도6표본에서 민지 범위를 회복. 기존 정확한 얼굴GT8개는 민지지만 전체 구간의 독립 GT는 아님.
- **혜인/Aura:** 뒤 경로는6표본에서 혜인3확정으로 근거를 확보하지만 앞 경로는0으로
  전체 보류를 유지. SFace는3/6/9표본에서 양쪽 확정0이고 전체에서는 뒤 하니4/혜인2가 충돌한다.
- **해린으로 배정된 범위/SFace:**3/6/9모두 해린, 전체25관측은 해린13/하니1로 충돌.
  반대 판정은 `s0029-p0-f912`,15.2152초. 이 정확한 얼굴의 사용자GT 없음.
  SFace 거리 하니0.632708/해린0.805042, 차이0.172334로 기존 기준에서 하니를 확정했다.
  Aura와Intel은 이 얼굴을 보류했다. 서로 다른 모델의 점수를 직접 비교하거나 임베딩을 섞지 않았다.

6개에서9개로 늘리면 사용 표본은42→63(50%증가)이나 이5범위의 전체 배정 결과는 동일했다.
실제 모델 추론 시간을 측정한 비교는 아니다. 세 시작 선택법을 합해 추가 선택126개를 검산했고,
0.25초 간격 완화는6개 단계9건·9개 단계39건(시작 선택법 간 중복 포함)이다.
