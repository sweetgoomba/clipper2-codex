# 2026-10-14 W14 새 촬영 안무 영상의 구간 정답 준비

## 후속 판정: 단일 메인 구간 정답용 사용 중단

사용자가 지적한 대로 릴레이댄스는 앞사람이 물러나고 다음 사람이 앞으로 나오는 전환이 한 구간 안에 들어갈 수 있다. 구간 1(0.000–15.883초)도 사용자 관찰상 김채원 파트 뒤 카즈하 파트로 바뀐다. 저장된 옛 결과의 `person_id=김채원`은 그 구간 전체의 사람 정답이 아니다. 순차적으로 바뀌는 두 사람을 `공동 메인`으로 표시하는 것도 맞지 않는다. 현재 양식의 단일 이름 + `같은 메인인가요?`만으로는 전환 시점과 전후 정답을 표현할 수 없다.

선정 당시 기존 얼굴 모델 비교에 쓰지 않은 촬영 원본, 이미 있는 18구간·21참조, 재다운로드가 필요 없는 점을 우선했다. **구간 내 단일 메인 지속성·인물 분리·실제 얼굴 가시성을 먼저 검토하지 않은 선정 오류**다. 따라서 사용자에게 18개 라벨 입력·내보내기를 요청하지 않는다. 이 화면과 기존 구간은 재생·경계 실패를 살피는 자료로만 보존하고, 독립 얼굴 매칭 정확도 분모나 제품 교체 근거에 넣지 않는다. 새 시험은 일반 무대의 다른 촬영 영상에서 원본과 실제 W13 메인 몸/track을 고정하고, 구간 안에 메인 교체가 있으면 전환 경계를 나누거나 단일 메인 채점에서 제외한 뒤 시작한다. 새 영상·경계·정답·모델 결과는 아직 없다.

## 결론

기존 얼굴 모델 비교에 사용하지 않은 르세라핌 릴레이댄스 원본과 Clipper가 이미 만든 안무 구간 18개로 멤버 예측을 숨긴 화면을 준비했다. 당시에는 정답 입력을 요청할 계획이었으나 위 후속 판정으로 철회했다. 사용자의 새 정답은 없고, 모델 정확도나 제품 개선 결과도 없다. 제품 기본 YuNet + SFace, AuraFace 비교 후보, W13 소비 코드는 그대로다.

## 정확도 평가로 넘어가기 전 남은 것

1. **기존 18구간 라벨 요청은 취소했다.** 단일 메인 구간이 성립하는 새 입력을 고른 뒤, 전환 시점과 한 구간의 동일 메인 유지 여부를 먼저 확인해야 한다. `공동 메인`은 동시 공동 주연에만 쓰고 순차 전환의 대체 라벨로 쓰지 않는다.
2. 원본 해시와 구간 경계를 유지한 채 W13의 실제 메인 몸·track·시점 산출물을 별도로 확보해야 한다. 현재 저장 메타만으로는 W13이 선택한 몸과 수집한 얼굴의 연결이 맞았는지 채점할 수 없다. W13 소유 코드의 새 추론·adapter 변경은 이번 단계에서 실행하지 않았다.
3. 정답을 고정한 뒤 같은 참조 사진, 같은 몸 경로와 얼굴 관측, 모델별 올바른 전처리 및 **미리 고정한** 각 모델 기준으로 SFace 대조와 AuraFace를 평가한다. 안무 구간 누락·메인 몸 선택 오류·얼굴 연결 오류·얼굴 미검출·인식 거부·다른 멤버 오확정을 분리한다. SeetaFace6 일반형은 직전 사전 통과 기준에 실패했으므로 이 자료 하나에 맞춰 재조정하지 않는다.
4. 이 영상 1개와 480×854 입력만으로 제품 모델 교체를 결정하지 않는다. 사용자 정답 전에는 채점을 하지 않고, W13 최신 경로 및 Apple Silicon·Windows x64 설치 검증이 끝나기 전 제품 연결도 하지 않는다.
