## 기록 계약

1. 원본 관측 키는 모델 이름 + **저장 pose 파일 SHA** + 유도 프레임 번호 + 원본 사람 순번이다. weight hash로 가장하지 않는다. 프레임 번호는 저장 시각×fps로 유도하며 원본 PTS 검증 전이다.
2. 필터링 후 사람 순번을 원본 순번으로 착각하지 않도록 원본 객체를 대조한다. 정확히 하나 일치, 복수 일치, 같은 관절의 파생 상자, 미해결을 구별한다. 이번 실제 자료는 전부 원본과 정확히 일치했다.
3. 현재/이전 관측, 실제 시간차, 직접 비교/좌우 교환, 직접 공통 관절 수·교환 비교 가능 수·실제 사용 수, 유효성, 평균에 포함된 표본을 저장한다. 숫자를 원래 계산과 검산하지만 판정에 다시 입력하지 않는다.
4. 초기 움직임 0.67초, 공동 시작 참고 분기0.4초, 후보 보완 뒤 최근 움직임0.2초의 네 기록 흐름을 보존한다. 보조 모델 내부의 모든 계산을 기록한 것은 아니다.
5. 단계별 표는 **역할 판정이 연결한 상자**의 스냅샷이다. 최종 실제 관측 뷰는 따로 저장한다. 실제 몸을 투영하는 모든 중간 단계의 변경 원인까지 설명하지 않는다.
