## 실제 변경

- `evaluation/segment_review/owned_faces.py`: 저장된 MoveNet 관절 중 신뢰 가능한 코 위치와 YuNet 얼굴의 코 landmark를 비교한다. 선택 몸과 정확히 일치하는 pose의 머리를 사용하고, 다른 사람의 머리와 구별하기 어려우면 보류한다. 얼굴 검출 점수 최고값이나 참조 멤버 이름으로 얼굴을 고르지 않는다. 소비자 평가 adapter이며 public core API를 Dance 타입에 종속시키지 않았다.
- `owned_replay.py`: 같은20구간·몸 위치·240시점에서 연결한 얼굴을 각각 public `match_reference`에 전달하고 `combine_reference_matches`를 호출한다. 같은 멤버 지지2표본 이상, 다른 멤버 지지 없음일 때 이름을 부여한다. 충돌/부족/분석되지 않은 track은 확인 필요로 보존한다. 평균 특징 하나로 충돌을 숨기던 경로를 제거했다.
- 시점에서 선택 몸이 없거나 머리 근거가 약하면 최고 얼굴로 fallback하지 않는다. 얼굴 미검출과 몸/얼굴 연결 불확실은 별도 이유로 남긴다. 알고리즘의 `confirmed` 연결은 자동 기하 판정이며 독립 소유 정답을 뜻하지 않는다.
- 기존 결과를 보존하고 `segments-v2` 비교 화면을 추가했다. 앞선 비교/이번 수정 목록, 수정 전후 얼굴, 개별 표본 이름과5멤버 거리, 원본 seek를 표시한다. 기존 앱 분류는 별도 문맥으로 표시한다. 실제 앱/완료 프로젝트 결과는 수정하지 않았다.
