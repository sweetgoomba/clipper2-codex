## 코드와 판정 계약

새 `tools/w13_auxiliary_group_models.py`는37번 결과를 그대로 읽고 보조 자료만 계산한다. 모든 모델에 같은 움직임·메인 점수·원시 역할 규칙을 적용하되, 저장자료 생성 시 각 모델이 썼던 검출/NMS 조건은 그대로다. 순수한 모델 정확도 순위 비교가 아니다.

1. 원본 경로·fps·duration·관측 시각/개수가 같아야 한다. YOLO는 관절 신뢰도를 보존한 confidence-v1 자료, MoveNet은512 자료다.
2. 보조 계산이 군무이고 후보≥3, 유효 움직임 비율≥0.6, 최대 움직임≥0.03인 근거가 첫~마지막 관측 기준0.4초 이상 이어져야 한다.
3. 기존 공동 메인과1초 이상 단독 구간은 항상 보호한다. 최종 후보는 **현재 후보 수와 당시 점수 순위 후보 수가 모두1인 짧은 단독**만 재검토한다. 둘 중 하나가 여러 명이거나 순위가 없으면 변경을 막는다. 복원된 사람이 과거 순위표에 없을 수 있기 때문이다.
4. 보호 판단은 별도 마스크로 적용한다. 보조 모델의 실제 원시 근거는 수정하지 않고 저장한다. 보조 모델의 상자·추적번호를 메인 경로로 가져오지 않는다.
5. 군무 변경 시 메인 목록을 비우고 기존 구간 연결을 재계산한다. helper의 장면 번호·시간 공백 보호는 유지하되, 현 전처리가 장면번호0을 공급하므로 실제 컷 검증 완료를 뜻하지 않는다.
6. 예측 파일을 모두 저장한 뒤 정답·보조라벨을 읽는다. 특정 시각·멤버·정답표를 예측 규칙에 넣지 않는다.
