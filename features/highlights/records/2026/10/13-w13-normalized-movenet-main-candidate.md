## 가설과 한 단계씩 바꾼 조건

기존 `main_score`는 `0.45×중앙 + 0.35×상자 면적/화면 면적 + 0.20×관절 길이 합/300`이다. 22.49초 512 관측에서 `중앙`은 0.365~0.809, `상자 면적/화면 면적`은 0.038~0.070, `관절 길이/300`은 1.076~1.640이다. 따라서 **가중치만 보고 세 항목 영향이 비슷하다고 생각하면 틀린다.** 사람 크기 항목의 실제 기여는 약 0.013~0.025에 불과하다.

1. **점수 범위만 맞춤:** 각 프레임의 여러 사람 중 크기·관절 길이를 그 프레임 최대값으로 나눠 0~1 범위에 맞추고 가중치 0.45/0.35/0.20은 유지했다. 기존 메인 선택기의 전환 규칙을 그대로 쓴다.
2. **점수 범위+빠른 전환:** 위 조건에 현재 메인 대비 즉시 전환의 점수 문턱(`HARD_SWITCH_MARGIN`)만 0.16→0.05로 낮췄다. 기존 지속 후보 문턱·프레임 수, IoU 추적, 최소 구간/연결, **저장 그룹 플래그는 고정**했다. 노트북은 평가 중에만 기존 선택기에 계산된 점수를 주입하고 종료 시 원래 함수를 복원한다. 제품 파일 수정 없음.

조사자가 만든 원본 우선 위치 표본 18/17/20장은 **사용자의 21행 정답과 별개**이며 서로 일부 중복한다. 따라서 아래 위치 표본의 적중 수는 진단용이지 사용자 기준 최종 정확도가 아니다. 사용자 정답과 직접 비교한 값은 메인 연속 전환 **11개 시각**의 경계 적중이다(예측 경계 ±0.75초, 일대일 매칭). `큰 위치 점프`는 인접 분석 프레임의 선택 상자 중심 x가 250px보다 크게 변한 횟수로, 실제 인물 전환과 잘못된 흔들림을 함께 포함한다.

22.49초 사용자 정답 메인은 다니엘이다. 앞선 원본 검토에서 그 메인으로 본 노란 의상 사람은 x≈640이다. 기존 빨간 상자는 x≈1179의 파란 의상 사람을 골랐고, 512 평가 후보는 노란 의상 사람을 고른다. 59.99초에도 후보는 기존 노란 의상 사람에서 보라 의상 사람으로 바뀌지만, 해당 인물의 사용자 멤버 정답 대응은 이 정지화면만으로 확정하지 않는다. 64.93초에는 여전히 **메인 1명만** 내므로 사용자 정답의 복수 메인(다니엘+하니)을 충족하지 못한다.

85~102초의 추적도 완전히 해결되지 않았다. 후보는 86초 선택 ID 33, 95초 ID 37로 기존의 같은 번호 재사용 사례는 피한다. 그러나 후보의 정리 구간은 85.285~89.489, 89.489~93.894, 93.894~100.634초이고, 정답의 92.9초 메인 전환에 가장 가까운 경계는 **93.894초로 약 0.994초 늦다.** 즉 8/11 적중 외에도 개선된 전환은 있으나 목표 허용 0.75초를 넘는다. 최소 구간을 1.2→0.8초로 줄인 **추가 정적 계산**은 92.9초를 93.093초에 잡아 전체 10/11로 늘지만 예측 경계도 20→26개로 늘어 미채택이다.

후속 **일회성 민감도 계산**에서 즉시 전환 문턱을 0.05→0.07로만 바꾸면 사용자 경계 8→9/11, 예측 경계 20→21개, 큰 위치 점프 33→32회였다. 문턱 0.10은 큰 점프 21회로 줄지만 경계도 6/11로 떨어졌다. 이는 같은 원본에 대한 사후 탐색이며 별도 검증 영상이 아니므로 0.07을 새 최종 후보로 채택하지 않았다. 현재 0.05 후보의 점프 중 사용자 메인 전환 ±0.75초 밖이 24/33회(저장 현재 8/14회)다. 그룹·공동 메인에서 정당한 이동도 포함될 수 있어 오류 24회라고 단정하지 않고, 전체 비교 영상에서 사람이 검토해야 한다.

## 판정과 다음 단계

512의 `점수 범위+빠른 전환`은 **평가 후보로만 보존**한다. 사용자 경계 포착과 몇몇 사람이 바르게 선택된 화면은 개선됐지만, 큰 위치 점프 14→33회, 과잉 경계 16→20개, 복수 메인 누락, 92.9초 전환 지연이 남는다. 256에는 같은 조정을 적용할 근거가 없다. **전체 원본 비교 영상**에서 어느 교체가 맞고 어느 상자 이동이 잘못됐는지 사람의 판정이 필요하다. 그 판정을 바탕으로 여러 메인 허용 및 그룹 중첩을 개선하고 **전체 정답표와 완성 MP4**로 품질을 확인해야 제품 후보가 된다. 얼굴 이름 정확도는 별도 얼굴 작업에서 통합 검증한다. 기존 앱·설치본·사용자 프로젝트·W14 공통 파일 불변, commit/push/merge/deploy 없음.
