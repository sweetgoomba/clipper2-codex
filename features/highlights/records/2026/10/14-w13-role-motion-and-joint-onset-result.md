## 조사한 원인

메인/군무를 처음 구분할 때는 약0.67초의 움직임 평균을 사용하고, 뒤에서 단독 메인 몸을 다시 고를 때는0.2초 평균을 사용했다. 뒤의 단계는 역할을 고정하므로, 이미 군무가 된 장면은 짧은 움직임을 다시 계산해도 메인으로 돌아오지 않는다.

## B: 공동 메인 시작만 보완 — 개발 후보 유지

A를 검토한 뒤 후속 조건을 별도 manifest로 고정했다. **0.4초 결과 전체를 채택하지 않고**, 기존38번 공동 구간의 시작 직전만 검토한다.

1. 기존 결과에서 두 사람이 관측된 공동 구간이 있어야 한다.
2. 새 후보도 같은 시점에 두 사람을 공동으로 선택해야 하며, 같은 실제 상자로 참여자 번호를 대응시킨다.
3. 그 직전 최대0.5초에서 두 사람이 계속 실제 검출된 경우만 연결한다. 관측 간격은 최대0.15초다.
4. 기존 단독 메인·미정·제외, 알려진 장면 변경, 검출 공백은 건너뛰지 않는다.
5. 모든 새 관측은 기존 raw/lower pose 자료와 완전히 같아야 한다. 검출 점수0.3 이상·몸통 포함·두 사람 구분·인접 관절 거리의 기존 기준을 적용한다.
6. 기존 참여자 번호를 유지하고 새 시작 관측의 출처·대응·기준점을 별도 sidecar에 기록한다. 기존 sidecar와 원래 메인 행은 보존한다.
