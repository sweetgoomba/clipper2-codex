## W13 → W14 입력 연결 조건

현재 설치본은 사용자가 향후 사용하지 않기로 한 YOLOv8s pose를 사용한다. W13의 RTMPose 등 대체 경로는 평가 단계이며, 현재 runner는 이전 영상의 2,002개 관측·FPS와 정확히 일치해야만 실행되도록 작성되었다. 이전 결과 JSON이나 18구간을 새 영상에 재사용하거나, W14가 임의 몸 상자를 그려서 `W13 선택 메인`으로 부르지 않는다.

이 SHA의 새 영상에 대해 W13이 별도 격리 실행에서 다음을 고정해 전달해야 한다: 사용 모델 파일 SHA·코드/config SHA·런타임/OS/device·실행 상한과 기록; 원본 PTS 기준 표본 시각; 프레임별 유효 person bbox/track ID와 선택한 메인 bbox/track ID; 단독/동시 공동/메인 없음/불확실 역할; 실제 구간 시작·끝과 전환 경계. 얼굴 인식에서 알게 된 멤버 이름을 메인 선택에 되먹이지 않는다. 연속된 한 구간 안에서 메인이 바뀌면 경계를 나누거나 해당 구간을 단일 메인 얼굴 매칭 채점에서 제외한다. 순차 전환을 공동 메인으로 표기하지 않는다.

W14는 동일한 W13 메인 경로와 원본 픽셀에서 얼굴 검출·몸↔얼굴 연결 실패를 먼저 구분하고, 동일 얼굴 관측/참조를 고정해 기존 YuNet+SFace와 후보 인식기를 비교한다. 별도 정답 검토에서는 W13이 선택한 몸과 실제 사람, 얼굴 식별 가능 여부, 등록 외 사람/군무/전환을 분리한다. 사용자에게 현재 새 구간 정답 입력을 요청하지 않는다.
