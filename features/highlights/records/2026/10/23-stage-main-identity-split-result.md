# 무대 하이라이트: 메인 인물 교대 분할 검증

2026-10-23. 사용자가 클립 도중 메인 인물이 바뀔 때 구간을 나누는 변경을 승인했다. 기존 프로젝트·수동 수정·실행 중 앱을 건드리지 않고, 통합 worktree에서 신규 분석 코드와 별도 빌드를 준비했다.

## 적용한 내용

- 기존 12개 표본과 track 평균은 그대로 유지했다. 기존 이름 판정 입력이 달라지지 않았음을 실제 영상 재추출로 확인했다.
- 이미 계산하는 pose의 코·눈·귀 좌표와 측정 confidence를 보존한다. 같은 프레임의 몸과 머리 점을 대조해 그 몸에 속한 얼굴만 추가 증거로 사용한다. 다른 몸의 머리 점이 겹치거나 몸을 하나로 특정할 수 없으면 사용하지 않는다.
- 약 0.2초 간격의 얼굴 증거를 추가로 보존한다. 새로 YOLO를 한 번 더 돌리는 방식은 아니다.
- 기존 미확인 구간에서 반복되는 얼굴 변화와 얼굴 위치/크기 변화가 함께 확인되면 교대 후보를 찾는다. 한 사람으로 직접 확인되는 증거, 단발성 이상 벡터, 조명 변화만으로는 분할하지 않는다.
- 나뉜 각 조각의 얼굴을 등록 사진에 독립적으로 비교한다. 다른 이름의 증거가 충돌하거나, 뚜렷한 얼굴과 시간 범위의 지지가 부족하면 미확인으로 남긴다. 적어도 한 조각에 이름을 붙일 수 있을 때만 분할을 적용한다.
- 확인된 교대의 좁은 시간 범위에서 실제 프레임 변화를 다시 찾아 경계를 조정한다. 변경된 다섯 조각은 정확한 시점으로 재인코딩한다.
- 기존 이름이 붙은 구간과 그룹 수신자 판정은 기존 입력을 유지한다. 새 이름을 그룹 구간이나 다른 미확인 구간에 전파하지 않는다.
- 새 분석마다 원본/모델/실행 코드 해시, 얼굴 관측 실패, 선택 근거, 분할 이력을 로컬 진단 파일로 남긴다.

## 한계와 제외한 실험

미확인 문제는 여전히 많이 남아 있다. 전 구간을 새 얼굴 방식으로 교체하거나, 참고 사진을 각각 비교하는 방식, 이미 이름 붙은 구간을 새 기준점으로 삼는 방식은 고정 입력에서 기존 결과를 손상시키거나 충분한 개선이 없어 기본 정책에 적용하지 않았다.

기존에 이미 이름을 받은 클립 안의 인물 교대는 이번 보수적 적용 대상에서 제외했다. 기존 등록 사진 라벨의 정확성도 자동으로 보증하지 않는다. 이번 비교는 저장된 몸 범위와 CPU로 보충한 pose 머리 증거를 사용한 오프라인 재생이며, 새 앱에서 처음부터 새 프로젝트를 생성하는 GUI 분석은 아직 실행하지 않았다.
