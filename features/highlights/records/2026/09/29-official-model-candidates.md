조사 기준: **2026-09-29 (Asia/Seoul)**. 로컬 소스·manifest·pyproject·uv.lock과 제작자의 공식 docs/repo/paper/model card만 읽었다. 제품 코드는 수정하지 않았고, 설치·모델 다운로드·ML 실행·모델 API 호출·git fetch는 하지 않았다. 아래 버전은 **lock 또는 설정의 값**이며 실제 설치된 런타임을 확인한 결과가 아니다. 공식 문서에 실린 성능도 우리 한국어 영상의 정확도·처리 시간으로 환산하지 않았다. ## 4. 얼굴 모델의 상업 사용과 최신 파일 의미

현행 두 weights의 상업 사용 근거는 상위 OpenCV repo의 일반 라이선스를 추정한 것이 아니다. [YuNet 공식 디렉터리](https://raw.githubusercontent.com/opencv/opencv_zoo/main/models/face_detection_yunet/README.md)는 **그 디렉터리의 모든 파일 MIT**, [SFace 공식 디렉터리](https://raw.githubusercontent.com/opencv/opencv_zoo/main/models/face_recognition_sface/README.md)는 **모든 파일 Apache-2.0**를 명시한다. 이에 따라 attribution/notice 등 라이선스 조건을 지키는 상용 사용 근거가 있다.

YuNet의 최신 기본 파일 `face_detection_yunet_2026may.onnx`는 기존 2023mar weights를 symbolic H/W로 재export한 파일이다. 공식 README는 OpenCV 5.x ONNX Runtime engine 용도로 설명하므로 **새 학습 모델·정확도 향상으로 계산하지 않는다**. 현행 OpenCV 4 계열 파일은 의미가 있는 호환 대조군이다. SFace int8/int8bq 역시 기존 파일의 양자화이며 새 recognition 학습 성능을 뜻하지 않는다. InsightFace의 모델 명칭·ArcFace loss·코드 MIT로 이 권리 근거를 대체해서는 안 된다. [InsightFace 공식 제한](https://github.com/deepinsight/insightface)과 실제 공급 계약을 weight별로 구분해야 한다.

## 5. 데스크톱 제약과 공식 문서의 빈틈

1. **Mac arm64:** pose는 현재 MPS 선택 코드가 있다. CTranslate2 STT는 CPU 경로이고 MPS 요청도 CPU int8로 돌아간다. Face의 현행 OpenCV 경로도 CPU다. InsightFace CoreML과 Paddle ONNX/Paddle CPU를 MPS 지원으로 합쳐 쓰면 안 된다. Qwen3-ASR와 WhisperX의 전체 MPS 동작은 공식 자료로 확정하지 않았다.
2. **Windows x64:** CTranslate2 CPU/CUDA wheel과 Visual C++ runtime 요구는 [공식 설치 문서](https://opennmt.net/CTranslate2/installation.html) 근거가 있다. InsightFace CUDA는 `onnxruntime-gpu` provider 선택이 필요하며 현재 CPU onnxruntime lock만으로 충족되지 않는다. ByteTrack/BoT-SORT의 원 연구 repo Linux 환경 성공을 Windows packaging 증거로 바꾸지 않는다.
3. **CUDA 라이브러리:** [faster-whisper README](https://github.com/SYSTRAN/faster-whisper)는 CUDA 12 cuBLAS/cuDNN 9를 안내하지만 [CT2 설치 문서](https://opennmt.net/CTranslate2/installation.html)의 cuDNN 설명과 다르고, [CT2 v4.6.3 release](https://github.com/OpenNMT/CTranslate2/releases)는 2026-01-06 pure-CUDA Conv1d로 cuDNN을 optional로 만들었다고 알린다. 현재 lock 4.7.1/후보 4.8.2에 필요한 라이브러리는 선택 build와 실제 로딩으로 검증해야 하며 오래된 문구 하나로 강제 의존성을 확정하지 않는다.
4. **자원 선언은 입장 조건:** dialog VRAM 4 GiB에 turbo·alignment·OpenCLIP이 겹칠 때의 peak RSS/VRAM을 확인한 자료가 없다. GPU가 실패해 CPU fallback되면 오류가 아니라 처리 지연으로 나타날 수 있다. 공식 모델의 parameter count만으로 자원 선언을 충족한다고 승인하지 않는다.
5. **LLM 교체는 env 이상의 차이:** [reasoning-model.ts](/Users/jina/project/adlight/web/clipper_web_api/src/shared/llm/reasoning-model.ts:14)의 prefix gate, 일반/HIGH/title-repair effort, output cap·JSON contract·timeout·usage 집계를 함께 검토해야 GPT-6 Luna와 현행 모델의 공정한 비교가 된다.

## 7. Gemini는 별도 경로의 참고 자료

[Google 공식 모델 목록](https://ai.google.dev/gemini-api/docs/models)에서 조사 때 확인한 stable 모델은 Gemini 3.8 Flash / 3.7 Flash / 3.6 Flash / 3.5 Flash-Lite이며 목록 마지막 갱신은 **2026-09-24**였다. [공식 changelog](https://ai.google.dev/gemini-api/docs/changelog)는 **Gemini 3.8 Flash GA 2026-09-02**를 명시한다. 따라서 3.8 Flash는 현행 shortform-director의 [3.6 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.6-flash)와 비교할 참고 최신 stable이지, 대사 title 서비스가 이미 사용 중인 최신 모델은 아니다. [3.8 모델 상세](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash).

[현재 Gemini 가격](https://ai.google.dev/gemini-api/docs/pricing)은 3.6/3.7/3.8 Flash Standard text/image/video **$0.75 input / $3.75 output per 1M tokens (thinking 포함), 2026-12-31까지**로 표시한다. **2027-01-01부터 $1.50/$7.50는 미래 요금 일정**으로 현행 비용 비교에 적용하지 않았다. 서비스 이용 조건은 [Gemini API terms](https://ai.google.dev/gemini-api/terms); 공개 local weights 라이선스가 아니다. 실제 shortform-director 가격 캐시·provider billing과 일치 여부는 이번 제품 수정 범위가 아니며 대사의 GPT-5 mini 비용에 섞지 않는다.

YOLO27 coming-soon, 2027년 legacy API 종료/Google 요금 일정은 미래 사실로 구분했다. 조사일 이후의 확정 출시를 현재 사용 가능한 모델로 채택한 항목은 없다. 날짜가 없는 model card나 GitHub UI의 연도 생략은 임의로 최신 출시일을 만들어 보완하지 않았다.

## 8. W12 비교 우선순위

- **댄스:** YOLO26 n/s-pose와 ByteTrack을 기존 pose/IoU 대조군과 비교하는 것이 변경 경로가 가장 직접적이다. BoT-SORT는 카메라 이동/ID 유지의 문제가 확인된 자료에 한정한다. YuNet/SFace는 상업 weight 권리가 명시된 얼굴 대조군으로 유지하고 InsightFace는 상용 weight 허가·가격 확보 후 검토한다.
- **대사 STT:** 현재 small을 유지한 대조와 turbo를 먼저 검토한다. 한국어 신규 모델 Qwen3-ASR-0.6B는 별도 adapter 실험 후보이며, WhisperX는 실제 단어 boundary 문제가 확인된 경우의 alignment 후보다. API STT는 word timestamps 계약과 업로드/비용이 해결되는 경우에만 비교 대상이 된다.
- **OCR:** EasyOCR의 현재 disabled/dependency gap을 해결해야 모델 비교의 출발선이 생긴다. 한국어 후보는 PP-OCRv5 mobile det + Korean rec로 고정하며 PP-OCRv6 최신 버전만으로 한국어 지원을 추정하지 않는다.
- **title/선별:** GPT-5 mini를 실제 기준선으로, GPT-6 Luna를 비용·품질 대조 후보로 삼는다. effort/gate/output cap이 다른 채로 단가만 비교하지 않는다. Gemini 3.8 Flash는 별도 shortform-director 참고로 남긴다.

이 우선순위는 공식 정보와 현행 호출 경로에 기초한 조사 판단이다. 모델 선정·다운로드·실행 승인, 실제 정확도/처리 시간/작업당 비용 측정 결과를 대신하지 않는다.
