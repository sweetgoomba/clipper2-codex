# 사용자 두 사례 교정과 판정 지도 복구

1. 실제 출력·동결 관측·원본 프레임으로 두 원인을 재현한다.
2. 이름 변경의 좌우 지원 창이 카메라 컷을 넘지 않게 한다. 알려진 컷의 경계만 사용하고 임의 길이 하한을 만들지 않는다. 반복 이름·정상 짧은 교대는 보존한다.
3. 얼굴+몸통 크기 우선권이 안무 자세 변화로 기존 중앙 주체를 덮는 조건을 좁힌다. 기존 앞줄 멤버 정답·실제 교대 반례를 함께 검증한다.
4. 판정 지도 기존 진입을 복구하고 화면 전환을 검증한다. 교정은 원본 결과와 별도 저장 정책을 유지한다.
5. 독립 검토·Dance 회귀·동일 세 영상 동결 자료 비교 후 원본 앱을 빌드·실행한다. 새 영상 전체 실행과 동결 비교는 구분해 보고한다. SAM OFF, Person 불변, 단체 탈락→메인 보류.
