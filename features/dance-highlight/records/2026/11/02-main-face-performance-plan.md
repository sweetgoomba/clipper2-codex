# 안무 메인 판정·얼굴 처리 성능 및 SAM 없는 구간 연결 개선

> Execution: superpowers:executing-plans, inline. 사용자가 현재 수정과 재검증을 직접 요청했고 원본 저장소 선호가 유지된다. 재승인·새 워크트리·커밋 없이 이어간다.

**Goal:** SAM을 비활성화한 채 메인/얼굴 처리 시간을 줄이고, 근거가 남아 있는 미확인 사이의 연속 멤버 구간을 복원한다.
**Architecture:** 모델·해상도·관측 간격·얼굴 임계값을 유지한다. 안무 프로세스에서 OpenCV CPU 병렬도를 복원하고, 꺼진 SAM만 소비하던 context 얼굴 추출을 제거하면서 장면 경계 정보는 보존한다. 기존 얼굴 공백 연결에 이미 측정된 포즈의 양방향 유일 대응을 보조 근거로 추가한다. 새 몸 추적 모델이나 SAM 호출은 추가하지 않는다.
**Tech Stack:** Python 3.11, OpenCV, 기존 YOLO/AuraFace/SFace, macOS arm64 패키지.
**Spec:** 현재 사용자 요청 및 [직전 실제 앱 결과](02-mask-cost-reduction-results.md).

## Constraints
- 인물 하이라이트와 공유 SDK/얼굴 코어 제품 소스 변경 금지. 기존 GPU 작업 및 SAM 비활성화 보존. Windows도 같은 CPU 설정 정책을 사용하되 Windows 실측으로 주장하지 않는다.
- 클립 길이 제한, 이름 강제 채우기, 영상명/멤버명/시각 하드코딩 금지. 같은 인물의 연속 장면은 보존하고 메인 교대는 합치지 않는다.
- 기준은 SAM 비활성화 앱 1793571868350 / 1793571915955 / 1793571975392. 기존 YouTube URL과 대표 이미지·모델·원본 동일 조건으로 최종 앱 실측한다. 크레딧 무제한 사용 및 로그인은 이미 승인됐다.

## Review focus
- OpenCV 설정이 안무 프로세스 외부에 적용되지 않고 저사양 CPU에서 과도한 스레드를 만들지 않는가.
- context 얼굴 제거 후 source cuts/camera transitions와 기존 장면 경계가 누락되지 않는가.
- 이미 계산된 포즈 대응을 재사용할 때 실제 메인 교대, 겹친 몸, 누락 관측을 잘못 이어붙이지 않는가.
- 약한 얼굴과 다른 이름의 유효 얼굴을 구별하고, 새 연결을 또 다른 연결의 이름 근거로 사용하지 않는가.
- 최종 시간은 실제 패키지 기준이며 테스트/독립 프로파일 시간을 앱 시간으로 제시하지 않는가.
