# 안무 메인 판정·얼굴 처리 성능 개선 및 SAM 없는 구간 복원

2026-11-02 · 원본 저장소 · `fix/dance-gpu-performance-20261102` · macOS arm64 local-API

몸 추적(SAM)을 계속 끈 상태에서 세 영상의 실제 앱 총 분석 시간이 **39분 05초 → 27분 53초(28.6% 단축)**됐다. 기존 확정 분류를 다른 이름으로 바꾼 시간은 0초다. 다만 품질 복원 효과는 NEON 미확인 .166933초를 기존 시리 클립에 연결한 1건이며, Made My Night/ANTIFRAGILE의 미확인·짧은 클립은 그대로다. **미확인과 구간 분절이 충분히 해결됐다고 주장하지 않는다.**

## 실제 앱 실행 시간

| 영상 | 직전 SAM-off 앱 | 이번 앱 | 단축 |
|---|---:|---:|---:|
| Made My Night | 10분 03초 | 7분 21초 | 26.9% |
| ANTIFRAGILE | 13분 55초 | 9분 46초 | 29.8% |
| NEON | 15분 08초 | 10분 46초 | 28.8% |

실제 앱 작업 시작부터 프로젝트 완료까지이며 큐 대기 제외. 동일 Mac에서 버전별 각 1회 순차 측정이다. 반복 통계/다른 기기 보장은 아니다. 최종 실행 동안 별도 모델 실험·테스트는 하지 않았다. 단순 파일/진단 조회는 수행했다. NEON이 여전히 10분 46초여서 서비스 목표에 충분하다고 보지 않는다.

보조 얼굴 검증은 cluster_map 내부이고 원경/장면 확인은 segment_build 내부다. 내부 시간을 전체 단계와 중복 합산하지 않는다. 사용되지 않는 context 얼굴 추출은 약.0005초의 원본 컷 목록 수집만 남았다. 기존 가벼운 포즈/색상 공백 검증은 .48/.62/1.00초다. 이는 비활성화한 SAM 추적과 다른 처리다.

1초 미만 개수는 개인·미확인·단체를 포함한 모든 저장 클립 기준. 임의 최소/최대 길이로 강제 분할·병합하지 않았다.

- Made My Night 89개와 ANTIFRAGILE 134개 클립의 이름·시작·끝 및 썸네일 바이트가 모두 기준과 같다.
- NEON은 `[201.0008,201.167733) 미확인`과 `[201.167733,201.834867) 시리`를 `[201.0008,201.834867) 시리`로 연결했다. 기존 이름이 다른 이름으로 바뀐 구간은 없다. 이 복원은 모델 근거 검증 결과이며 해당 0.167초에 대한 별도 사용자 정답 판정은 받지 않았다.
- 세 영상 9,266개 메인 판정 프레임이 전부 동일하다. 원본/모델/설정 해시, 대표 이미지 선택·바이트도 동일하다.
- 사용자 검토 14구간은 기준 결과와 완전히 같다. 이전 SAM-off에서 남아 있던 오분류/미확인이 해결됐다는 의미가 아니다. 특히 MMN37.738–39.339 사쿠라, ANT4.571–6.139 홍은채 등 기존 문제는 남는다.
- SAM 두 경로 모두 reason=disabled_runtime_cost,0초·시도0·모델미초기화 확인.


## 원인과 적용

YOLO의 Ultralytics import가 OpenCV 병렬 처리를 끄고 있었다. 포즈 모델은 이미 MPS를 쓰고 있었지만 메인 판정에서 반복 호출하는 YuNet과 보조 얼굴 인식 SFace는 CPU 직렬 상태였다. 안무 플러그인 모델 로드 후 OpenCV 병렬 설정을 복원했다. macOS GCD는 OS 기본 pool(-1), 다른 backend는 CPU 수 이내 최대4를 요청한다. GCD getNumThreads=10은 pool 보고값이며 4개 제한을 의미하지 않는다.

대표 실제 프레임30개·얼굴75개에서 검출/특징 배열이 비트 단위로 일치했다. YuNet 1.942–2.109초→.777초, SFace .985–1.044초→.441초. 이는 모델 부분 실험이며 앱 전체 시간과 구별한다. 기존 모델, 해상도, 프레임 간격, 얼굴 판정 임계값은 바꾸지 않았다.

동일 입력 캐시의 키는 모든 픽셀·shape·dtype·input size를 그대로 검사하되, BLAKE2b의 byte 복사 대신 SHA256 연속 버퍼를 사용한다. 키 생성의 1080p 실측4.93ms→1.93ms, ROI .679ms→.307ms. 화질 축소나 픽셀 부분 검사는 하지 않는다.

꺼진 SAM만 소비하던 context 얼굴 추출을 제거하고, 후속 장면 구성에 필요한 원본 컷·카메라 전환 정보 수집은 별도 함수로 보존했다. 기존 inventory의 경로·FPS·완전성 검증도 유지했다.

## 미확인·짧은 클립

기존 색상 기반 얼굴 공백 검증에 이미 계산된 포즈의 양방향 유일 대응을 보조적으로 허용했다. 경쟁 인물·부분 포즈·다른 얼굴·원본 컷은 여전히 거절한다. 별도 추적 모델은 호출하지 않는다. 세 기준 영상에서 이 변경 단독 복원은0으로 확인됐다.

인접한 개인 구간에 있던 원래 얼굴 근거가 잘린 미확인 구간 밖에 있다는 이유만으로 버려지는 경우를 보완했다. 최종 개인/단체 구간 확정 뒤, 실제 얼굴 근거가 있는 미확인 가장자리에 대해서만 이웃의 최대 0.6초 고정 얼굴 관측을 함께 검토한다. 각 새 이름은 같은 이름의 독립된 원래 얼굴 2개와 거리·시간 조건을 만족해야 한다. 원래 클립 이름 자체는 얼굴표로 세지 않는다. 새로 복원한 이름을 다음 복원의 근거로 전파하지 않는다.

최종 메인 교대·얼굴 일관성 규칙으로 실제 병합을 실행한 뒤, 모든 복원 조각이 같은 멤버의 원래 개인 클립을 확장했을 때만 적용한다. 하나라도 따로 남으면 해당 실행의 복원 전체를 원래 출력으로 되돌린다. 단체 구간을 덮거나 새로운 짧은 개인 조각을 만들지 않는다. 고정 길이 분할 제한을 추가하지 않았다.

## 철회한 시도

- 전체 화면의 기존 얼굴 검출을 ROI보다 먼저 재사용한 후보는 속도가 빨랐지만 원래 이름·미확인을 악화시켜 제외했다.
- ROI/회전 검출 실패 때만 전체 화면 검출을 쓰는 후보도 기존 영상 내 얼굴 anchors를 바꿔 ANT 홍은채.533867초를 미확인으로 만들었다. 이 경로 및 관련 제품 코드는 완전히 제거하고 작업 시작 사본의 얼굴 추출을 복원했다.
- 최종 단체 구간 투영 전에 이름 가장자리를 복원한 후보는 ANT에.166733초 허윤진 고립 조각을 만들었다. 복원 시점을 최종 출력 뒤로 옮기고 실제 병합 성공까지 적용 조건으로 삼았다.
- 원본 시각의 밝기 변화에 대한 global guard를 local median으로 완화하는 실험은 짧은 삽입 편집 반례가 있어 철회했다.
- 전체 timeline에 보조 이름을 다시 넣는 실험은 이미 확정된 이름까지 변경하여 미채택했다.

후보들의 빠른 시간은 최종 결과의 성능 수치로 사용하지 않는다. 기존 프로젝트 및 후보 결과는 보존한다. 실행 중 후보 NEON 취소는 자동 승인 검토가 거절하여 완료까지 기다렸고, 우회 종료하지 않았다.

## 검증 범위

- 관련 안무·인물 1,191개 테스트 통과(48.99초). 마지막 테스트 강화 후 해당 73개도 통과(2.94초). 모든 저장소의 전체 테스트를 통과했다는 뜻은 아니다.
- 독립 코드 검토에서 경쟁자의 불완전 포즈, 단일 잘못된 보조 이름, 병합이 거절되는 고립 조각 반례를 반영했다. 최종 Critical/Important 추가 없음.
- 인물 하이라이트, 공유 얼굴 코어, 공유 SDK 제품 소스 변경 없음. OpenCV 설정은 별도 안무 프로세스에만 적용한다.
- `recover_mask_names` 및 SAM 이름 재검증 호출은 계속 주석 상태이며 추가 SAM 모델은 초기화하지 않는다. 기본 포즈·얼굴 관측과 기존의 가벼운 공백 검증은 유지한다.
- Windows CUDA/DirectML 분기와 CPU fallback 보존. CPU 병렬 정책도 Windows에 적용되지만 실제 Windows 하드웨어 성능은 미검증이다.
- 원본 sibling 저장소에서 Node24.19.0으로 `npm run build:app:mac:arm64:local-api` 성공. 안무 Python 51개 파일 소스/패키지 SHA256 일치.
- 실제 앱 UI에서 기존 세 YouTube URL 제출, 같은 저장 대표 이미지 사용. 앱 정상 다운로드 캐시가 있어 신규 YouTube 전송 시간을 비교하는 실험은 아니다.
- 커밋·푸시·dev 병합 없음.

## 남은 과제

미확인 0초나 짧은 클립의 일괄 합치기를 목표로 하지 않는다. 메인 구도 선택이 잘못된 경우, 선택된 사람의 얼굴이 실제로 없는 경우, 카메라 편집으로 동일 인물 근거가 끊기는 경우는 이번 조건만으로 해결되지 않는다. 이전 사용자 판정14구간과의 일치 여부를 별도 표로 유지해야 한다. 기준 결과와 같다는 사실만으로 원래 분류가 올바르다고 주장하지 않는다.
