# 안무 품질 개선의 dev 반영과 통합 앱 검증

2026-11-04 KST. 사용자 지시에 따라 별도 기준 앱 비교를 정리하고, 이미 dev에 반영된 공통 GPU·ONNX 구조 위에 검증된 안무 변경을 먼저 병합했다. **GPU 공통 코드가 누락된 상태가 아니었다.** 관측된 CPU 전환은 별도 실행 문제이며 이번 작업에서 공통 가속을 추가 개발하거나 교체하지 않는다.

## 반영 범위

- 이름 증거 구간과 최종 메인 파트 조립을 분리하고 중복 교대 경계·컷 바깥 이름 padding·제외 구간 이름 상속을 방지한다. 실제 교대와 미지원 구간은 보존한다.
- 얼굴이 검출되지 않은 경쟁 몸도 메인 비교에 남긴다. 반복·장식물 오검출과 기존 메인 맥락을 다루는 관측 보호를 유지한다.
- 단체 확대 문턱에서 생기던 가짜 개인 조각은 원본 컷·완전한 동일 구도·역할 증거와 **확대 방향**이 함께 확인되는 경우만 이어 붙인다. 축소/정지 구도까지 확대 적용하지 않는다.
- 다중 컷 사이에서 서로 다른 독립 이름 run이 확인된 경우, 그 bridge 안의 기존 raw 얼굴 교대 경계가 소실되지 않도록 한다. 이름을 강제로 확장하지 않는다.
- 검증된 suffix만 복원하고 미지원 prefix는 미확인으로 남긴다. 짧다는 이유의 삭제·강제 이름 부여·고정3초 제한을 추가하지 않는다.
- 정확히 같은 입력의 캐시·원본 프레임 재사용·얼굴 검출 프리패치를 유지한다. GPU 제공자 선택은 기존 공통 승인 경로에 위임한다. CPU 기준 경로와 전체 작업 복구를 보존한다.
- SAM/mask/joint 몸 추적 호출은 비활성화 상태로 유지하고 기존 구현은 남긴다. 사용하지 않는 SAM 내부 최적화6파일은 이번 병합에서 제외했다.
- 판정 지도는 개발자 검토와 별도 교정본 저장 용도로 복구했다. 자동 결과와 교정본을 합치지 않는다.

독립 검토에서 발견한 shared BackendFailure/Cancelled/CleanupIncomplete 전파와 source-routing 변경 시 검출 캐시 무효화도 안무 소비자 안에서 검증했다. 공통·인물 코드는 변경하지 않았다.

## 보존·제외

기존 미커밋112파일은 해시 사본과 Git stash로 보존했다. 중복된 legacy GPU 제공자 선택·세션별 CPU 복구는 이식하지 않았고, 의존성 변경과 이미 dev에서 해결된 Nest 이용권 호환 변경도 제외했다. 생성 CoreML 캐시38개(약572MiB)는 커밋에 넣지 않았다.

이전 기준 비교 중 첫 MMN만 완료됐고, ANT 부분 실행과 대기 NEON·MMN 반복은 사용자의 순서 변경에 따라 UI에서 취소했다. 기존 프로젝트·교정본은 삭제하지 않았다. 이 중단 자료를 완성된 세 영상 A/B로 제시하지 않는다.

### 실제 가속 경로와 한계

세 영상 모두 공통 MPS 시도 후 `backend_unavailable`로 CPU 재분석됐다. 최종 YOLO `torch_cpu`, AuraFace `CPUExecutionProvider`, YuNet `opencv_cpu`다. GPU·ONNX 코드가 빌드에서 빠진 것이 아니며, 이 결과는 GPU 실행 성공이나 GPU 속도 성과를 증명하지 않는다. 최초 실패의 구체 원인은 이번 작업에서 확정하지 않았다. 사용자의 범위 변경에 따라 공통 가속 추가 수정·우회·GPU 진단 반복은 중단했다.

세 영상의 실행 모듈50개씩은 현재 dev와 모두 일치하고, 대표 이미지 선택·바이트도 비교 자료와 같다. 원본 영상 SHA256은 최종 검증 JSON에 남겼다. SAM/mask/joint 복구는 세 영상 모두 비활성화 정책과 복원·교정0을 확인했다. 기존 관측 좌표에 기반한 가벼운 연속성 처리는 남아 있으며, 고비용 SAM 몸 추적을 다시 켜지 않았다. 공통 가속·Person 소스의 무변경은 원격 병합 증거로 별도 확인한다.

판정 지도를 실제 앱에서 열고 50.577초 단체/51.077초 허윤진/102.943초 홍은채 분류 및 일시정지 키 이동을 확인했다. ANT9.902초 김채원도 원본 화면·얼굴 박스를 확인했다. NEON 결과 목록에 오래된 진행 상태가 남아 있어 Cmd+R로 새로고침한 뒤 신규 완료 프로젝트ID를 확인했다. 새 교정본이나 자동 결과 수정은 저장하지 않았다. 앱은 최종 dev 빌드의 NEON 판정 지도184.128초에 멈춰 열어두었다.
