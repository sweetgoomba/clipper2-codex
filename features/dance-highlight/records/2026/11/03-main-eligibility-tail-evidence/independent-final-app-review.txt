최종 판정: 전역 무퇴행 승인 불가. 의도한 경계 회귀 복구와 ANT의 검증된 부분 복원은 실제 앱에서 확인했다. 동시에 ANT171초대의 미확인 이름 확장, MMN41/118초대 역할 변화, 기존 미해결 기준과 실행시간 증가가 남아 있다. 최종본에는 ANT 교정 외에도 MMN·NEON의 이름·구간 변화가 있으므로 ‘ANT 경계만 바뀌었고 나머지는 전부 동일’이라고 보고할 수 없다.

최종 검토는 저장 JSON, JPEG, 소스·설치 파일 해시를 읽었다. 최종 3개 작업 중 모델 추론·pytest·전체 영상 재분석을 추가하지 않았다. 빌드 전 독립 ANT 제한 검증은 원본49프레임만 읽었고 모델 추론은0회였다. 앱UI 판정지도 확인은 부모 세션에서 별도로 진행했다.

MMN50초대의 잘못된 짧은 main은 group50.2502–50.8341167로 정리되고 컷 이후 허윤진으로 이어진다. 103초대는 홍은채97.7978–104.0205833으로 이어진다. 후반 회귀는 완전히 복구됐다. 홍은채→카즈하 경계가134.1673667초/8042프레임으로 돌아왔고, 기존 visual_difference16.55625/median4.337986과 일치한다. 홍은채131.2977333–132.6326의 기존 body bridge도 복구됐다. 중간 실행 대비 출력 변화는 후반 홍은채·카즈하 이름 복원과127.7276–131.9985의 불필요한 group 중첩 제거에 한정된다. 새 suffix 복원은0건이다.

ANT109.109 및172.2053667의 서로 다른 이름 전환 후보가 복구됐다. 사쿠라110.0098–110.5104, 허윤진169.2023–169.3025, 사쿠라172.2054–172.4057의 이름이 돌아왔고108.5084–109.0423의 group 중첩이 제거됐다. 18초대의 unknown 둘로 나뉜 구조도 기준 실행으로 돌아왔으며, 단순 라벨 coverage 비교가 놓칠 수 있는 내부 구간 경계도 별도 대조했다.
NEON은 중간 실행 대비 모든 표시 구간의 종류·시작·끝·이름과185개 썸네일이 그대로다. 최종 경계·suffix 수정이 추가한 출력 변화는0이다.

승인과 분리할 변화·한계
ANT171.8049667–172.2053667의 .4004초는 기준 unknown에서 허윤진으로 바뀌었다. 중간 실행 대비 추가 확장은 .3337667초다. 기존171.804967 얼굴 변화 경계가 샷 내부 양측 지지 제한에서 빠지고, 복구된172.205367 이름 midpoint까지 앞 이름이 이어졌다. 마지막 허윤진 named support171.7716, 다음 사쿠라172.639133 사이에는 실제 컷171.888383/172.255417이 있다.171.8383 joint는insufficient이고172.0385–172.172는pose_face_missing이다. 이 추가 이름 확장을 확인한 양성 GT가 없으므로 증명된 품질 개선으로 집계하지 않는다. 명백한 오인식이라고 단정하는 것도 피한다.
MMN41초와118초는 다섯 명의 전신 ensemble 근거로 group 유지가 늘었다. 41초대에는 독립 사쿠라 이름 근거도 남는다. 이름·몸의 연결만으로 solo main 역할을 확정할 수 없으며, 기존 멤버 맥락 유실과 group/main 중첩을 주의점으로 유지한다. 실제 helper 연장 프레임은MMN19개,ANT0,NEON0이다. 최종 scene_context 출력을 잘못 입력했던 이전 replay의 ‘MMN3개뿐’ 결론은 폐기했다.
ANT128.294833–128.962267, NEON116.649867–117.050267 및120.687133–120.987533에는 이름이 unknown으로 바뀐 변화가 남는다. 기존 conflict/insufficient 얼굴 또는 역할 근거가 있어 저장 자료만으로 인식 회귀나 올바른 abstention을 확정하지 않는다. NEON43.777067–44.110733의 기존 main 역할 확장 주의점도 해결된 것으로 표시하지 않는다.
그 외 작은 이름 교대·패딩 변화까지 모든 기준→최종 및 중간→최종 라벨 구간과 실제 클립 경계 차이는 동반JSON에 전부 열거했다. 총 변화 시간은MMN4.1039,ANT1.9852167,NEON1.5350667초이며, 이 값은 오류 시간이나 개선 시간이 아니다.

기존14개 기준과 짧은 구간
14개 사용자 기준 범위의 잘라낸 이름/역할 시간선은 기준 실행과 전부 동일하다. 기존 미해결 항목도 유지됐다: MMN1.9–2.3은no_person 대신group,34.73–34.8348은unknown,45초대에는 준비 맥락 문제와사쿠라/허윤진45.362–46.4631 중첩, ANT4.5712–6.139 및9.9098–10.2769에는unknown이 남는다. ‘14개 모두 보존’을 ‘14개 모두 정답’으로 해석하지 않는다.
보호 대상MMN26.1428–26.3930,88.4217–88.8554,ANT82.182–82.6826,NEON115.6155–115.9158 네 구간은 이름/역할과 겹치는 실제 구간 구조 모두 유지됐다. 표시 클립370→368,1초미만191→185,unknown총36.7733667→36.3231167초(-.45025)다. 이름 미확인 시간의 감소에는 위 미검증 이름 확장도 포함되므로 전체 감소를 검증된 정확도 개선으로 세지 않는다.

썸네일·실행 동일성·SAM
기준과 같은(종류,시작) 썸네일은MMN57/ANT109/NEON181,총347쌍이며 모두SHA-256이 같다. 중간 실행과 공통인363쌍도 모두 같다. 기준 대비 새로운 시작은총21개:20개는 이미 직접 열어본 중간 실행 썸네일과 바이트 동일하고, ANT64.41435의 새썸네일은 최종 파일을 직접 열어 정상 확인했다. 빈 이미지나 깨진 이미지는 발견하지 않았다. 일부 원본 동작 흐림·크레딧 오버레이가 있으며, 얼굴 식별 정답이나 대표 프레임의 적절성까지 보증하지 않는다. 클립 번호가 바뀔 수 있어 번호형clip_id로 동일성을 판정하지 않았다.
