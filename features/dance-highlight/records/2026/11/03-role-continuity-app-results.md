## 판정

확인된 연속성 오류와 이름 전파 오류를 수정하고 실제 앱 세 영상을 검증했다. 그러나 전체 품질 문제는 아직 해결되지 않았다. 원래 분류 자료의 1초 미만은226→216개로만 줄었으며, 중복 표시 정리 후에도195개가 남는다. 실행 시간 합계도20:08→22:07로 증가했다. 부분 수정의 채택 근거와 미해결 역할 문제를 분리한다.

## 문제와 수정

짧은 클립 수를 줄이는 것만으로 품질을 평가하지 않는다. 실제 인물 교대를 보존하면서 잘못 생긴 단절을 연결하고, 잘못 확정된 이름을 제거하는 것이 목적이다. 임의 최소 길이, 3초 상한, 원경 단체의 일괄 멤버 변환은 추가하지 않았다.

1. **중복된 전신 관측 정리:** 한 사람을 중복 검출하면 얼굴 소유권과 다음 프레임의 연결이 모호해진다. 머리·몸통·다리 관측이 함께 일치하는 원본 대표를 사용하고, 서로 다른 사람이 섞이거나 원본 관측이 모순되면 보류한다. 원본과 대응 관계를 진단 자료에 남긴다. 이것은 이후 분류의 입력 개선이며, 제거한 검출 수를 개선된 클립 수로 세지 않는다.
2. **이름 근거 없는 앞뒤 여유 구간 보호:** 얼굴 인식 구간을 늘리는 과정에서 실제 얼굴 관측이 없는 0.03초 조각에도 부모의 이름이 복사되었다. 이제 직접 얼굴 근거 또는 같은 사람으로 이어지는 검증된 경로가 필요하다. 다른 몸·다른 이름·장면 전환이 끼면 이름을 확정하지 않는다.
3. **교대 경계 보정:** 두 얼굴 인식 시각의 단순 중간값 때문에 실제로 다른 사람이 선택된 이후까지 이전 이름이 붙는 경우가 있었다. 들어오는 사람의 반복 얼굴 근거와 원래 몸 관측을 역방향으로 확인해, 처음 실제로 관측된 교대 시점까지 경계를 조정한다. 남는 이전 파트도 별도로 확인한다.
4. **줌 변화로 생긴 잘못된 단절 복원:** 기존 이름·몸·장면 전환 검사를 통과했는데 화면 전체의 밝기·흐림 변화만으로 끊긴 경우에 한해, 원래 얼굴 픽셀의 짧은 앞뒤 경로를 추가 확인한다. 한 창은 최대 5개 원본 프레임이며 모든 의심 구간을 확인해야 한다. 얼굴이 없거나 가림·다른 사람이 끼면 원래 보류를 유지한다. 새 얼굴 모델이나 SAM을 실행하지 않는다.
5. **같은 단체 구도의 관측 공백 연결:** 세 사람의 독립적인 머리·몸 관측이 모든 샘플에서 이어지고 중간 원본 프레임에 컷이 없을 때만 단체 구간을 잇는다. 멤버 분류가 끝난 뒤 적용하므로 이것이 새 이름 근거가 되지 않는다.
6. **완전히 중복된 단체 출력 정리:** 하나의 기존 멤버 클립에 전체가 포함되고 경쟁 멤버가 없는 단체 카드만 결과 목록에서 생략한다. 실제 분류·원래 단체 진단·원본 커버리지는 남긴다. 이 항목은 인식 정확도 개선과 별도 집계한다.

- macOS ARM64 실제 앱에서 검증했다. 새 로직은 기존 Python/NumPy/OpenCV 경로를 사용하지만 Windows 실기기 성능을 이번 실행으로 검증했다고 주장하지 않는다.

## 실패한 시도와 남은 한계

- 단체 사이의 중앙 인물을 기존 메인으로 유지하는 초안은 실제 단체에 임의 메인을 만들거나 작은 섬 구간을 늘려 채택하지 않았다. NEON 약 48초에는 신뢰할 수 있는 앞쪽 개인 메인 근거가 부족하다.
- 전신 중복 정리만 넣은 첫 앱 실행은 사용자 검토 14구간을 개선하지 못했다. 새 초단편 이름 누출과 교대 경계 지연을 독립 검토가 찾아냈고, 이후 보호 로직과 경계 수정을 함께 적용했다.
- 얼굴이 작거나 옆모습이거나 가려진 경우의 이름 인식은 여전히 약하다. 이름이 확인되었다고 그 사람이 해당 장면의 메인이라는 뜻도 아니다.
- 단체·메인 구분은 전체 구도, 개인 안무, 스포트라이트, 카메라 의도를 함께 다뤄야 한다. 중앙 좌표나 짧은 시간만으로 해결한 것으로 간주하지 않는다.
- 사용자 검토 사례의 개선과 모든 영상의 정확도는 구분한다. 세 영상 전체를 사람이 전수 정답 라벨링한 정확도 수치는 없다.


## 잔여 구조적 원인과 다음 우선순위

MMN50.6506–50.683967의2프레임 김채원 조각에는 실제 얼굴이 있다. 그러나 전신 군무의 한 사람 높이가360→363픽셀로 규모 경계를 넘으면서 단체 조건이 탈락했고, 이를 개인 메인 자격으로 사용했다. 긴 이름 구간과 개인 메인 허용 구간의 교집합에 마지막2프레임만 남았다. **단체 조건 탈락은 개인 주역의 양성 증거가 아니다.** 얼굴 이름을 더 잘 맞히거나 최소 길이를 주는 것만으로 이 구조를 해결할 수 없다.

MMN45초에는 원래 선택된 허윤진 몸과 별도 사쿠라 준비 동작 몸이 실제 저장 관측상 다르다. 준비 동작을 사쿠라 클립 앞에 붙이면서 허윤진 범위는 그대로 남겨1.1011초가 겹친다. 이는 원래부터 남은 문제다. 확인된 사쿠라 준비 맥락을 허윤진의 역할 종료 증거와 동일하게 취급해서는 안 된다. 현재 구도의 얼굴 크기·중앙 가중치와 전후 파트의 의미를 한 역할 조립 단계에서 다루는 개선이 필요하다.

MMN68초와 NEON161초에 제한된 torso 픽셀 검증을 추가하는 방법도 조사했다. 직접 검토 가능한 후보 교집합은 최대1.067933초로, 성공 예상치가 아니다. 다른 후보는 torso 자체 저신뢰·얼굴 소유권 모호성 등 원인이 다르다. 이 좁은 보완을 더 넣는 대신 다음 구조를 우선한다.

1. 단체 구도 증거, 개인 주역 증거, 얼굴 이름을 독립 사실로 보존한다. 단체가 아니라는 이유나 이름을 안다는 이유만으로 메인 anchor를 만들지 않는다.
2. 직접 개인 주역 근거로 시작한 역할 구간을 원래 몸·경쟁자 관측으로 유지하고, 그 위에 얼굴 이름을 연결한다. 확정 교대·컷·가림은 보존한다.
3. 실제 메인 구간과 앞뒤 준비 맥락, 내보낼 클립 범위를 구분한 하나의 최종 조립 지점에서 처리한다. 준비 맥락을 실제 역할 전환으로 자동 승격하지 않는다.

이 세 항목은 **독립 검증 세션의 다음 설계 제안이며 이번 앱에 구현한 성과가 아니다.** 전 영상의 실제 역할 근거와 잘린 원인을 먼저 같은 형식으로 모으고, 출력이 바뀌지 않는 검증 경로에서 계약을 확인한 뒤 적용해야 한다. 기존 사용자14범위, 실제 교대·짧은 파트·원경 단체 반례를 함께 보존한다.

## 근거 보관

동봉 `03-role-continuity-evidence/`에 실제 실행 비교JSON, 새 프로젝트ID, 소스·패키지SHA, 회귀검사/빌드 로그, 이번 turn 소스diff, 독립 검토, 남은20개 짧은 main 분석과 미채택 torso 조사 자료를 보관한다. 원본 앱 프로젝트와 기존 사용자 결과는 보존했다. 통합 실행 후 NEON 독립 검토까지 완료했으며 함께 보관했다. 전체400개 원래 분류 중 이전과 같은 시작점394개의 썸네일 바이트가 같고, 시작점이 달라진6개는 구분했다. 직전 canonical 앱과 비교하면399개가 같고 ANT의 새 시작점1개만 바뀐다.

NEON 43.777067–44.110733의 역할 문제는 미해결이다. 다음 클로즈업의 seed2644에서 앞쪽 군무의 관측 5개를 group→main으로 변경했으나, 모두 exclusive_foreground=false, role_retention=false다. 현재 오아 main 43.777067–45.045와 group 42.6426–44.110733가 공존한다. 이름·몸 연결을 개인 주역 근거와 같게 쓰는 문제가 남아 있다. baseline보다 main 시간 합집합이 0.333667초 늘었으나, 전체 main+group 시간 합집합 보존을 역할 정당화로 해석해서는 안 된다. 따라서 baseline 대비 ‘전체 품질 퇴행 없음’이라는 판정은 확정하지 않았다.

이를 막겠다고 컷을 넘는 연속성을 일괄 금지하는 변경도 하지 않았다. 같은 멤버의 실제 파트가 각도 전환을 넘는 반례를 보존해야 하기 때문이다. 다음 설계의 역할 양성 근거와 맥락 범위 구분이 필요하다.
