# 제안 F 원본 대조 보정과 프로모션 참여 제한 수정 요구

2026-11-02 KST. 작업 브랜치 `feat/signup-credit-promotion-free-20261102`. **요금제 UI 보정 완료·미커밋. 참여 제한은 요구사항/설계 수정이며 아직 API/Admin에 구현하지 않았다.** 기존 W19 검증 완료 기록 이후의 후속이다.

## 참여 제한: 혜택과 별개로 선택

사용자가 크레딧형 프로모션도 캠페인별 참여 조건을 선택해야 한다고 정정했다. ‘크레딧형이므로 이용권 검사를 무조건 생략’하는 정책은 사용하지 않는다.

- 혜택: 크레딧 지급 / 이용권 지급.
- 참여 시점: 회원가입할 때만 등록 / 가입 후 회원 화면에서도 등록 등, 가입 제한을 혜택 종류와 독립시킨다.
- 참여 제한 체크박스: 현재 활성 이용권 보유, 과거 유료 이용권 결제·사용 이력, 관리자 지급 이용권 이력. 선택한 항목 중 하나라도 해당하면 참여 불가. 선택하지 않은 항목은 거절 근거로 사용하지 않는다. 과거 이력은 만료 이력도 포함한다.
- Free 기본 상태는 ‘현재 활성 이용권’ 제한의 대상 이용권으로 취급하지 않는다. 유료·프로모션·관리자 지급 이용권이 현재 활성인 경우를 검사한다.
- 과거 다른 캠페인 참여 이력과 무료체험 이력을 선택지로 다시 추가하지 않는다. 같은 캠페인 1회, 코드별 상한, 코드/캠페인 운영 상태와 기간 검사는 공통으로 유지한다.
- 이용권을 새로 지급하는 혜택은 동시 이용권 중복을 막는 구조적 검사를 별도로 유지한다. 크레딧 지급형에 이 구조적 검사를 강제하지 않는다.

**남은 구현:** 현재 `access | signup_credits`로 묶인 모델을 혜택과 참여 시점으로 분리하고, 위 선택 조건을 저장/검사하며 관리자 폼과 회원 안내, 가입 지급과 일반 등록에 공통 적용해야 한다. 이번 UI 변경만으로 그 기능을 구현했다고 간주하지 않는다. 회원에게 숨겨진 조건이나 새로운 성과/레퍼럴/예약 기능을 붙이지 않는다.

## 제안 F와 실제 UI의 차이 및 보정

원본: https://claude.ai/artifact/Vir1fujgQnWxy2bWMGRTrD#play-f26af133c213 (`MainF.dc.html`). 렌더된 원본 main HTML과 스크린샷을 증거 폴더에 보존했다. 이전 구현은 원본을 참고해 다시 구성한 것으로, 원본 그대로 적용했다는 설명은 부정확했다.

이번에는 원본의 1280px 프레임/24px 안쪽 여백, 제목 40px·카드명 26px·가격34px, 리본28px/왼쪽 정렬, 카드 padding24px20px와 8px 모서리, Pro 흰 테두리/리본/버튼, Business 배경/라임 테두리/리본/버튼, 크레딧 영역과 전체 폭 버튼 구분선, 16px SVG 체크/X와 목록 간격을 대조해 옮겼다. 추가 크레딧은 원본의 독립 카드·기간 배지·가로 수량/가격·하단 설명/링크 구조로 복원했다.

연간 선택 시 월 환산 가격이 주 가격이며 실제 연간 총액과 자동 갱신은 상단에 명시한다. 할인 칩은 API 값이다. 원본의 하드코딩 가격/지급량/10개 묶음 목록은 복사하지 않았다. 현 API의 가격/가입 혜택/각 플러그인 목록·허용 여부/크레딧 유효기간이 표시된다. 따라서 목록 수와 금액, Free 명칭·가입 시1회·유효기간 안내는 원본 예시와 다르다. Free 이용 자체에 14일 종료를 붙이지 않았다. 가입 크레딧 사용 기한을 분명하게 표시했다.

`/#price`와 `/pricing`은 여전히 같은 catalog/card/toggle 컴포넌트를 재사용한다. 제품 API·DB·다른 서버/앱은 변경하지 않았다. 4241은 최종 빌드 복사본으로 갱신했으며 API4340/Admin4242/독립 앱을 종료하지 않았다.
