# 종료일 미정 캠페인 구현 계획

**후속 정정:** 이 기록 당시의 ‘등록 이력 후 종료일 단축 금지’는 [최신 정책](02-campaign-deadline-and-summary-colors.md)으로 대체됐다. 현재는 시작일 이후 범위에서 단축/연장/미정 전환을 허용하며 지급 혜택은 유지한다.

사용자 요구: 종료일 없이 캠페인을 생성·수정할 수 있다. 시작일 이후 캠페인과 코드가 활성 상태인 동안 참여 조건·코드별 상한을 만족하면 등록 가능하다. 운영자가 비활성화하면 신규 등록을 차단한다. 지급 크레딧의 유효기간과 이용권 기간은 바꾸지 않는다.

작업: 기존 격리 worktree signup-promotion-plugin-access-20261028, feat/signup-credit-promotion-free-20261102. 다른 미커밋 변경은 보존. 커밋·푸시·dev 병합 없음.

- [x] API 계약·DTO·도메인 모델에서 캠페인/코드 미리보기 endsAt은 날짜 또는 null. 혜택 지급·참여 내역의 endsAt은 기존대로 실제 만료일이다.
- [x] 종료일 없는 정책 판정·생성·활성화·수정·조회·실제 등록 및 크레딧 자체 만료 보존을 실패 테스트로 고정한다. 유효하지 않은 날짜와 시작일 이전 종료일은 계속 거절한다.
- [x] DB migration으로 campaign.ends_at의 NOT NULL만 해제. 기존 날짜와 혜택 기록 보존. null이 남은 상태의 rollback은 임의 날짜를 만들지 않고 DB 제약으로 거부한다.
- [x] 종료일 null은 만료 검사에서 제외하고 활성화 CAS에서도 허용한다. 날짜가 있는 캠페인의 기존 만료 및 재활성화 금지 유지. 종료일 없는 활성 캠페인도 이용권 등급 비활성화 방지 검사에 포함한다.
- [x] 관리자 종료일 필수 해제·‘종료일 (선택)’과 빈 값 도움말·목록/상세 ‘종료일 미정’ 표시. 수정 시 null을 빈 칸으로 불러오고 빈 칸은 null 전송. 등록 이력 후 시작일·혜택 잠금과 이미 정한 종료일의 단축 금지는 유지. 날짜→미정은 허용하고, 미정→새 날짜는 처음 종료일을 정하는 것으로 처리한다.
- [x] 클라이언트 코드 미리보기 타입도 계약에 맞추되 크레딧 만료/참여 내역 표현은 변경하지 않는다.
- [x] 관련/전체 테스트 및 build, 일회용 PostgreSQL 통합 검증. 로컬 사용자 DB는 백업 후 신규 migration만 적용하며 초기화하지 않는다. 해당 세션 API4340·웹4241/4242만 반영하고 다른 서버·앱은 유지한다.
- [x] 실제 관리자 추가/수정 화면을 확인하고 결과·증거를 .codex에 기록한다.
