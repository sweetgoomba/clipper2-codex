# 프로모션 참여 가능 조건: 후속 후보

2026-11-02. 사용자 요청으로 후보를 보존한다. 아래 목록은 구현 확정/현재 지원 목록이 아니다.

## 이번 확정

참여 대상: 신규 가입 과정의 회원만 / 기존 회원만 / 신규·기존 회원. 단일 선택.
추가 조건: 현재 활성 이용권 없음 / 유료 이용권 결제·사용 이력 없음. 선택한 조건을 모두 충족한다.
신규 가입 전용이면 추가 조건을 해제하고 보이는 상태로 비활성화한다. 다른 캠페인 이력, 무료체험 이력, 관리자 지급 과거 이력은 제한으로 추가하지 않는다.

## 향후 조건을 추가할 때

같은 축의 상반된 조건은 체크박스 둘로 만들지 않고 단일 선택으로 묶는다. 같은 축의 여러 값은 OR, 축 사이의 조건은 AND다. 갱신 취소와 현재 이용권 종료는 다르다. 유료 이용권 결제와 추가 크레딧 구매는 구분한다. 결제금액 집계는 환불·실패·기간을, 활동 기준은 이벤트/시점을 먼저 정의한다. 현재의 두 추가 조건부터 시작하며 일반 규칙 편집기나 위 전체 옵션을 선제 구현하지 않는다.
