## 조건 사이의 포함 관계와 요약 정정

신규 가입자만 참여하도록 제한하면 기존 회원의 활성 이용권/과거 유료/관리자 지급 이력 조건은 불필요하다. 이를 동시에 독립 체크하게 했던 목업을 수정했다.

- ‘이미 가입을 완료한 회원 제외’를 체크하면 나머지3개의 체크값을 해제하고 숨기며 비활성화한다. 숨겨진 조건을 저장 미리보기에 남기지 않는다.
- 체크를 해제하면 나머지3개를 다시 표시하고 선택할 수 있게 한다. 해제 전 값을 자동 복구하지 않는다.
- 신규 가입자 전용의 요약은 ‘신규 회원이 회원가입할 때만 참여할 수 있습니다.’ 한 문장만 표시한다. 불필요한 추가 제한 없음/이력 없음 안내, 복수 선택 안내를 숨긴다.
- 아무 제한을 선택하지 않으면 ‘신규 회원과 기존 회원 모두 참여할 수 있습니다.’로 표시한다.
- 향후 실제 저장도 신규 가입자 전용과 불필요한 나머지 조건을 중복 저장하지 않도록 같은 의미로 처리해야 한다. 현재 제품/API는 미구현이다.

CUA에서 나머지3개를 모두 선택한 뒤 신규 가입자 전용을 체크했을 때 checked=false/disabled=true/hidden=true, 체크 해제 시 false/false/false를 확인했다. 별도 참여 시점과 상단 탭은 계속 없다. [현재 화면](02-campaign-create-eligibility-dependent-mockup.jpg).

## 최신 사용자 지시: 실제 구현 보류 · 참여 가능 조건 목업으로 재검토

사용자가 실제 관리자/API 구현을 일단 홀딩하고 참여 가능 조건으로 바꾼 목업부터 다시 보겠다고 지시했다. 직전 실제 구현 요청은 재검토 대기 상태이며, 이 변경에서 제품 소스/API/DB/마이그레이션은 수정하지 않았다. 기존 W19 미커밋 구현은 보존하며 되돌리거나 초기화하지 않는다. 이용권형 월별 만료 통일은 요구로 유지하되 실제 구현을 진행하지 않는다.

이번 목업은 앞선 동등한 제외 체크박스 구성을 대체하는 **검토 제안**이다. 아직 실제 제품 정책/UI 확정으로 취급하지 않는다.

- ‘참여 가능 조건’ 안에서 참여 대상을 단일 선택: ‘회원가입하는 신규 회원만’ / ‘신규 회원과 기존 회원’.
- 그 아래 추가 조건은 긍정형 체크박스: ‘현재 활성 이용권이 없는 회원’, ‘유료 이용권 결제·사용 이력이 없는 회원’.

- 신규 회원만 선택하면 두 추가 조건을 해제하고 비활성화한다. 숨기지 않는다. 대상 선택을 되돌리면 빈 선택으로 재활성화한다.
- ‘선택 · 복수 선택 가능’ 및 ‘체크한 조건을 모두 만족하는 회원만 참여할 수 있습니다.’ 안내는 계속 표시한다.
- 요약은 실제 참여 가능 대상을 표시한다. 유료 이력 없음만 체크한 예: ‘신규 회원과, 유료 이용권 결제·사용 이력이 없는 기존 회원이 참여할 수 있습니다.’
- 유료 이용 이력이 있는 회원은 이미 가입한 회원의 일부다. 따라서 유료 이력자 제외는 기존 회원 전체 제외를 포함하지 않는다. 가입 후 무료로만 이용한 기존 회원은 유료 이력 없음 조건을 통과한다. 이 포함 관계를 잘못된 자동 비활성화로 구현하지 않는다.
- 관리자 지급 **과거 이력** 옵션 삭제, 상단 탭 금지, 별도 참여 시점 항목 없음, 이용권형 구조적 중복 지급 방지는 유지한다. 새 ‘참여 대상’ 단일 선택은 긍정형 목업의 제안이며 사용자 재검토가 필요하다.
- 직전 요청의 크레딧형 지급량/유효기간 입력을 한 줄 반반으로 적용했다. 이용권형에는 별도 유효일수 입력이 없다.

검증: 브라우저에서 유료 이력 없음 단독/두 조건 동시 선택/신규 전용 전환/다시 전체 대상으로 전환/저장 미리보기/혜택 종류 전환을 확인했다. 신규 전용일 때 두 조건 visible=true, checked=false, disabled=true. 크레딧 입력 두 개의 y좌표 동일, 너비 각각245.10/245.12px. 이용권형 유효기간 hidden/disabled=true. 콘솔 오류 없음. 목업이므로 실제 저장 요청 없음, 제품 빌드/회귀 시험 없음.
