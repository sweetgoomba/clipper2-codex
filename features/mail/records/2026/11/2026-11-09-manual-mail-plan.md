# 관리자 수동 메일 발송 구현

> **2026-11-10 현재 기준:** 이 문서는 초기 단계의 과거 기록입니다. 현재 10개 자동 이벤트는 실제 연결·dev 반영을 완료했고, 문의 전달·운영자 초대/재설정은 Resend를 유지합니다. 사용자는 최신 개발 배포 완료, 운영 SES/SNS/IAM 생성만 완료를 보고했습니다. [종합 기록](2026-11-10-mail-session-summary.md)과 [현재 색인](../../../README.md)을 먼저 확인하세요. 아래 초기 리소스 이름·배포 지침·미커밋/미연결 상태를 현재 기준으로 실행하지 마세요.

## 승인된 범위
사용자의 2026-11-09 요청: 기존 Angular 목업을 실제 관리자 기능으로 구현한다. 제목과 일반 텍스트 본문 작성, 공통 상·하단 디자인, 미리보기, 임시 저장, 전체/조건/직접 선택 수신 대상, 광고 동의자 전체, 즉시/예약 발송, 취소, 수신자별 결과를 포함한다. 오픈소스 에디터 도입과 신규 자동 발송 이벤트의 구현·업무 연결은 제외한다. 기존 문의/운영자 초대/비밀번호 재설정은 SES로 이전한다. 발신은 Clipper <clipper@metabuzz.co.kr>. 앱 소식과 독립한다.

## 구현 선택
- 현재 사용자 작업 및 목업이 있는 dev 체크아웃에서 파일별로 추가하며 기존 변경을 보존한다. 커밋/푸시/운영 배포/실제 회원 발송은 수행하지 않는다.
- 일반 텍스트 본문을 서버에서 이스케이프하고 줄바꿈을 보존해 HTML+text로 생성한다. 본문 배경은 흰색. 공통 디자인은 로고 업로드/너비 슬라이더/정렬/여백/상하단 색/문구와 문구 안의 링크를 DB에 저장한다. 업로드 로고는 미리보기에서 data URL로 표시하고 SES 전송 시 CID 인라인 첨부로 변환한다. 하단 HTML은 서버에서 허용 목록으로 정리한다.
- 사용자 DB에 광고 수신 설정과 변경 이력을 저장한다. 가입 트랜잭션에 최초 선택을 저장하며 기존 미기록 회원은 미동의로 처리한다. 계정 설정과 서명된 수신거부 링크가 같은 값을 바꾼다. 동의 변경 자체의 자동 메일은 구현하지 않는다.
- 관리자 DB에 발송 건·수신자·디자인·피드백·차단 주소를 저장한다. 수신 대상과 디자인을 발송 확정 시 고정하고 광고 동의/차단/회원 존속 여부는 실제 발송 직전에 다시 확인한다.
- DB 작업 큐와 SKIP LOCKED 청구, 작업 토큰, 제한된 재시도, 재시작 복구를 사용한다. 제공자 응답이 불명확한 전송은 자동 재발송하지 않고 확인 필요로 남긴다.
- AWS SDK 기본 자격 증명 체인 사용. IAM 역할 우선, SES 리전/발신/구성 세트/웹 주소/수신거부 서명 키/작업 활성화/발송 속도를 env로 받는다. SES SNS 피드백은 허용 토픽과 서명을 검증한다.
- 모든 관리자 API는 mail.read/mail.write로 보호하며 발송 확정/취소/디자인 변경은 감사 기록에 남긴다. UI는 기존 공통 부품을 재사용한다.

## 작업과 검증
1. 발송 모델·미리보기·SES 어댑터: 안전한 HTML, 제목 광고 표기, 주소/링크 제한, SDK 요청/실패 분류 테스트를 먼저 작성 후 구현.
2. 수신 동의: 가입 선택 저장·기존 동의 보존·계정 변경·서명된 수신거부 검증 테스트 후 사용자 DB migration/API/client 구현.
3. 발송 저장/API/작업: 수신 대상 선택, 예약 검증, 동시 청구·중복 요청·취소·재시도·불명확 상태·피드백 테스트 후 관리자 DB migration/서비스/worker 구현.
4. 관리자 UI: 실제 HTTP API를 호출하는 작성/미리보기/확정/디자인/내역 화면과 mock handler, 권한·검증 테스트.
5. 기존 Resend 어댑터 교체, env 예시/compose/OpenAPI/운영 안내, 서버·관리자·고객 빌드/관련 테스트/브라우저 검증.
6. 전체 변경을 별도 검토하고 발견한 실질 문제 보완. 실제 AWS 발송·운영 migration/배포는 실행하지 않은 항목으로 명시.

## 진행 기록

## 완료 기록

- 범위 내 코드 구현 완료: 관리자 수동 작성/저장/미리보기/확정/예약/취소/발송 내역, 공통 디자인, 사용자 광고 수신 동의/계정 토글/서명된 수신거부, SES 공통 어댑터 및 기존 문의/운영자 메일 이전, SNS 결과 수집, DB 마이그레이션·OpenAPI·권한·mock·compose/env 예시.
- 신규 자동 발송 이벤트/본문 후보의 실제 업무 연결은 구현하지 않음. 결제 작업/재시도 코드는 수정하지 않음. 외부 에디터를 도입하지 않음.
- API 전체: 489 suites / 5,330 tests 통과, 환경 선택형 기존 테스트 등 17 suites / 190 tests 기본 제외. 격리 PostgreSQL/runtime 테스트 15개를 별도로 활성화하여 통과. 메일 DB/작업/피드백 결합 23개 통과.
- 관리자: 2,872 browser tests 통과. 고객 웹: 665 browser tests 통과. 인프라 배포 스크립트 검증: 35개 통과.
- API 빌드, 관리자·고객 웹 prod 빌드 통과. 웹 기존 bundle 예산 warning 존재(admin 903.56kB, client 515.19kB, error 한도 이내). 관리자 색상 규칙 직접 색 0개, 네 repo diff whitespace check 통과.
- 실제 Angular 브라우저: 작성→미리보기→발송 확인 취소→확정→결과, 예약→취소, 공통 디자인, 가로 넘침 없음 확인. 발송은 mock transport로 격리, 외부 메일 전송 없음.
- 별도 검토에서 발견한 전송 전 오류의 재시도 누락과 취소/완료/늦은 결과 경합을 실제 DB 실패 테스트로 재현 후 보완. 검토자가 두 지적 및 마지막 완료 경합 해결을 확인.
- 임시 PostgreSQL은 검증 후 종료. 관리자 로컬 검토 서버 http://127.0.0.1:4299/mail 유지(목업 로그인 admin@clipper.app / password). 검토 화면에서는 실제 SES 발송하지 않음.
- 사용자 변경과 기존 목업을 보존. 커밋·푸시·AWS 설정 변경·운영 env/DB 수정·운영 배포·실제 회원 메일은 수행하지 않음.
- [IAM/SES/환경변수/배포 안내](2026-11-09-ses-deployment.md). IAM JSON은 clipper_infra/env/clipper-ses-send-email.policy.json.

## 사용자 검토 후 화면 보완

- 기존 공통 UrlTabs에 `발송 현황 / 자동 발송 설정 / 공통 디자인` 세 탭을 표시한다. 사용자 후속 요청에 따라 공통 디자인 버튼을 제거하고 같은 탭 영역으로 옮겼다. 기존 `?screen=design` 링크는 `?tab=design`으로 연결한다.
- 자동 메일 19개 목록·오른쪽 편집 패널·본문 표·미리보기·DB 저장 구현. 실제 업무 트리거 연결은 계속 제외하며 모든 이벤트는 미연결 상태다. 저장해도 발송 큐를 만들지 않는다.
- 공통 디자인을 승인된 목업의 로고 업로드·크기 슬라이더·여백·색상·글자 선택 링크 편집·실시간 미리보기로 복원. 별도 본문 에디터 라이브러리는 도입하지 않았다.
- 가입의 광고 수신 설명 문구는 선택 체크 항목 안에서 바로 아래에 한 번만 표시한다.
- PostgreSQL UPDATE 반환 형식을 정규화하여 템플릿 재저장 결과와 버전 충돌 처리 보완. API 전체 5,338개 통과, 별도 PostgreSQL 16개 통과. 관리자 전체 2,872개·고객 웹 전체 665개 통과. 로컬 브라우저의 저장/새로고침/진입 탭 복귀와 SDK→로컬 받은 메일함의 CID 로고·하단 링크 확인.
