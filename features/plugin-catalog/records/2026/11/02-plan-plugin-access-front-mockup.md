# 요금제별 플러그인 관리: 프론트 전용 목업

2026-11-02. 사용자 요청으로 실제 API 변경 전에 화면과 조작을 검토한다.

## 열어 보기

- URL: http://localhost:4242/__mockups/plan-plugin-access
- 기존 관리자 인증과 AppShell을 사용한다. local/mock 빌드에서만 접근한다.
- 요금제 등급 카드의 ‘요금제별 플러그인 관리’ 버튼 하나로 큰 모달을 연다.
- 기존 /plans의 실제 저장 기능과 등급별 허용 설정 버튼은 검토가 끝날 때까지 유지한다.

## 화면과 동작

- Free → Basic → Pro → Business 네 개의 세로 카드를 가로로 비교한다.
- 현재 카탈로그의 플러그인 이름 14개를 표시하되, 등급별 체크 상태는 예시 데이터이다.
- 상단 ‘상위 요금제에 하위 요금제의 모든 플러그인 포함’ 토글을 둔다.
- ON: Free를 포함한 하위 등급에서 허용한 플러그인을 모든 상위 등급에 자동 포함한다. 상위 카드의 해당 체크는 잠금 표시와 비활성 상태로 해제할 수 없다.
- OFF: 화면의 체크를 유지하고 등급별 독립 편집을 허용한다. 하위만 허용하거나 상위만 허용할 수 있다.
- OFF에서 ON으로 바꾸면 하위 선택을 상위에 다시 강제 포함한다.
- 취소/닫기는 편집을 버린다. ‘목업에 적용’은 이 페이지의 메모리에만 적용하며 다시 열면 유지한다. 새로고침하면 예시 초기값으로 돌아간다.
- 기존 공통 Page/Card/Modal과 Material 체크박스·토글·버튼을 재사용한다. 공통 Modal에는 extra-wide(1280px) 크기만 추가했다. 좁은 화면에서는 카드 비교 영역을 가로로 스크롤한다.

## 이번 범위에서 변경하지 않은 것

API·DB·실제 플러그인 허용 정책·클라이언트 요금제 카드·앱 스토어·W18 동기화는 변경하지 않았다. 실제 플러그인 설정 저장을 호출하지 않는다. 특히 기존 백엔드의 유료 등급 포함 규칙을 이번 OFF 목업과 연동한 것으로 해석하지 않는다.

## 검증

- 관리자 local 최적화 빌드 성공(2026-11-02 22:44 KST), check:colors 통과, git diff --check 통과.
- 실제 4242 브라우저에서 모달 열기 및 네 등급 비교 확인. 좁아진 창에서도 비교 영역 826px 안에 네 카드가 모두 표시됨을 확인했다.
- Free의 대사 하이라이트 선택 → Basic/Pro/Business에 체크·비활성 반영 확인.
- OFF 전환 시 체크 유지, Basic만 해제하고 Free/Pro/Business 유지 확인.
- ON 복귀 시 Basic 체크·잠금 재적용 확인.
- 취소 후 기존 2/5/11/14개 유지 확인. 목업 적용 후 3/6/11/14개, 재열기 유지 확인.
- 새로고침 후 예시 2/5/11/14개로 복귀 확인.
- 이 세션 관리자 정적 번들만 갱신했다. API/DB/클라이언트/설치형 앱 및 다른 작업 환경은 중지·초기화하지 않았다.
