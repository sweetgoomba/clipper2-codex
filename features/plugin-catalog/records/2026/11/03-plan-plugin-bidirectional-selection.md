# 요금제 플러그인 체크 양방향 연동

2026-11-03. 사용자가 기존 체크 잠금 대신 양방향 연동 방식을 승인했다.

## 최종 동작

- 자동 포함 ON: 체크하면 현재 요금제와 모든 상위 요금제에서 같은 플러그인을 체크한다.
- ON에서 해제하면 현재 요금제와 모든 하위 요금제에서 같은 플러그인을 해제한다. 상위 선택은 유지한다.
- OFF에서는 현재 요금제의 해당 플러그인만 바뀐다.
- 예: 모두 체크된 상태에서 Pro 스토리보드 해제 → Free/Basic/Pro 해제, Business 유지.
- 체크박스의 상속 잠금, 잠금 아이콘·툴팁과 관련 CSS를 제거했다. 저장 중 비활성화는 유지한다.
- 모달 안내: ‘플러그인을 체크하면 상위 요금제에도 적용되고, 해제하면 하위 요금제에서도 해제됩니다.’
- 현재 보이는 선택을 기준으로 연동하므로 Free에서 해제해도 상위 요금제의 기존 선택은 유지된다. 변경하지 않은 다른 플러그인에는 영향을 주지 않는다.

## 구현과 범위

실제 /plans와 개발 목업이 함께 사용하는 PlanPluginEditorComponent만 수정했다. API/DB의 일괄 저장·포함 관계 검증·revision 충돌 방지는 그대로 사용한다. API·DB 변경이나 초기화·서버 재시작 없이 Admin4242 정적 번들만 갱신했다. 브랜치는 feat/signup-credit-promotion-free-20261102이며 미커밋·미푸시 상태다.

## 검증

- 변경된 요구 테스트가 기존 코드에서 5건 실패하는 것을 확인한 뒤 구현했다.
- 공통 편집기6 + 상품 화면75 = 관련81 tests 통과. build/check:colors/git diff --check 통과.
- 실제 /plans에서 기존 모든 체크가 활성 상태임을 확인했다. Pro 스토리보드 해제 한 번으로 Free/Basic/Pro false, Business true를 확인했다. 잠금 아이콘0개를 확인했다.
- ON/OFF 전환·다른 플러그인 보존·Business 해제 시 전체 해제·Free 해제 시 상위 보존·저장 중 차단·전송 목록을 검증했다.
- 실제 브라우저 테스트 초안은 취소했으므로 저장된 요금제별 허용 목록은 바꾸지 않았다.

## 후속: 자동 포함 섹션 고정

사용자 요청으로 자동 포함 토글·등급 순서 안내·체크 연동 안내를 함께 sticky 영역으로 묶었다. 기존 공통 모달의 제목/하단 버튼 고정은 유지하고, 편집기 자체 HTML/SCSS에만 적용했다. 모달 본문 상단8px 여백까지 배경을 덮어 스크롤 목록이 고정 영역 위로 비치지 않게 했다.

실제 /plans에서 목록을263px 내려도 토글 상단 위치가134.46px로 동일하고, 고정 영역 상단은 본문 상단106.82px와 일치함을 확인했다. 체크 목록은 이동하며 토글·안내·제목·하단 버튼은 계속 보인다. 공통 편집기6 tests·build·check:colors·diff 확인 통과. Admin4242 번들만 갱신했고 API/DB/저장 설정은 변경하지 않았다.
