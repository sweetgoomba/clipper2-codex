# 플러그인 설정 변경 이력 표시 구현 계획

목표: 목록 요약과 상세 전/후에서 UUID·pluginKeys JSON 대신 변경된 요금제·플러그인 조합과 허용 여부를 표시한다.

사용자 승인 범위: 기존 기록을 포함하여 비개발자 관리자도 읽을 수 있게 수정. 기존 감사 원본·회원·결제 데이터 보존, 전용 API4340/Admin4242만 갱신.

- [x] API: 기존 기록에 표시용 변경 행·요약을 조회 시 추가한다. 원본 changes는 보존하며, 기존 기록의 등급 이름은 현재 catalog에서 한 번에 조회한다. 새 기록은 저장 시점의 이름 스냅샷을 보존한다.
- [x] 표시: 바뀐 조합만 ‘Free · 스토리보드 | 허용 | 허용 안 함’으로 펼친다. 목록은 ‘Free·Basic·Pro: 스토리보드 허용 해제’처럼 묶는다. 다른 감사 기록의 표시는 바꾸지 않는다.
- [x] 검증: 기존/새 스냅샷, 삭제된 등급, 알 수 없는 플러그인, 권한 추가/해제·공통 정책 변경·무변경을 테스트한다. 기존 기록 원본이 바뀌지 않는지 확인한다.
- [x] 배포: 빌드·관련 테스트·실제 기존0140이력 화면 확인 후 로컬 적용 및 문서/WORKBOARD 갱신. 커밋/푸시 없음.
