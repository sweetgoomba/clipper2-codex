# 프로모션 점검 수정 계획 (2026-10-20)

기존 승인된 프로모션·레퍼럴 기능을 대상으로 한다. 코드와 계약은 각 기능 저장소에서, 이 계획과 검증 기록은 `.codex`에서 관리한다.

1. **이용권·크레딧 정합성**: 만료된 프로모션에서 빠진 월별 크레딧을 유료 이용권 활성화 트랜잭션 안에서 먼저 처리한다. 짧은 유효기간의 크레딧은 현재 혜택 표시에 포함하지 않는다. 작업 중단 후 전환과 만료 크레딧 회귀 테스트를 둔다.
2. **결제·회수**: 추가 크레딧 주문의 프로모션 적격성 조회를 저장소로 옮기고 회원 잠금 순서를 유지한다. 회수 사실과 예약 유료 결제일을 회원이 확인할 수 있는 지속적인 화면 안내를 제공한다. 회수·예약 동시성 검사를 보강한다.
3. **성과 조회와 XLSX**: 관리자 성과 화면은 응답 역전으로 이전 필터가 표시되지 않게 한다. 조회 목록은 페이지 단위로 제한하고 전체 XLSX는 배치 조회로 작성한다. 원래 결제·환불·크레딧 열과 숫자 형식을 유지한다. CSV 엔드포인트와 UI는 제거한다.
4. **운영 무결성**: 캠페인·코드 변경·회수를 작업자와 함께 감사 기록에 남긴다. 마이그레이션 역방향은 프로모션 데이터가 존재하면 변경 전에 명시적으로 막는다. 관리자 권한, PostgreSQL 마이그레이션·경합, 가능한 결제 스모크를 확인한다.
5. **검증**: 먼저 실패하는 회귀 테스트를 확인하고 최소 수정 후 API 집중·전체 테스트와 3개 웹 앱 빌드를 실행한다. 실행할 수 없는 외부 Toss 검증은 별도로 기록한다.
