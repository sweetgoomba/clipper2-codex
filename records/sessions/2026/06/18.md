## Template Builder Subtitle Height Auto-Sizing

사용자 QA:

- Template Builder에서 자막 폰트 크기를 키우면 `fontSize`만 바뀌고 자막 레이어 높이는
  그대로라 글자 아랫부분이 잘린다.
- 그 상태로 템플릿을 저장하고 shortform render에 사용하면 최종 output에서도 자막
  아랫부분이 잘린다.

원인:

- Angular Template Builder의 공통 스타일 패치는 `text.fontSize`, outline/shadow/box
  style만 draft family에 적용하고, `subtitleText.height`와 `subtitleText.box.height`는
  갱신하지 않았다.
- Python subtitle artifact renderer도 저장된 `box.height`를 그대로 신뢰해, 이미 작게
  저장된 템플릿은 큰 폰트/윤곽선이어도 작은 box 안에서 clipping됐다.

구현 커밋:

```text
clipper_angular: 37dea74 Auto-size subtitle height for template typography
clipper_python:  5eda200 Guard subtitle artifact height for large typography
```

구현:

- `clipper_angular`
  - Template Builder common style apply 단계에서 `role === 'subtitleText'`일 때만
    최소 line box height를 계산한다.
  - 최소 높이는 `fontSize * lineHeight`, outline width, shadow outline/offsetY,
    box border width를 반영한다.
  - 기존 높이가 더 크면 줄이지 않고, 필요한 경우에만 `subtitleText.height`와
    `subtitleText.box.height`를 같이 키운다.
- `clipper_python`
  - `render_template_builder_subtitle_artifact()`에서 저장된 box height와 계산된 최소
    line box height 중 큰 값을 사용한다.
  - 이미 작게 저장된 기존 템플릿도 최종 artifact/render에서 clipping되지 않도록
    방어한다.

## Shortform TTS Duration Truncation Follow-Up

사용자 QA:

- 새로 만든 shortform의 마지막 대사 `큰 환경 보호가 가능해요! 함께 실천해요.` 중
  TTS가 `큰 환경 보호가 가능해요!`까지만 재생됐다.

원인:

- 최신 job `shortform_render_1781743028087`의 payload에는 마지막 subtitle text와
  `tts_url`이 온전하게 들어 있었다.
- 실제 TTS 파일
  `tts.shortform_project_1781743003682.clip.7.line.clip.7.1.1781743024154.mp3`은
  ffprobe 기준 `2.760s`였지만, `shortform/projects.json`과 render payload에는
  `durationMs=1981` / `duration=1.981`로 저장돼 있었다.
- 저장된 `1981ms`는 `estimatedTtsDurationMs()` fallback 공식과 정확히 일치했다.
  즉 packaged/backend 환경에서 ffprobe duration 측정이 실패했고, 짧은 추정 duration이
  저장됐다.
- Python render worker는 subtitle duration을 믿고 TTS segment에
  `atrim=0:1.981`을 적용하므로 뒤 문장이 잘렸다.

구현:

- `clipper_nestjs`
  - `NaverClovaShortformTtsProvider`가 ffprobe를 사용할 수 없을 때도 TTS 응답 buffer에서
    WAV/MP3 duration을 직접 계산하도록 fallback parser를 추가했다.
  - 기존 프로젝트처럼 이미 짧은 duration이 저장된 경우도 다시 렌더하면 고쳐지도록,
    render job 준비 시 local TTS 파일의 실제 duration을 읽어 in-memory render project의
    narration line duration, clip duration, media slots를 보정한다.
  - 저장 project 구조는 바꾸지 않고 render manifest/payload 생성에 쓰는 project copy만
    보정한다.

## App FFmpeg/FFprobe Env Contract

사용자 정정:

- `/opt/homebrew/bin/ffprobe` 같은 개발자 로컬 설치본은 앱 런타임 기준이 아니다.

  사용해야 한다.

  `CLIPPER_FFMPEG_BIN`, `CLIPPER_YTDLP_FFMPEG_LOCATION` 같은 별도 이름은 직접 사용하지
  않는 방향으로 정리한다.

## Shortform Render TTS Tail + Outline Subtitle Fix

사용자 QA:

- 최근 생성 영상 중 제목이 `삼길포 대호방조제`로 시작하는 결과에서 마지막 자막
  `곧 큰 우럭도 기대해 볼 수 있겠습니다`의 TTS가 끝까지 재생되지 않고
  `...있겠습니` 부근에서 영상이 끝났다.
- 가장 최근 추가한 세 번째 Template Builder 템플릿은 흰색 자막 + 오렌지색 윤곽선이어야
  하지만 shortform preview에서는 글자가 거의 오렌지색으로 보였다.
- 같은 템플릿으로 실제 렌더하면 자막이 아예 overlay되지 않았다.

확인:

- 실제 render wrapper:
  `~/Library/Application Support/Clipper2/projects/files/local/shortform_1781747569696/render-jobs/shortform_render_1781747569696.clipper1-render-payload.json`
- payload subtitle duration 총합은 `33.336s`였지만 실제 `main.mp4`는 ffprobe 기준
  `33.200s`였다.
- 최신 outline 템플릿 payload
  `shortform_render_1781747941693.clipper1-render-payload.json`의 `subtitleText`는
  `box.enabled=false`, `subtitleBox.visible=false`, `outline.width=8`,
  `outline.color=#ff751a`였다.
- 수정 전 subtitle artifact는 alpha bbox가 `None`인 완전 투명 PNG로 생성됐다.

원인:

- auto zoom/pan frame count가 `int(duration * 30)` floor 계산이라 segment video가
  payload duration보다 짧아질 수 있었다.
- TTS/BGM concat은 AAC segment를 concat demuxer + `-c copy`로 붙여 timestamp/tail 손실
  가능성이 있었다.
- 최종 mux에 `-shortest`가 들어 있어 video 쪽이 조금이라도 짧으면 마지막 audio tail을
  잘랐다.
- Template Builder subtitle artifact 생성 시 `subtitleBox`가 숨겨져 있고
  `subtitleText.box.enabled=false`인 템플릿을 1px fallback box로 처리해 텍스트가 전부
  clipping됐다.
- Angular preview는 `-webkit-text-stroke`를 실제 fill text에 직접 적용해 stroke가 굵은
  윤곽선에서 글자 내부를 거의 덮었다.

구현 커밋:

```text

```

구현:

- `clipper_python`
  - auto motion frame count를 `ceil(duration * 30)`로 바꿔 fractional duration을 덮는다.
  - AAC TTS/BGM segment concat은 filter `concat=n=...:v=0:a=1`로 re-encode한다.
  - 최종 audio mux에서 `-shortest`를 제거했다.
  - subtitle box가 비활성/숨김인 Template Builder 템플릿은 `subtitleText` layer 자체의
    height와 style을 fallback으로 사용한다.
- `clipper_angular`
  - preview caption fill에는 stroke를 직접 적용하지 않는다.
  - caption span의 `::before` pseudo layer가 `data-text`로 outline/shadow를 뒤쪽에 그리고,
    실제 text node는 흰색 fill로 위에 남긴다.

## Shortform Preview Caption Outline Fill Follow-Up

사용자 QA:

- 이전 수정처럼 caption outline을 `::before` pseudo layer로 뒤에 그려도, 프리뷰에서는 여전히

  검증하지 못했다.

구현 커밋:


구현:

- caption preview에서 `data-text` / `::before` / `-webkit-text-stroke` 방식을 제거했다.
- caption line text 자체에 여러 방향 `text-shadow`를 적용해 outline을 근사한다.
