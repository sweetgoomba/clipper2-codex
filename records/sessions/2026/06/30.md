## Important Issues Resolved

### m2-stage API container에 git 없음

초기 source snapshot 고정은 API container에서 local repo git command를 실행하려다 실패했다.

```text
Error: spawn git ENOENT
CLIPPER_RELEASE_REPO_ROOT unset
```

해결:

- source snapshot capture도 Windows runner container endpoint에서 수행.
- m2-stage API는 desktop repo를 가질 필요가 없다.
- API는 runner `/source-snapshots/capture`에 sourceBranch를 보내고, runner가 실제 workspace에서 git fetch/rev-parse를 수행한다.

### GitHub private repo fetch prompt

Windows runner container에서 `git fetch origin dev`가 credential prompt 때문에 멈췄다.

해결:

- `GIT_TERMINAL_PROMPT=0`.
- `CLIPPER_RELEASE_GITHUB_TOKEN`을 mounted env file로 전달.
- Git extraheader로 PAT 전달.
- error log에서 raw/encoded token redaction.

### CodeSignTool env quote 문제

`C:\secure\clipper-codesign.env` 값에 따옴표가 들어가면 Docker `--env-file`이 quote 문자를 literal로 넘겨 인증 실패했다.

해결:

- env file 값은 quote 없이 저장.
- README/runbook/env example에 quote 금지 문서화.

### electron-builder output file lock

bind mount 아래 `desktop\clipper_electron\dist-app`에 출력할 때 NSIS artifact lock 대기 문제가 반복됐다.

해결:

- container 내부 `C:\runner-output\dist-app`로 output redirect.
- signed output은 `C:\runner-output\signed`.
- 현재는 `electron-builder.yml` 임시 수정 방식이다.
- 다음 세션에서 `clipper_electron/scripts/build-app.mjs --output-dir` 정식 지원으로 바꾼다.

### release_artifacts.s3_key unique collision

두 번째 build success report가 API 500으로 실패했다.

원인:

```text
duplicate key value violates unique constraint "release_artifacts_s3_key_key"
Key (s3_key)=(clipper2/dev/windows/Clipper2 Setup 0.0.1.exe) already exists.
```

해결:

- artifact/log key에 release version과 build number를 포함.
- `clipper2/dev/windows/0.0.1/build-N/...` 구조로 변경.

### Windows Runner Runtime 이슈

source snapshot 401:

- API는 `CLIPPER_RELEASE_WINDOWS_RUNNER_TOKEN`을
  `x-release-runner-token`으로 Windows runner에 보낸다.
- Windows runner는 `CLIPPER_RELEASE_RUNNER_START_TOKEN`으로 검증한다.
- 두 값이 같아야 한다.

runner report `ECONNREFUSED`:

- Windows runner env의 `CLIPPER_RELEASE_API_BASE_URL`이
  `http://localhost:3000`으로 되어 있었다.
- container 내부 localhost가 m2-stage API가 아니므로
  `https://dev-api.clipperstudio.ai`로 바꿔야 한다.

`electron-updater` module missing:

- `desktop/clipper_electron/package.json`/lock에는 dependency가 있었지만,
  Windows runner workspace의 `node_modules`가 예전 상태였다.
- feature branch pull 후 `runner/windows/install-windows-deps.ps1` 재실행이 필요했다.

build 8 stuck:

- build 8은 Windows build failure 후 runner report도 실패해서 API DB에
  `building`으로 남았다.
- `POST /release-runner/jobs/:id/report`를 수동 호출해 `failed` report를 넣고,
  build를 `blocked`로 닫았다.
