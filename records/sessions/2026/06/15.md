## Preview Engine Decision

The user clarified that the shortform preview cannot remain a static square or
ratio box. The target preview is a Vrew-like browser timeline preview:

- It must play generated clips as if they were a video.
- It must not pre-render a temporary FFmpeg preview file for normal editing.
- It must compose selected media assets, generated TTS audio, BGM audio,
  `main_title1`, `main_title2`, and active captions in the browser.
- It must react when caption text is edited and TTS regeneration updates
  `ttsAudioUrl` or `durationMs`.
- It must react when clips are added, deleted, reordered, or when selected media
  changes.
- It must consume the same template runtime contract that final render consumes.

The agreed sequence is:

1. Lock the shortform template runtime contract.
2. Simplify Template Builder so Builder-created templates produce that runtime
   contract and real 9:16 card thumbnails.
3. Replace the temporary simplified built-in template catalog with
   Builder-produced templates.
4. Build the browser timeline preview engine after Builder-created templates are
   flowing through the catalog.
