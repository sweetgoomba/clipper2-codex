## Release Runtime Implementation

`web/clipper_web_api`에는 release management runtime을 추가했다.

구현 방향:

- release version / build / artifact / source snapshot / target / event를 API runtime으로 관리.
- runner가 release job을 claim하고 결과 report하는 endpoint 추가.
- `ReleaseRunnerService` report API는 success/failure별 외부 method가 과도하게 드러나지 않도록
  SOLID 관점에서 리팩토링했다.
- 관련 변경 파일들을 추가 검토하고 large component/service를 분리했다.

주의:

- polling/SSE/WebSocket 기반 build 상태 실시간 갱신은 사용자가 제외 요청했다.
  초기 구현은 page refresh 기준으로 충분하다.
