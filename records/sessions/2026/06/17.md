## URL Backend Implementation

NestJS 이전 상태:

- URL mode project creation은 가능하다.
- 클립 생성 시에는 `current.source.url` 문자열을 그대로 LLM prompt로 넘긴다.
- Python legacy처럼 URL 본문 파싱, 원본 이미지 추출, 원본 이미지 우선 미디어 배정은
  아직 없다.

Python legacy 기준:

- `input_type == 1`이면 URL을 파싱한다.
- Naver Blog / Tistory / Brunch는 Selenium + BeautifulSoup로 제목, 본문 HTML,
  이미지 URL을 추출한다.
- 그 외 URL은 news scraper로 제목/본문을 가져온다.
- GPT에는 URL이 아니라 `parsed_content`를 넘긴다.
- 추출 이미지는 S3 업로드 후 클립 순서대로 먼저 배정하고, 부족할 때만 이미지 검색
  API를 사용한다.

NestJS 구현:

- `ShortformUrlContentExtractor` provider를 추가한다.
- URL 타입 판별과 본문/이미지 추출을 service로 분리했다.
- 지원 대상은 Naver Blog, Tistory, Brunch, generic/news HTML fallback이다.
- Naver Blog는 `mainFrame` iframe을 follow하고 `se-image-resource` 이미지를
  `?type=w966`으로 정규화한다.
- URL mode `generateClips()`는 파싱된 본문을 LLM prompt로 사용한다.
- `ShortformProject.source`에 `parsedHtml`, `parsedText`, `sourceImageUrls`,
  `sourceType`, `parsedAt`을 보존한다.
- 추출 이미지는 clip media asset으로 순서대로 우선 사용하고, 부족하면 기존 Naver
  image search fallback을 사용한다.
- mock HTTP fixture 기반 테스트로 URL 원문이 아닌 파싱 본문이 prompt로 들어가고,
  첫 clip media가 원본 이미지가 되는지 검증했다.

## Shortform Render Background Color / Subtitle Wrapping Follow-Up

사용자 QA:

- 새로 만든 shortform output에서 Template Builder layout background color가 적용되지 않고
  content area 밖이 흰색이었다.
- 자막이 잘려 보이는 경우가 있고, 긴 한국어 문장이 줄바꿈되지 않았다.

원인:

- 실제 완료 job `shortform_render_1781705695094` payload에는
  `template_settings.template_builder_layout_layers[0].background_color = "#0017c7"`와
  `contentArea y=456,height=1080`이 들어 있었다.
- 하지만 image clip의 auto zoom/pan 경로는 ffmpeg layout stack을 타지 않고
  `_write_legacy_auto_zoom_frames()` / `_write_legacy_auto_pan_frames()`에서 PIL frame을 먼저
  만들었다.
- 이 legacy auto motion preprocessor가 `layout_path is None`일 때 항상 흰색 canvas를
  생성해 Template Builder color layer를 무시했다.
- Template Builder 자막 아티팩트 렌더러는 `text.splitlines()`만 사용했다. 따라서 이미
  줄바꿈된 텍스트만 2줄로 그릴 수 있었고, 공백 없는 긴 한국어 token은 폭 기준 wrap 없이
  한 줄 이미지로 렌더된 뒤 clipped 처리됐다.

구현:

- `clipper_python` `010c1d0 Fix shortform render background and subtitle wrapping`
  - auto zoom/pan frame 생성 경로에 resolved `layout_layers`를 전달한다.
  - `_legacy_zoom_background_array()`가 흰색 고정 canvas 대신
    `template_settings.background_color`와 `template_builder_layout_layers`를 반영한
    background image를 만든다.
  - color layer와 image layer 모두 canvas bounds에 맞춰 alpha composite한다.
  - Template Builder subtitle artifact 렌더 전에 layer width 기준으로 text를 wrap한다.
  - 공백 기반 word wrap 후, 한국어처럼 긴 token은 글자 단위 fallback으로 나눈다.
  - `lineMode=double`이면 2줄 안에 들어오도록 font size를 낮춰 horizontal clipping을
    피한다.
