- New DB decision:
  - Split DBs into user, admin, and release data.
  - Each environment has three PostgreSQL containers.
  - DB Compose projects are environment-scoped:
    - `clipper-db-dev` contains `db-user`, `db-admin`, and `db-release`.
    - `clipper-db-stage` contains `db-user`, `db-admin`, and `db-release`.
    - `clipper-db-prod` contains `db-user`, `db-admin`, and `db-release` only
      when prod is self-hosted.
  - User DB ports: dev `55203`, stage `55201`, prod `55202`.
  - Admin DB ports: dev `55213`, stage `55211`, prod `55212`.
  - Release DB ports: dev `55223`, stage `55221`, prod `55222`.
  - Do not WAN-forward any Clipper DB port.
  - Prod can be either self-hosted Postgres containers or an external
    PostgreSQL service. Docker Compose only creates self-hosted containers; app
    env DB URLs point to the external DB endpoints when using external prod DB.
