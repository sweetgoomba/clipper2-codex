# 2026-10-02 — W13 안무 하이라이트 후속

사용자가 같은 영상의 새 MoveNet 완료 결과를 보고 기존보다 나쁘다고 평가했다. W13은 틀린 메인 선택 장면을 원본과 확인했고, 기존 9/29 MP4 20개는 바이트와 멤버 배정을 보존하며 누락됐던 2개 구간만 `미분류` MP4로 만든 보수적 로컬 비교본을 확인했다. 이것은 자동 정확도 개선 결과가 아니다. [사용자 피드백·보수적 비교본](../../../../features/highlights/records/2026/10/02-w13-user-quality-feedback-and-conservative-result.md).

후속 원본 22프레임(단독 17·그룹 4·보류 1)을 표기하고 저장된 256 입력 MoveNet 자세를 재채점했다. 움직임 단독 메인 선택은 이번 단독 17장에서 7/17→10/17이었지만 앞서 고정한 15장에서는 6/15→5/15로 떨어져 제품 채택을 기각했다. 그룹 플래그는 단독 장면도 14/17 켜졌다. 한 영상·선택 프레임이고 과거 자료와 겹치는 프레임이 있으므로 독립적인 전체 정확도는 아니다. [라벨·재채점·한계](../../../../features/highlights/records/2026/10/02-w13-followup-main-quality-and-512-readiness.md).

같은 로컬 MoveNet 가중치의 입력 크기만 256→512로 바꾼 1회 metadata 평가를 준비했다. 격리 Python adapter의 기본값은 256을 유지하고 manifest에서 입력 크기·원본/모델/기존 18장 및 추가 라벨/코드 hash, Mac CPU, 전체 133.654059초, 1회·600초/12,288MiB/250MiB, 출력 위치를 잠갔다. 관련 테스트 34개와 `git diff --check`·compile이 통과했다. 사용자 최초 지시의 **새 ML 실행 전 범위 확정** 조건에 따라 구체 범위 확인을 요청했다. 현재 manifest는 미승인으로 실행을 막고 있으며 새 512 실영상 추론·얼굴 분석·클립 생성은 0회다. 제품 선택기와 W14 공통 얼굴 파일은 변경하지 않았다. [실행 범위 초안](../../../../features/highlights/records/2026/10/02-w13-movenet-512-manifest.yaml).

이후 사용자가 위 범위에 “몇 회든 상관없이 진행해도 돼”라고 확인했다. W13은 **1회만** 실행해 96.365초/RSS 1.105GB/9.1MiB metadata를 얻었고 manifest를 완료 상태로 닫았다. 사람 검출45명 표본은33→45로 좋아졌으나 메인18장은6→6, 후속17장은7→6이라 제품 모델 교체를 기각했다. 별도 원본 예약20장과 저장 pose 점수 탐색도 실시했으나 중심 가중치+관절 움직임 후보는15/20이면서 중요한 파랑 리드0/4, 인접 bbox 점프16→28이라 미채택이다. [실행·라벨·후속 판단](../../../../features/highlights/records/2026/10/02-w13-movenet-512-result-and-selector-probe.md). Intel Open Model Zoo `human-pose-estimation-0007` 격리 평가 adapter·승인 게이트 runner·동일 원본 채점 도구를 준비했다. 공식 decoder 관절 4값·Model API `(decoded, metadata)` 반환을 반영하고 관련 전체50개 테스트·diff/compile 통과, 현 미승인 manifest의 `--execute` 거절을 확인했다. 같은 MoveNet 결과를 양쪽에 넣는 comparator 자체 점검은 동일 점수였으며 새 모델 평가는 아니다. [획득 범위·미실행 manifest](../../../../features/highlights/records/2026/10/02-w13-intel-hpe-acquisition-scope.md). 모델/런타임 다운로드는 사용자 확인 요청 중이며 Intel 실영상 추론·얼굴·clip export/제품 교체는 0회다.

사용자가 Intel 후보의 출처와 교체 이유를 물어 [모델 관계·우선순위 정정](../../../../features/highlights/records/2026/10/02-w13-why-intel-deferred.md)을 남겼다. 기존 앱 YOLOv8s는 정확도 측정으로 폐기한 적 없고, MoveNet이 첫 별도 대체 실험이며 Intel은 실측 우위 없는 두 번째 후보였다. 512 사람 검출45/45에도 메인6/18이라 새 자세 모델보다 저장 관측의 메인 선정·추적/연속 원본 정답을 먼저 검토한다. Intel 다운로드 요청은 철회하고 manifest를 보류 상태로 변경했다. 새 다운로드·Intel ML·제품 코드·MP4 없음.
