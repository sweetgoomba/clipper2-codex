# 2026-10-26 — 루트 문서 위치 정리

사용자의 조사·정리 지시에 따라 루트 `docs/merge`·`docs/superpowers`의 Markdown 6개를 `.codex`로 옮기고, 현재 문서의 기존 참조·상대 링크·색인·후속 상태 안내를 갱신했다. `docs/tips`와 hash로 봉인한 증거/실험 사본·다른 worktree 자료는 보존했다.

[이동 대응표·생성 원인·수정 범위·보존 자료의 옛 링크 읽는 법](../../../2026/10/26-root-docs-relocation.md)을 따른다. 새 문서 저장 위치는 [문서 규칙](../../../../README.DOCS.md)을 우선한다. 앱 코드 변경·모델 실행·커밋·푸시는 수행하지 않았다.
