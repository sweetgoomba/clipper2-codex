### 숏폼/Template Builder 안정화

- 앱 초기화 후 기본 숏폼 템플릿이 항상 존재하도록 처리했다.
- 기본 템플릿은 삭제되지 않게 했고, Template Builder 목록의 사용자/기본 제공 뱃지는 제거했다.
- 기본 템플릿 카드 썸네일은 실제 preview DOM 캡처 기반으로 맞췄다.
- 작은 Electron 창에서 preview 영역 스크롤바가 썸네일 캡처에 포함되는 문제를 수정했다.
- 숏폼 제작 페이지의 템플릿 기본 선택/정렬과 TTS 재생성 후 선택 상태가 바뀌는 문제를 수정했다.
- 새 템플릿 생성 모달에서 생성 버튼을 여러 번 눌렀을 때 중복 생성되는 문제를 막았다.
- Template Builder에서 제목 첫째줄/둘째줄 색상 맞추기 기능을 추가했다.
- Template Builder 저장 시 편집이 종료되게 하고 별도 편집 종료 버튼은 제거했다.
- Template Builder 샘플 렌더 버튼은 우선 숨겼고, 해당 페이지에서 ffmpeg/ffprobe 설치 확인을 하지 않게 정리했다.

### 숏폼 생성/편집/렌더

- 붙여넣기 숏폼 프로젝트 편집 진입 시 원본 입력 내용이 복구되지 않던 문제를 수정했다.
- 기존 DB 경로를 제거하고 숏폼 편집용 원본 프로젝트는 파일 JSON 저장 방식으로 정리했다.
- URL/프롬프트/붙여넣기 숏폼 생성 경로에서 Template Builder snapshot/render params를 안정적으로 쓰도록 정리했다.
- `Shortform render requires a legacy Clipper1 or Template Builder template preset` 오류 경로를 추적하고 수정했다.
- shortform script generation에서 web search가 붙은 primary OpenAI 요청은 유지하되, JSON이 깨질 경우 no-tools JSON repair 요청으로 복구하도록 `web_api`를 수정했다.
- generated media search provider 실패가 자동 클립 생성 전체를 중단하지 않도록 처리했다. 자동 생성에서는 narration/TTS를 유지하고 media pool은 비워 생성할 수 있게 했다.
- packaged NestJS에서 숏폼 BGM 파일을 찾지 못해 preview/file 요청이 404가 나는 문제를 수정했다.
  - 실제 packaged 경로: `Resources/clipper_nestjs/modules/projects/assets/clipper-studio-bgm`
  - `shortform-bgm-catalog` resolver 후보 경로와 테스트를 보강했다.

### ffmpeg/ffprobe 설치 flow

- 앱 시작 preflight나 packaged plugin 시작 경로에서 동의 없이 `ensureFfmpeg()`가 호출될 수 있는 흐름을 제거했다.
- ffmpeg/ffprobe는 사용자가 필요한 기능을 시작했을 때 동의 UI를 통해 설치되는 방향으로 정리했다.
- reset 후 fresh 상태에서 자동 다운로드되지 않는지 확인 항목으로 유지했다.

- 배리에이션 plugin 설치 시 ffmpeg/ffprobe 동의 설치 후 virtual workflow 설치가 이어지지 않던 문제를 수정했다.

  - `pluginRouteFor('variation')` -> `/variation`
