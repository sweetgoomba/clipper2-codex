## 제품 방향 재정의 — 일회성 생성기에서 지속 콘텐츠 운영으로

- 업종, 채널, 표현 원칙 같은 공통 맥락은 여러 영상에서 반복 사용한다.

  한다.

## 품질 문제를 더 거시적으로 재정의

AI 숏폼 디렉터의 출발점은 현재 `프롬프트로 영상생성` 결과가 사용자에게 매력적이지 않다는
문제다. 품질 개선은 다음 두 축이다.

1. 기획 입력과 판단 재료 개선
2. 장면·에셋·대사 매칭, 생성형 영상, 도식과 renderer 등 표현 방식 개선

현재는 첫 번째에 집중한다. 하지만 `입력 개선 = 사용자 목적 + Vira`로 고정하면 시의성은
있지만 뻔한 영상을 만들 위험이 있다. NotebookLM 공식 자료에서 source grounding, 대상·초점
조정, 시각 표현 선택, creative direction과 refinement 원리를 확인했다.

새 핵심 흐름:

```text
Project Memory + Current Context
  → Episode Research Pack
  → Content Opportunity
  → Director Brief
  → Story / Scene / Visual Intent
  → VideoPlan
  → RenderRecipe / MP4
  → Performance & Editorial Feedback
  → Project Memory
```

입력의 일곱 축:

1. 정체성·목적
2. 공식 지식과 source library
3. 시청자 정보
4. 시장·트렌드 정보 — Vira
5. 창작 레퍼런스와 표현 문법
6. 과거 성과와 편집 피드백
7. 실행 조건과 제작 가능성

핵심 중간 산출물:

- `Episode Research Pack`: 이번 실행에 필요한 자료만 immutable snapshot으로 선별
- `Content Opportunity`: 시청자 질문, 유용한 정보, 근거, 프로젝트 관련성과 시각적 payoff의
  조합
- `Director Brief`: 시청자, thesis, promise, 훅, 주장·근거, beat별 narration·visual·asset
  intent와 품질 위험

상세 설계:

- `.codex/design/SHORTFORM_DIRECTOR_QUALITY_INPUT_ARCHITECTURE_AND_DIRECTOR_BRIEF_DESIGN_2026-07-21.md`
