## 숏폼 원본 이미지 재사용 기능

### 사용자 요구

- `붙여넣기로 숏폼 제작`에서 붙여넣은 HTML의 원본 이미지를 클립 자동 생성에도 사용한다.
- URL 방식과 붙여넣기 방식 모두 에셋 교체 모달에 `원본 이미지` 탭을 표시한다.
- 원본 이미지를 선택하면 해당 클립 에셋으로 교체한다.

### Angular 구현

- 붙여넣은 HTML에서 유효한 HTTP(S) 이미지 URL을 중복 없이 추출한다.
- `data:`와 `blob:` URL은 원본 이미지 후보에서 제외한다.
- 저장된 project source와 현재 paste HTML의 원본 이미지 URL을 에셋 교체 dialog에 전달한다.
- 에셋 교체 dialog의 탭을 `검색 / 원본 이미지 / 업로드`로 확장했다.
- 원본 이미지 선택은 기존 remote asset import/replace 경로를 재사용한다.
- URL과 paste 양쪽에서 원본 이미지가 dialog에 전달되는 테스트를 추가했다.

변경 파일 범위:

- `shortform-workflow-paste.ts`와 spec
- `shortform-workflow-page.component.ts`와 spec
- `shortform-asset-replace-dialog`의 TS/HTML/spec

### NestJS 구현

- paste source의 HTML에서 HTTP(S) `<img src>`를 추출하고 HTML entity를 해석한다.
- 저장된 `sourceImageUrls`와 새로 추출한 원본 URL을 정규화해 project source에 보존한다.
- URL 방식과 동일하게 원본 이미지를 media search보다 우선해 생성 클립에 사용한다.
- 원본 이미지 두 개가 paste generation에서 실제 클립 에셋으로 사용되고 media search를 호출하지 않는 테스트를 추가했다.

변경 파일 범위:

- `src/modules/shortform/application/shortform-project.service.ts`
- `test/shortform-project-generation-assets.test.js`

- 제품 비전은 Vira 진단 → Clipper 제작 → ViewX 측정이며, 현재 자동 연동은 로드맵이고 문의 기반 수동 연계 단계다.

### NotebookLM 공식 자료로 확인한 사실

- NotebookLM은 사용자가 선택한 source를 기반으로 artifact를 생성한다.
- Short Video Overview는 공식 도움말 기준 약 60초이며 현재 영어만 지원한다.
- 일반 Video Overview는 Nano Banana로 source 문맥에 맞는 일러스트를 만든다고 Google이 공개했다.
- Cinematic Video Overview는 Gemini 3, Nano Banana Pro, Veo 3를 사용하고 Gemini가 creative director 역할을 한다고 Google이 공개했다.
- source grounding에도 생성물 부정확성과 audio glitch 가능성이 남는다.

### 확정 사실로 취급하지 않은 항목

- Stable Video Diffusion, SDXL, Manim, Remotion, ChatTTS, ElevenLabs, Suno, Udio와 구체적인 FFmpeg pipe 방식은 NotebookLM 내부 스택으로 공개 확인되지 않았다.
- 위 기술 목록은 NotebookLM 역공학 결과가 아니라 유사 파이프라인 후보군으로만 취급한다.
- Short와 Cinematic이 같은 생성 파이프라인을 쓴다고 단정하지 않았다.

### 합의한 제품 방향

- 입력 품질과 영상 제작 파이프라인을 별도 축으로 고도화한다.
- 입력은 사용자 프롬프트를 넘어 브랜드 정보, 캠페인 목적, source 문서와 Vira 시장 분석을 구조화해 사용한다.
- 한 prompt에 영상 하나가 아니라 content matrix를 통해 수십·수백 개의 캠페인 변형을 만든다.
- 검색 에셋 방식이나 생성형 방식 하나로 전환하지 않고 Shot/Beat별 hybrid routing을 사용한다.
- 실제 사람·제품·증거는 실제/원본/검색 에셋을 우선한다.
- 추상 개념·분위기는 생성 이미지·영상, 관계·비교·숫자는 프로그램 모션과 도식을 사용한다.
- 기존 clip은 편집 호환 단위로 남길 수 있지만 렌더 모델은 `VideoPlan → Scene → Beat → Shot → Layer` 시간 기반 IR을 검토한다.
- Supertonic은 유지하고 Remotion/Motion Canvas를 범용 후보, Manim을 특화 도식 renderer 후보로 검토한다.
- 최종 encode·mux·audio mix는 FFmpeg 역할을 유지한다.
