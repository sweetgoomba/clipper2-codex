# 2026-07-29 AI 숏폼 디렉터 — 검증된 Shorts discovery와 선택적 정밀 분석

## 사용자 결정

- YouTube 검색은 조회수순 40개와 관련도순 40개를 같은 최근 30일 조건으로 가져온다.
- `shorts`, `쇼츠`, `챌린지` 같은 단어를 검색어에 코드로 강제 추가하지 않는다.
- 검색 결과는 모두 중복 제거 후 Shorts URL로 확인하며 중간에 임의로 검사를 멈추지 않는다.
- 확인된 Shorts 전체를 보여준다. 상위 6개 같은 표시 제한은 두지 않는다.
- 정밀 분석 영상은 사용자가 0~5개 선택한다.
- 0개도 정상 흐름이며 시장 조사 근거만으로 주제·영상 후보를 만들 수 있어야 한다.
- 1~5개 선택 시 실제 영상 정밀 분석을 수행하고 그 패턴을 후속 생성 근거로 쓴다.
- 사람이 읽는 조사·검증 요약을 먼저 보여주고 원본 JSON은 접어 둔다.

## 구현

### Web API

- YouTube search DTO/provider가 `maxResults=40`을 허용하고 실제 query에 전달한다.
- video details를 최대 80개 ID에 대해 50개 단위 batch로 조회한다.
- topic synthesis v3가 레퍼런스 분석 없는 market-only grounded context를 허용한다.

커밋:

- `0a80e14 feat: expand shortform YouTube discovery`
- `c8696c8 feat: expand shortform video details batch`
- `0239779 feat: support market-only topic synthesis`

### Desktop Nest

- 두 YouTube search lane을 각각 40개·최근 30일·`videoDuration=short`로 요청한다.
- 중복 제거된 최대 80개 ID 전체를 Shorts URL로 확인한다.
- 200/no-redirect, 해당 ID의 watch redirect, 기타를 각각
  `shorts`, `not-shorts`, `unverified`로 구분한다.
- 검증 request/result 전체를 strict local JSON artifact로 저장한다.
- 길이 기준 필터를 제거하고 검증된 Shorts 전체를 candidate snapshot에 보존한다.
- 정밀 분석 계약을 고정 3개에서 1~5개로 변경했다.
- 명시적인 정밀 분석 skip preflight/start 경로와 skip artifact를 추가했다.
- skip 경로는 source-normalization market evidence로 topic synthesis를 실행한다.
- reference 경로는 선택된 실제 분석 결과를 reference pattern으로 전달한다.

커밋:

- `abf49ec feat: verify public YouTube Shorts`
- `f841266 feat: collect all verified Shorts references`
- `8416bb5 feat: retain all verified Shorts candidates`
- `817fabc feat: support one to five reference analyses`
- `569576a feat: continue research without reference analysis`

### Angular

- 확인된 Shorts 전체를 표시하고 기본 선택을 0개로 바꿨다.
- 최대 5개 선택, 1~5개 정밀 분석 비용 확인, 0개 skip 비용 확인/승인 UI를 분리했다.
- YouTube 링크는 `/shorts/{videoId}`를 연다.
- Shorts URL 검증 artifact를 사람이 읽을 수 있게 다음으로 표시한다.
  - 검색 결과(중복 포함)
  - 중복 제거 후 실제 검사 수
  - 확인된 Shorts / 일반 영상 / 확인 실패 수
  - 모든 video ID의 lane, 판정, HTTP 상태, 시도 횟수
- 기술 정보와 원본 JSON은 기존 panel에서 기본 접힘 상태를 유지한다.

커밋:

- `29f0a00 feat: make reference analysis optional`
- `9341050 feat: explain YouTube Shorts validation`

  - `CI=1 npm test -- --watch=false --browsers=ChromeHeadless --include='src/features/shortform-director/**/*.spec.ts'`
  - 303/303 통과
  - `CI=1 npm run build` 통과
- Electron:
  - `CI=1 npm run build:app:mac:arm64:local-api`
  - macOS arm64 패키징 통과
  - 출력 `desktop/clipper_electron/dist-app/mac-arm64/Clipper2.app`

Web API, Desktop Nest, Karma의 실제 HTTP 경계 테스트는 샌드박스 로컬 포트 제한으로 처음
`EPERM`이 났으며 동일 명령을 권한 환경에서 다시 실행해 전부 통과했다.

Angular 기본 빌드는 32.39GB 영속 캐시의 LMDB native close에서 SIGABRT가 재현됐다.
캐시 파일은 삭제하지 않았고 `CI=1`로 이번 검증과 패키징에서만 영속 캐시를 비활성화하자
같은 소스가 정상 빌드됐다.

## 실제 provider 상태

이번 구현 검증에서는 새 유료 provider 호출을 하지 않았다. fixture를 성공 증거로 보고하지
않는다.

사용자가 등록한 Naver, YouTube Data API, OpenAI, Gemini credential은 기존 관리자
페이지/Web API 구조를 그대로 사용한다. 키 값은 출력하거나 문서에 기록하지 않았다.
