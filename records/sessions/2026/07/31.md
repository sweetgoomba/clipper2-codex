# 2026-07-31 AI 숏폼 디렉터 부분 레퍼런스 성공 자동 진행

## 배경

선택한 레퍼런스 영상 3개 중 2개의 정밀 분석이 실제로 성공했지만, 기존 구현은 선택한
영상이 모두 성공해야만 조사 주제 생성으로 넘어갔다. 한 영상의 실패 때문에 이미 얻은
유효한 분석 결과도 사용하지 못하고 흐름이 멈추는 문제였다.

## 확정한 동작

- 정밀 분석이 하나 이상 성공하면 성공한 분석만 `reference-pattern-synthesis`와 주제 종합에
  전달하고 부모 조사를 자동으로 계속한다.
- child 정밀 분석 attempt의 실제 상태는 그대로 보존한다. 일부 실패가 있어 child가
  `partial`이어도 부모 조사 자체에 discovery 실패가 없으면 부모는 `succeeded`다.
- 성공 분석이 하나도 없으면 부모는 `awaiting_reference_selection`을 유지한다. 이 경우
  사용자는 실패 영상 재시도, 다른 영상 선택, 또는 정밀 분석 없이 계속(시장 근거만 사용)을
  선택할 수 있다.
- 모든 분석이 끝난 화면에는 `레퍼런스 N개 중 M개 분석 성공 · K개 실패`를 표시한다.
  성공이 0개면 가능한 세 경로를 설명한다.
- Angular는 부분 성공 attempt 뒤 부모의 종합이 완료될 때까지 폴링한다. 분석 목록 조회가
  일시적으로 실패해도 기존 상태와 승인 정보를 지우지 않고 재시도한다.

설계와 실행 계획:

- `.codex/design/SHORTFORM_DIRECTOR_PARTIAL_REFERENCE_CONTINUATION_DESIGN_2026-07-31.md`
- `.codex/design/SHORTFORM_DIRECTOR_PARTIAL_REFERENCE_CONTINUATION_EXECUTION_PLAN_2026-07-31.md`

## 최종 검토 후 보완

최종 검토에서 확인한 부분 성공 폴링의 경계 조건을 Angular에 보완했다. 외부 provider/API
호출은 하지 않았다.

- 부모 조사가 완료될 때 child attempt의 입력·진행·실패 artifact를 덮어쓰지 않고 유지한다.
  완료된 조사를 다시 선택해도 저장된 attempt와 분석 결과를 다시 읽어 카드와 요약을 복원한다.
- 분석 목록의 로컬 조회가 일시 실패한 시점에 부모가 완료돼도 조사 주제는 표시하되, 분석 목록이
  정상적으로 읽힐 때까지 폴링을 계속한다.
- 부모가 아직 종합 중이면 선택·건너뛰기·재분석으로 현재 폴링 세션을 무효화할 수 없도록
  레퍼런스 선택을 잠근다.
- 회귀 테스트 3개를 RED로 확인한 뒤 구현했다. 대상 스토어 `34/34` 통과, Angular 전체
