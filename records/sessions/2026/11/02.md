# 2026-11-02 세션 기록

## 운영 API 요청 경로와 ALB 전환 설명 문서화

- 사용자 요청: 직전 대화의 상세 경로 설명을 `.codex`에 저장하고 WORKBOARD에서 참조할 수 있도록 남긴다.
- [설명 문서](../../../../operations/production-ha/records/2026/11/02-api-request-path-and-alb-transition.md)에 앱 API 호출 예시, DNS와 실제 요청 전달의 구분, 회사 현재 경로, ALB를 통한 회사 중계, AWS API/주 DB 전환의 세 도식을 저장했다.
- DDNS가 공유기 공인 IP를 안내하는 역할, m2-proxy 내부 포트, Host/SNI 유지와 순환 방지, HTTPS 연결 구간, 루트 도메인 Alias 지원 조건, 비동기 복제의 데이터 유실 가능성을 함께 기록했다.
- [Production HA 진입점](../../../../operations/production-ha/README.md)과 [작업 현황판](../../../../handoff/WORKBOARD.md)에 설명 문서를 연결했다. 과거 자동 HA 장비 논의와 이번 수동 전환 우선 구성의 시점을 구분했다.
- 문서화 작업이다. 회사/AWS 구성·소스·DB·DNS를 변경하거나 본 세션에서 운영 전환을 실행한 것은 아니다. 커밋·푸시는 수행하지 않았다.
