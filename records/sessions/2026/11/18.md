Nest 전체 실패 129개는 같은 샌드박스의 기준판에서도 재현됐다. 기준판은 5,531개 통과·130개 실패·2개 취소였으며, 임시 기준 스냅숏의 경로 검사 실패가 한 건 더 있었다. 로컬 리스너 권한과 런타임 조건이 포함된 전체 검사 결과다. 집중 64개와 커밋 전 53개는 실행 파일 범위가 다르다.

Electron 전체 검사의 초기 1건은 비어 있던 이전 빌드의 `.tmp-uv` 디렉터리에 대한 기대값 실패였다. 폴더 정리 후 전체 2,050개가 통과했다. Angular의 초기 전체 실패 92개는 세션 의존성이 추가된 실제 견적 서비스를 쓰던 두 테스트 픽스처의 인증 주입 누락이었고, 픽스처 보완 후 전체가 통과했다.

최초 감사 중 AI 재료 확인창을 좌표로 취소하려다 유료 선택지가 눌린 일이 있었다. 전용 QA 계정에 120크레딧이 차감됐고, 더미 공급자 인증의 401 실패 뒤 120이 환불됐다. 최종 측정에서는 모달의 정확한 제목을 확인하고 Escape 또는 유일한 취소 버튼을 사용했으며, AI 유료 실행 URL도 디버그 세션에서 차단했다. 최종 전후 원장에는 해당 기존 실패 1건과 차감·환불 2행, 합계 0이 남았고 추가 실행이 없었다.

Windows 설치판, 실제 외부 이미지 서비스 지연, 서로 다른 파일을 많이 사용하는 프로젝트의 전체 성능은 별도 확인이 남아 있다. 큐레이션은 사용 가능한 조각의 조기 판정을 적용했으며 원격 미리보기 결과는 생성 시 다시 확인한다.
