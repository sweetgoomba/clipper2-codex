# 2026-09-20 W07 스토리보드 재설계 결정과 작업 공간 준비

## 사용자 의도와 확정 흐름

유튜버가 다음 영상을 결정하고 제작할 기획을 얻도록 돕는다. 외부 AI 영상 도구용 프롬프트는 필요하지만 주된 목적은 아니다.
프로필 → 조사·주제 → 영상 후보 → 상세 스토리보드 생성 순서는 유지한다. 단계마다 사용자 선택·대기를 요구하던 UI를 하나의 생성 작업으로 묶는다.

1. 최초 진입에서는 플러그인 설명, 프로필 생성과 추천을 제공한다.
2. 프로필 생성은 목록에 저장만 한다. 이 시점에 과금하거나 큐에 넣지 않는다.
3. 목록의 ‘스토리보드 생성하기’로 수량·과금 모달을 연다.
4. 기본 주제 3 × 주제별 시나리오 5. 주제 1~5, 시나리오 2~10을 사용자가 선택한다.
5. 상세 스토리보드 1개당 5크레딧. 기본 15개/75크레딧, 범위 2~50개/10~250크레딧. 동의한 뒤 큐에 등록한다.
6. 주제·후보·상세 생성은 내부에서 이어 진행한다. 사용자가 화면에 머물며 다음 단계를 누를 필요가 없다.
7. 완료된 홈 카드 또는 프로필에서 주제별 시나리오(기존 영상 후보) 카드를 보고, 클릭하면 이미 생성된 상세 결과를 연다.

## 프로필 모달 요구

제목: ‘숏폼 스토리보드를 만들 프로필을 생성해 보세요’. 하단: ‘취소’, ‘프로필 생성하기’.

- 필수: 직접 입력하는 이름; 추천 1뎁스 분야 드롭다운과 그 아래 추천 2뎁스 복수 선택 버튼; 성별·연령층; 제작 목적.
- 2뎁스는 ‘전체’를 맨 앞에 두며 선택 시 다른 버튼을 해제한다.
- 성별: 전체/남/여. 연령: 전체, 10~20대, 20~30대, 30~40대, 40대 이상. 연령 복수 선택.
- 제작 목적: 추천 중 단일 선택 또는 직접 입력.
- 선택: 생성 스타일(어투 등 추천 복수 선택), 관련 키워드, 금지 키워드.
- 관련 키워드는 분야를 더 좁힐 내용, 금지 키워드는 생성에 사용하면 안 되는 단어·문구.
- 키워드 입력 앞에 #, Enter로 칩 추가, Space는 공백 유지, 칩 ×로 삭제. 레이블 옆에 용도·입력 안내. Enter 처리 시 한글 조합 확정과 태그 추가를 구분한다.
- 필수값 미입력 시 생성 버튼 비활성화. 작성한 내용이 있으면 취소 시 소실 확인.

## 재시도·완료·환급 결정

성공한 주제·후보·상세·유효한 중간 결과는 보존한다. 실패한 부분만 제한된 자동 재시도로 복구한다.
‘재시도 중’, 재시도 횟수, 중간 오류는 사용자에게 표시하지 않는다. 생성 진행만 표시한다.
자동 재시도 종료 후 최종 실패만 안내하고 실패 수 × 5크레딧을 환급한다. 환급 완료 문구는 실제 정산 확인 뒤 표시한다.

사용자는 규칙·상투 문구로 기본 스토리보드를 대신 만들어 성공 처리하는 기존 로컬 fallback을 거부했다. 새 생성 흐름에서는 그런 대체 결과를 만들고 성공으로 처리하지 않는다. 유료 완료 개수에도 포함하지 않는다. 정상 AI 중간 결과를 재사용하는 checkpoint 복구는 유지할 방향이다.
환급 종료 후 수동 재시도·재과금, 취소/종료 정책, 구체적 병렬도와 시도 한도는 아직 상세 설계하지 않았다.

## Git 작업
