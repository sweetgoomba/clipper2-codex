# 2026-08-25 Storyboard 세션 마무리

## 결과

AI 숏폼 디렉터를 `스토리보드` 중심의 플러그인으로 정리했다. 운영 프로필에서 주제를
조사하고, 영상 후보를 만든 뒤, 선택한 후보로 외부 AI 도구에서도 활용할 수 있는 상세
스토리보드를 만드는 흐름까지 구현했다. 플러그인 자체에서 영상을 생성하고 렌더하는 기능은
현재 제품 흐름에서 제외했다.

Web API와 관리자 웹의 Storyboard 변경은 `dev`에 병합·푸시했고 2026-08-25 개발 서버에
배포했다. 상세 배포 명령과 결과는
`../../../../operations/env-runtime/records/2026/08/25-storyboard-dev-deployment.md`에 있다.

## 구현 및 변경 사항

### 플러그인 명칭과 역할

- 플러그인 스토어의 `AI 숏폼 디렉터` / `shortform-director` 표기를 사용자 화면에서
  `스토리보드` / `storyboard`로 변경했다.
- 설명에서 특정 내부 조사 명칭을 제거하고, 여러 근거를 바탕으로 영상 스토리보드를
  생성하는 플러그인이라는 역할이 드러나도록 수정했다.
- 기존 식별자를 사용하는 API·저장 데이터와 사용자에게 보이는 제품 명칭을 분리했다.

### 운영 프로필

- 분야·대상·목적 아래에 영상 `길이`를 함께 표시한다.
- 카드 상단의 수정 버튼을 세로 점 3개 메뉴 안의 `수정`으로 대체했다.
- `새 영상 시작`을 `프로필 선택`으로 바꾸고 카드 전체를 클릭해 선택할 수 있게 했다.
- 고정된 10개 후보를 보여주는 프로필 추천 프리셋을 추가했다. 추천 API 호출은 없다.
- 사용자가 실수로 보관한 K-POP 프로필을 복구했다.
- 프로필 복제·보관 UI와 관련 백엔드 흐름을 제거했다.

### 아이디어 조사와 주제 생성

- 아이디어 조사 단계에서는 YouTube 영상 검색을 수행하지 않는다.
- 결과 개수를 8개로 강제하지 않고, 근거와 프로필에 맞는 서로 다른 주제를 최대 12개까지
  생성한다. 유효한 주제가 적으면 억지로 개수를 채우지 않는다.
- 같은 사건을 표현만 바꿔 여러 주제로 쪼개는 결과를 줄이고, 하나로 묶기 어려운 별개의
  사건만 따로 주제로 만들도록 생성·후처리 기준을 조정했다.
- 네이버 검색어는 Google Trends 항목에 종속시키지 않고 운영 프로필에서 독립적으로
  계획한다. 프로필과 관련된 상위 개념·동의어도 탐색할 수 있도록 검색 범위를 넓혔다.
- 외부 검색 일부가 비거나 모델 응답이 불완전해도 가능한 근거로 계속 진행하도록 복구
  경로를 보강했다.
- `조사 내용`을 오른쪽 패널이 아닌 중앙 모달로 통일했다. 바깥 클릭 닫기, 어두운 배경,
  높이 제한, 비고정 헤더를 적용했다.
- 실제 생성 검색어는 전체 너비로 표시하고, 공급자별 조사 결과는 한 열로 배치한다.
  항목은 처음 10개만 표시하며 `더보기`마다 10개씩 추가한다.
- 새 조사 모달의 높이를 줄이고 조사 범위 카드의 세로 레이아웃을 복구했다.

### 영상 후보

- 선택한 조사 주제를 바탕으로 영상 후보를 만들고 후보에서 스토리보드로 이동하는 흐름을
  유지했다.
- 후보 페이지의 조사 내용도 아이디어 페이지와 같은 중앙 모달을 사용한다.
- 아래 기술·과정 중심 동작은 이번 일정에서 화면에만 보이지 않게 처리했다. 삭제나 최종
  정보 구조 정리가 끝난 상태가 아니며 후속 작업이 필요하다.
  - `생성 기록 상세`
  - `근거와 과정`
  - `근거 ID와 기술 정보 보기`

### 스토리보드 생성과 결과 화면

- 영상 모델 선택과 영상 생성·렌더 중심 흐름을 스토리보드 문서 생성 흐름으로 바꿨다.
- 영상 후보의 개략 구성을 바탕으로 컷별 시간, 장면 목적, 화면 구성, 카메라·동작, 자막,
  내레이션, 전환과 오디오 지시를 제공한다.
- 컷별 이미지 탐색에 쓸 검색어와 활용 가이드를 제공한다. 이미지를 자동 검색하거나
  다운로드하지는 않는다.
- 사용자용 한국어 스토리보드와 외부 생성형 영상 도구에 붙여 넣을 수 있는 영문 컷
  프롬프트를 함께 제공한다.
- 컷 내용과 AI 프롬프트를 따로 복사할 수 있게 했다.
- 결과 카드에서 레이블과 내용을 명확히 분리하고 복사 버튼을 짧고 일관된 크기로 정리해
  가독성을 개선했다.
- `새 스토리보드 만들기`가 반응하지 않던 문제와 반복적으로 발생하던 생성 502 오류 경로를
  수정했다.
- 모델·응답 형식 문제로 정상 결과를 만들 수 없을 때 로컬 스토리보드로 복구하는 경로는
  유지했다.

### 품질 검증의 역할 변경

- 내레이션 밀도, 컷별 시간 합계, 고유명사 문자열 비교, 일부 프롬프트·근거 연결 같은 품질
  검사는 더 이상 스토리보드 생성을 실패시키지 않는다.
- 검사는 삭제하지 않고 비차단 품질 경고로 남겼다. 어느 장면의 어떤 항목이 걸렸는지 결과
  화면 한쪽에서 확인할 수 있다.
- 구조적으로 읽을 수 없는 모델 응답처럼 결과 자체를 만들 수 없는 오류와, 개선 가능한
  품질 경고를 분리했다.

### 공통 모달과 화면 정리

- Storyboard 플러그인의 모달은 화면보다 짧은 최대 높이, 내부 스크롤, 더 어두운 배경,
  바깥 클릭 닫기를 공통 동작으로 사용한다.
- 조사·프로필 추천·새 조사 등 개별 화면마다 달랐던 높이와 닫기 동작을 정리했다.

## 이번에 확정하지 않은 것

- 모델은 비용 때문에 변경하지 않았다.
- 스토리보드 직접 수정 기능은 이번 범위에 넣지 않았다.
- 품질 경고만 모아 AI에게 개선을 요청하는 기능은 아직 구현하지 않았다.
- 자동 이미지 검색·다운로드·삽입은 구현하지 않았다. 검색어와 활용 가이드만 제공한다.

## 실제 비용 기준선

2026-08-26에 로컬에 저장된 최근 성공 실행의 artifact usage를 다시 확인해 비용 기준선을
정정했다. Luna 할인 단가는 입력 `$0.20`, 출력 `$1.20`/100만 토큰이며, Nano는 입력
`$0.20`, 출력 `$1.25`/100만 토큰이다. 환산은 보고용으로 `$1=1,400원`을 사용했다.
Reasoning 토큰은 `outputTokens`에 포함되어 별도 가산하지 않았다.

| 단계 | 실제 표본 | 확인 비용 |
|---|---|---:|
| 주제 뽑기 | K-POP `#51E9F9`: Nano 4회 + Luna 1회 | $0.011058 ≈ 15.5원 |
| 주제 뽑기 | 생활비 절약 프로필: Nano 4회 + Luna 1회 | $0.011684 ≈ 16.4원 |
| 영상 후보 | K-POP 하이브/JYP 주제, Luna 1회 | $0.007622 ≈ 10.7원 |
| 영상 후보 | K-POP 캣츠아이 주제, Luna 1회 | $0.005441 ≈ 7.6원 |
| 스토리보드 | 하이브 vs JYP, Luna 2회 | $0.011573 ≈ 16.2원 |
| 스토리보드 | 앨범 판매량, Luna 2회 | $0.009223 ≈ 12.9원 |
| 스토리보드 | 튜이드, Luna 2회 | $0.010183 ≈ 14.3원 |

따라서 현재 정상 실행의 대표 범위는 주제 15~16원, 후보 8~11원, 스토리보드 13~16원이며,
주제→후보→스토리보드 한 사이클은 약 40~42원이다. K-POP `#51E9F9`에서 하이브/JYP
후보를 스토리보드까지 연결한 실제 계보는 `$0.030253 ≈ 42.4원`이었다.

과거에 기록한 스토리보드 `$0.012313 ≈ 17.2원`도 같은 할인 단가로 계산된 별도 실행이며,
해당 실행은 입력 6,393·출력 9,195 토큰이었다. 최근 실행마다 출력 분량과 입력 근거가
달라 금액도 달라진다.

이 수치는 공급자 청구서가 아니라 앱이 저장한 usage에 표준 단가를 적용한 확인 가능한
계산값이다. 현재 usage 저장 구조에는 cached input 토큰이 별도 보존되지 않으므로 실제
청구액은 캐시 할인 적용 여부에 따라 조금 낮을 수 있다. 모델 호출까지 진행된 실패·재시도는
성공 실행 비용과 별도로 추가될 수 있다.
